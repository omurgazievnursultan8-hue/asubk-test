| ФК-40 | Бланки в каталоге | **Нет**: бланки печатаются только из карточки объекта («Печать ▾», ФК-24); каталог — только отчёты и собранные отчёты. Решено против рекомендации | Свёрнутая группа «Бланки · 54» с подсказкой, где печатается (рекомендация); отдельный пункт меню «Бланки» |
| ФК-41 | Порядок внутри группы | **Как в перечне — по смыслу** (ФО-02 → ФО-01 → ФО-27 → ФО-98); тот же порядок, что в перечне к акту; номер — через поиск | По номеру ФО (смысловой ряд ломается) |
| ФК-42 | По чему ищет поиск | **Номер, название и весь текст «Что показывает»** перечня (на экране — первая фраза, поиск — по всему тексту) | + колонки и разрезы (шум: «куратор», «заёмщик» есть почти везде); как на стенде — только номер и название |
| ФК-43 | Название пункта меню и страницы | **«Каталог отчётов»** (вместо «Формы ФО»); меню «Отчеты»: Каталог отчётов · Рабочие списки · Конструктор отчётов · Шаблоны печати; номера ФО-NN остаются в строках | «Формы ФО» (непонятно и обещает бланки, которых в каталоге нет — ФК-40); «Отчёты» (в меню «Отчеты → Отчёты») |

**По умолчанию (частные случаи принятых решений):**
- Виды отчётов (ФО-04, 09, 10, 11, 14, 15, 16, 17, 47) — отдельной строкой с пометкой «вид» сразу под своим отчётом, в той же группе (ФК-2).
- «Собранные отчёты» — группой в конце каталога, видна подразделениям из круга отчёта (ФК-22, ФК-39).
- Непустой запрос скрывает группы без найденного; ничего не нашлось — «По запросу … ничего не найдено». Число отчётов у группы — число найденных.
- Название отчёта в строке — тоже ссылка, как «Открыть»; открывает экран отчёта (ФК-25).
- ФО-27 «Эпизоды просрочки за период» на стенде отсутствует — дефект стенда (письмо, п. 1.1), не вопрос каталога.

**Дефекты макета:**
- ФК-Д1. Экран «Рабочие списки», пометка 2: «кнопкой «В рабочий список» в окне отчёта» — окна больше нет, кнопка на экране отчёта (ФК-25). Поправить текст пометки.
- ФК-Д2. Макет каталога ещё не отражает ФК-43: пункт меню и заголовок страницы — «Формы ФО», «← Формы ФО» на экране отчёта; пометка 9 называет пункт «Формы ФО».

## Гриллинг экрана отчёта — 20.11.2026

Страница 2 макета `mockups/reports/dorabotki-otchetnosti.html` (экран «Экран отчёта»). Решения ФК-25…ФК-37 этой же даты
не переспрашиваются. Каждое решение принято владельцем из 2–3 вариантов с рекомендацией.

| № | вопрос | решение | отвергнуто |
|---|---|---|---|
| ФК-44 | Рамка экрана отчёта | **Один отчёт: настроить → сформировать → посмотреть → забрать** (Excel, PDF, рабочий список). Свои показатели — конструктор; выпуска и сравнения отчётов здесь нет | Рабочее место аналитика (сводная таблица, свои показатели, графики — снято в ФК-11, ФК-16, ФК-20) |
| ФК-45 | Формировать ли при открытии | **Сразу по умолчаниям**: из каталога отчёт открывается сформированным; другие параметры — «Сформировать». Отчёт дольше 30 с — в фоне с уведомлением (письмо, раздел 3) | Пусто до «Сформировать», как на стенде (лишний клик); сразу только у быстрых (признак «тяжёлый» вести некому) |
| ФК-46 | Возврат из карточки | **Та же вкладка; «Назад» возвращает отчёт как был** — настройки, свёрнутые группы, прокрутка. Номер договора и заёмщик — обычные ссылки (новая вкладка — средней кнопкой). ФК-32 не нарушается: не запоминается только новый вход из каталога | Всегда новая вкладка (вкладки копятся); карточка поверх отчёта (карточке кредита тесно) |
| ФК-47 | Карточки итогов: какие числа | **Задаём в перечне**: у карточки каждого отчёта строка «Итоги сверху» — 3–4 колонки ИТОГО (наша работа на 31 отчёт). Пока не задано — запасное правило: число строк детали + первые 2–3 суммовые колонки ИТОГО | Только автоматическое правило (у ФО-01 теряет «Залог», у ФО-09 сумм нет); без карточек (частично переигрывает ФК-34) |

**По умолчанию (частные случаи принятых решений):**
- Пока отчёт считается — «Формируется…» на месте таблицы, «Сформировать» неактивна; дольше 30 с — расчёт в фоне с уведомлением о готовности (письмо, раздел 3; ФК-45).
