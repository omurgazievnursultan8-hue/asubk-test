## Answer

Внесено в `mockups/collection/collection.html`, по всем шести пунктам тикета
«Точки интеграции» (01), включая дополнение (пункт 6, гейт треков), плюс
восполнен найденный пробел — недостающий вид меры для терминала 7.

**`MEASURE_KINDS`** (:1494 район, после «Решение суда (отсутствие
правопреемника)»): добавлено «Определение о замене стороны правопреемником» —
`внешний акт`, `outcomes:[{value:'заменена', setsTerminal:'Правопреемство'}]`,
без `setsPhase` (в К5 нет фазы под положительное разрешение), `basisKinds`
такой же, как у сиблинга. Сателлиты: `KIND_SECTION` → `'Правопреемство'`;
`PERSON_STATE_CLOSE` — новый вид добавлен (закрывает ожидание правопреемства
симметрично отрицательной ветви); `MEASURE_SUBDIV`/`GATES`/`DEADLINE_*`/`SPINE`/
`CHILD_DEADLINE_TPL`/`SCOPE_KIND_DEFAULT` — не тронуты (сиблинг тоже без
записей, фолбэк раздела покрывает).

**МП-О3** — `measureSetsTerminal(m)` заведена рядом с `measureSetsPhase`,
зеркалит её формулу (пара вид×исход). `outcomes[].setsTerminal` дописан
четырём существующим терминальным видам (значения совпадают с их же
`setsPhase`) и новому виду правопреемства. Старый `TERMINAL_BY_MEASURE`
оставлен без изменений (те же 4 записи) — единственный его читатель теперь
деадлайн-глушилка «Сроки на контроле» (:3973, вне наряда этой волны);
`outcomeOf()` его больше не читает.

**Миражи** — `RESTRUCTURING_APPROVALS`/`SECURITY_TERMINATIONS`, пустые объекты
по `creditId`, у залогового зеркала (:1840 район). SEED не заводился.

**Треки и гейт** — `collTrackClosed(r)` (`collsOf(r).every(c =>
!collSnapshotStale(c) && c.realStage === 'реализовано')`), `tracksClosedFor(r)`
(судебный+исполнительный+залоговый), `terminalCandidateOf(r)` (меры через
`measureSetsTerminal` + миражи, терминал 6 гейтится `layerOf(r._proc,
r.credit) === null` + нулевой остаток фолбэком, ранжировано `TERMINAL_RANK`).
`outcomeOf(r)` = кандидат, пропущенный через `tracksClosedFor` — общий гейт для
всех семи терминалов, включая «Полное погашение» (пункт 6, МП-О4).
`TERMINAL_RANK` +3: Реструктурирована 5 · Обеспечение прекращено 6 ·
Правопреемство 7.

**Чип** — третий член `trackBadges`: когда есть кандидат, но `outcomeOf`
пуст — pill `${candidate}, взыскание идёт` с подсказкой, какой именно трек
(судебный/исполнительный/залоговый) не закрыт.

Проверено throwaway jsdom-смоуком (`_smoke-terminaly.mjs`, выполнялся через
`dom.window.eval` — classic `<script>`, top-level `const` не становится
свойством `window`; создан, прогнан, удалён, в репозитории не остался):
- новый вид зарегистрирован, `setsTerminal` верный, `setsPhase` отсутствует
  намеренно, секция/`PERSON_STATE_CLOSE` подключены;
- `measureSetsTerminal` — совпадение по исходу, пустой исход/неизвестный вид →
  `null`, новый вид даёт «Правопреемство»;
- `TERMINAL_RANK` — все семь ключей, новая тройка 5-6-7;
- `TERMINAL_BY_MEASURE` не изменился (4 ключа);
- на синтетике: мираж реструктуризации при чистых треках закрывает требование;
  открытый судебный трек блокирует терминал даже при нулевом остатке (гейт
  универсален) — чип появляется с верным текстом; терминал 6 не наступает,
  когда по кредиту уже образован слой (`layerOf`), даже при наличии миража
  прекращения обеспечения; требование без предметов залога — трек закрыт
  тривиально;
- ни одной console/pageerror ни в одном сценарии.

SEED терминалов 5/6/7 не заводился (миражи остаются пустыми, вне карты — наряд
п.6). Полный прогон `collection-check.mjs`/`collection-data-audit.mjs`/
`collection-seed-coverage.mjs` не запускался (резерв на конец пятой волны).

Destination карты достигнут: три новых терминала подключены (мера/мираж/мираж),
проверка треков универсальна для всех семи (включая ранее не проверявшееся
«Полное погашение», МП-О4), `TERMINAL_BY_MEASURE` заменён на пару вид×исход
там, где это имеет значение (МП-О3), не трогая единственного другого читателя.
Карта закрыта.
