# Карта: приказная ветвь взыскания (МП5-17)

## Destination

Три вида приказной ветви из `ASUBK-vzyskanie-logika.md` §30 (МП5-17) — «Заявление о
выдаче судебного приказа» · «Судебный приказ» (исправленный `basisKinds`) ·
«Определение об отмене судебного приказа» — корректно объявлены в `MEASURE_KINDS`
`mockups/collection/collection.html` **и** во всех сателлитных runtime-структурах,
которые запись `MEASURE_KINDS` сама по себе не покрывает (открыватели/закрыватели
трека, гейт, подразделение, сроки, хребет дела).

Явно ВНЕ этой карты (следующие пункты наряда §30, зависят от механизмов, которых в
коде ещё нет):
- гашение слоя по «Определение об отмене» — п.2 наряда (слой по кредиту, МП5-1/2);
- откат фазы у отменённого приказа — п.5 наряда (фаза-максимум, МП5-12);
- SEED-кейсы приказной ветви (K3-подобная ситуация) — п.6 наряда (пересев затравки).

## Decisions so far

- [Точки интеграции (01)](issues/01-tochki-integracii.md) — семь сателлитов
  `MEASURE_KINDS` (нашли седьмой по ходу — `KIND_SECTION`, не был в исходном
  списке): `SUD_OPENERS` получает оба новых вида · `KIND_SECTION` получает оба
  → `'Судебный'` · `MEASURE_SUBDIV` не трогать (фолбэк через раздел) · `GATES`
  получает заявление СВОЕЙ темой (не общей с иском) · срок тпл №24 не трогать
  (декоративный даже у иска) · `SPINE` вне тикета (SEED, п.6 наряда) ·
  `CHILD_DEADLINE_TPL` не трогать (нет источника числа дней — п.7 наряда) ·
  `SCOPE_KIND_DEFAULT` получает только заявление.
- [Реализация (02)](issues/02-realizaciya.md) — три вида внесены в `MEASURE_KINDS`
  (заявление, отмена, исправленный `basisKinds` приказа) и все восемь сателлитов
  правлены построчно по тикету «Точки интеграции». Проверено throwaway jsdom-смоуком
  (не `collection-check.mjs`) — страница грузится чисто, все структуры дают ожидаемые
  значения. SEED не тронут. **Destination карты достигнут — карта закрыта.**
