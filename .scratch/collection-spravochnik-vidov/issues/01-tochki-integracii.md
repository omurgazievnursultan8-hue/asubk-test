## Question

Пять вопросов, что Destination оставил открытыми (`/grilling`, рекомендация на каждый,
ответ фиксируется здесь же).

0. Наряд-обходный вопрос (прецедент 6а/6б): `МП-11` (мировое соглашение — три вида
   вместо одного, `ADR-0047`, 61→64) не реализован в коде, хотя Destination карты
   считает от базы «64 после МП-11». По объёму (снять `p.agreements[]`, три кнопки,
   три новых вида) сравним с отдельной картой — входит в периметр этой карты или
   выносится?
1. «Определение о повороте исполнения» (`ADR-0049`) — `source`/`resultIsDocument`/
   `outcomes`/`basisKinds`/`needsDelivery`.
2. «Дополнительное решение суда» (кандидат, `ADR-0046`) — те же поля; заводить сейчас
   (до наряда п.2, ключ слоя) или ждать?
3. Прекращение обеспечения / утверждение реструктуризации — подтвердить 0 новых видов
   (уже миражи `RESTRUCTURING_APPROVALS`/`SECURITY_TERMINATIONS`)?
4. Итоговый счёт справочника после карты.

## Answer

Все пять решены (`/grilling`, рекомендации приняты все пять раз):

0. **МП-11 выносится в отдельную карту**, не входит в наряд п.1. Наряд п.1 по тексту
   §30 называет 4 компонента (приказ/поворот/обеспечение/реструктуризация) — мировое
   там не названо, только фигурирует как молчаливая база отсчёта. МП-11 меняет модель
   состояния (снимает хранимые `status`/`active`/`breached`), не просто справочник —
   другой класс работы. Правило деления то же, что у 6а/6б: резать по границе
   независимого объёма обхода.
2. **«Определение о повороте исполнения»**: `source:'внешний акт'`,
   `resultIsDocument:false`, `outcomes:null`, `basisKinds:['Определение об отмене
   судебного приказа','Решение суда']`, `needsDelivery:false`, `deliveryChannels:null`.
   Basis — акты, гасящие слой при уже произведённом взыскании; мировое (МП-11 вне
   периметра) и голый «Судебный приказ» (гасится только через отмену) не включены.
3. **«Дополнительное решение суда»**: `source:'внешний акт'`, `resultIsDocument:true`
   (по аналогии с базовым «Решение суда» — само основание для дальнейших бумаг),
   `outcomes:null`, `basisKinds:['Решение суда']` (единственный вид, слой которого можно
   «добавить», по тексту `ADR-0046`). Заводится **сейчас** — справочник декларативный,
   слоевую арифметику подключит отдельно наряд п.2 (ключ слоя); раннее заведение вида
   не создаёт дефекта, вид просто не встретится в затравке до п.2.
4. **Прекращение обеспечения / утверждение реструктуризации — 0 новых видов**,
   карта их не трогает. Механизм (`RESTRUCTURING_APPROVALS`/`SECURITY_TERMINATIONS`)
   уже реализован как снимок чужого модуля; видимость на карточке и SEED — отдельные
   тонкие хвосты показа/данных, не справочника.
5. **Итог: 60 → 62.** Приказная ветвь (3 вида) уже была внутри текущих 60 (пришла
   попутно, наряд п.4/п.5). МП-11 (+3) — отдельная карта. Два новых вида этой карты:
   «Определение о повороте исполнения», «Дополнительное решение суда».

Тикет исчерпан — «Реализация» (02) разблокирована.
