# Карта: мировое соглашение — акты журнала вместо сущности с флагами (наряд МП-11, ADR-0047)

## Destination

`p.agreements[]` (`collection.html:8158`+ — `status`/`breached`/график/авторство,
переходы кнопками `msApprove`/`msReject`/`msBreach`, синхронизация `msSyncStates`)
схлопывается в реквизиты **трёх новых видов меры** в `MEASURE_KINDS` (:1501 заменяемая
запись «Мировое соглашение»):

- **«Проект мирового соглашения»** — наш документ, единственный исход `направлен на
  утверждение` (без `setsPhase`). Предусловия вида (ADR-0045) вместо кнопок-гейтов
  `msTermGate`/`msNotWorseOk`/`msScheduleReady`/`msStageEligible`: подан иск (п. 22) +
  собственные поля формы (график от отраслевого отдела · срок ≤5 лет при истёкших
  обязательствах, п. 24 · аттестация «не льготнее ранее принятых», п. 24) — см. вопрос 1.
- **«Определение об утверждении мирового соглашения»** — внешний акт,
  `basisKinds:['Проект мирового соглашения']`, исходы `утверждено`
  (`setsPhase:'Решение суда'`) / `отказано в утверждении` (без `setsPhase` — взыскание
  продолжается). Вступает в **`AWARD_KINDS`** (наряд п.2/п.3, `.scratch/collection-sloy-
  klyuch`, `.scratch/collection-razbivka-stati`) — переиспользует готовый механизм целиком:
  `m.awards[reqId]` по пяти статьям, `layerOf()`, плитка «Слой: X (акт от Y)» в
  `panelDebt`, сверка «требовали → присудили» в `panelReq()`. Ни одной новой денежной
  машины не заводим — см. вопрос 3 (как график соотносится с суммой присуждённого).
- **«Констатация нарушения мирового соглашения»** — наш документ, исход `нарушено`,
  `basisKinds:['Определение об утверждении мирового соглашения']`. Закрывает паузу
  досрочно, запускает срок 10 р.д. по п. 37 (строка 43 таблицы сроков — уже существует,
  новый шаблон не заводим).

**Пауза «действует МС» — свёртка, не флаг.** ~~`PAUSE_KINDS` (`:1906`, сегодня
`{guarantee_letter, restructuring}`) пополняется `'mirovoe'`~~ — **ИСПРАВЛЕНО при
реализации (issues/02): НЕ пополняется**, см. «Decisions so far» ниже — открыватель/
закрыватель вычисляются напрямую из журнала (`mirovoeApprovalOf`/`mirovoeBreachOf`),
без записи в `r.states` вовсе (тот же `breached`-факт, что `pauseClosed` читает для
двух прежних видов, но другим механизмом — `r.states` там несёт мануальный closer,
здесь закрыватель мера, не кнопка). `r.states` перестаёт получать push из
`attachAgreementState`; `msSyncStates` снимается целиком. Календарного закрывателя
«график погашен полностью» нет (вопрос 2 — подтверждено).

**«Соглашение о добровольном исполнении»** уже вид меры (`:1514`, `basis:true`
предусловие уже есть, `COURT_ACT_BASIS_KINDS`) — снимаем только вторую, параллельную
бухгалтерию (`p.agreements`-запись/`attachAgreementState`/`states`-push при регистрации).
Слоя не образует (акт-основание уже его создал, ADR-0047 §Последствия). Входила ли она в
ту же паузу «соглашение» — вопрос 2.

**`Исполнительный лист.basisKinds`/«Заявление о выдаче исполнительных листов».basisKinds**
(`:1422`, `:1503`) — `'Мировое соглашение'` → `'Определение об утверждении мирового
соглашения'`.

**Регистрация — общей формой.** `openAgreementModal`/`agSync`/`agSave` уходят;
регистрация «Проекта…» идёт через обычный `openMeasureModal`/`saveMeasure`, с секцией
МС-полей, включаемой по виду (тем же приёмом, что секция «Присуждено» у `AWARD_KINDS` —
условная секция по `Set.has(kind)`, не отдельная модалка). `msCards`/`msBanner`/
`msStatusPill` (карточка в `panelReq`, баннер в шапке) читаются по мере/паузе, а не по
`a`-объекту.

**Справочник видов:** −1 («Мировое соглашение») +3 = **62 → 64** (совпадает со счётом
ADR-0047, который считал от 61 — до наряда п.1; наряд п.1 добавил 2 своих вида, здесь
считаем от текущих 62).

Явно ВНЕ этой карты:
- Денежные агрегаты слоя МС — третий уровень матрицы разнесения читает график
  соглашения (МП5-8/МП5-10) — вне всех 7 пунктов наряда §30 (та же граница, что назвала
  карта «ключ слоя»). Слот в матрице, по тексту ADR, уже есть — не трогаем.
- Признание недофиксированной разницы безнадёжной (п. 83) — существующий гейт `GATES`,
  ничего не меняем; ADR §4 — модельное утверждение «ничего не запрещает», не код.
- SEED-примеры НОВЫХ ситуаций сверх миграции существующих дел 120/344 — вне карты.

## Decisions so far

Грилинг 01 закрыт (`issues/01-tochki-integracii.md`, `Status: resolved`):

1. МС-5 → `PRECONDITIONS`-предусловие (`basis:true`); МС-1/2/4 → in-form валидации
   в `openMeasureModal`, условные по `kind==='Проект мирового соглашения'`.
2. `dobrovolnoe` — из паузы убирается вовсе. `'mirovoe'` → `PAUSE_KINDS`, открыватель
   «Определение об утверждении…», закрыватель «Констатация нарушения…», без
   календарного закрывателя.
3. `m.awards`/`m.schedule` — раздельный ввод, без автосинхронизации/сверки.
4. Дела 120/344 мигрируются: 120 — «Проект…» (16.06.2026, якорь `hearings[]`) +
   «Определение…» (10.07.2026, `m.awards` из фактического графика = 257000, не 240000
   как предполагалось здесь по `credit.debt.principal` — грилинг не сверил с числами
   графика, реализация исправила при тестировании), `m.schedule`; 344 — только
   «Проект…» (18.07.2026). `p.agreements`/`extra.agreements`/`c.agreement`(мировое)
   вычищаются, дело 120 ДОПОЛНИТЕЛЬНО уже имело живую меру «Мировое соглашение» через
   `opt('agreement')`-билдер (карта ошибочно считала, что мер там нет вовсе) —
   ререйзена, не создана с нуля.

**Отход от буквы карты, найден при реализации (issues/02, п. «Пауза «действует МС»»):**
`PAUSE_KINDS`/`r.states` НЕ используются для мировой паузы — `r.states`-механизм несёт
МАНУАЛЬНЫЙ closer (toolbar «Снять паузу»), а закрыватель МС — мера («Констатация
нарушения…»), не кнопка; общая запись создала бы ложную «Снять паузу» на живом МС.
Вместо этого — `mirovoeApprovalOf(r)`/`mirovoeBreachOf(r,appr)`, вычисляемые целиком из
журнала (тот же паттерн, что судебный/исполнительный трек, ADR-0032 п.1), отдельная
проверка в `measureGate` после существующей `r.states`-паузы. `dobrovolnoe` вышло из
блокировки автоматически (единственный источник его `r.states`-записи удалён).

## Out of scope

- Денежные агрегаты слоя МС (третий уровень матрицы разнесения, МП5-8/МП5-10) — вне
  наряда §30 целиком, прецедент — карта «ключ слоя».
- Признание разницы безнадёжной (п. 83) — не меняем существующий гейт `GATES`.
- SEED новых (не существующих 120/344) ситуаций мирового — вне карты.
- Апелляция как акт, ревизующий слой (МП-2, отдельный номер от МП-11) — не эта карта.
