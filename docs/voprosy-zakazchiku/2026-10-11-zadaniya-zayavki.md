# Вопросы к заказчику по заданиям из кредитных заявок

**Дата:** 11.10.2026 · **Модуль:** задания (поручения по кредитным заявкам) ·
**Вопросов:** 3

Модуль заданий получает работу из карточки кредитной заявки
(`mockups/zadaniya/ASUBK-zadaniya-logika.md`, §5; решения `ЗЗ-1`…`ЗЗ-14`). Задание появляется
каждый раз, когда заявка переходит к следующему исполнителю:

- головной филиал получает «Подтвердить комплект»;
- каждый назначенный отдел получает «Дать заключение»;
- комиссия получает «Предварительно изучить»;
- каждый член комиссии получает «Проголосовать», председатель — «Вынести решение»;
- после одобрения специалист получает «Сформировать кредит», а затем «Зарегистрировать договоры».

Если заявку вернули на доработку, специалист получает «Дополнить заявку».

По всем трём вопросам проект **уже принял решение** и построил по нему систему. Просим одно из
двух: **«подтверждаем»** или **«иначе: …»**. Ответ «иначе» систему не ломает: меняется значение
настройки или набор действий.

---

## Вопрос 1. Сроки работы по заявкам · заказчик · `ЗЗ-12`

**Приняли.** Сроки заданий:

| задание | кому | срок |
|---|---|---|
| Подтвердить комплект | головной филиал | 2 р.д. |
| Дать заключение | отдел | 3 р.д. |
| Предварительно изучить | комиссия | 3 р.д. |
| Проголосовать | член комиссии | «Крайний срок», назначенный комиссией |
| Вынести решение | председатель | дата заседания |
| Дополнить заявку | специалист | 1 календарный месяц |
| Сформировать кредит | специалист | 2 р.д. |
| Привязать решение и программу (индивидуальная заявка) | специалист | 30 р.д. |
| Зарегистрировать договоры | специалист | 10 р.д. |
| Заявка 10 р.д. без движения в статусе «Новый» | специалист | 5 р.д. |
| Обязательный документ просрочен у заявки в работе | специалист | 5 р.д. |
| Программа заявки перестала принимать заявки | специалист | 5 р.д. |

**Почему.** ТЗ сроков этих работ не задаёт. Срок «Дополнить заявку» взят из п. 66 Типового
положения (ПКМ №554), остальные — оценка проекта.

**Просим** подтвердить сроки или назвать свои. Если у разных кредитных линий свой регламент,
просим его назвать: система умеет держать разные сроки по видам работ.

## Вопрос 2. Недостатки не устранены за месяц · заказчик · `ЗЗ-13`

**Приняли.** Если специалист не дополнил возвращённую заявку за месяц, комиссия получает задание
«Отклонить за неустранение недостатков» со ссылкой на п. 66. Комиссия может отклонить заявку
прямо из статуса «Требуется доп. информация». Сейчас такой возможности нет: отклонить можно
только заявку, которая находится на рассмотрении. Автоматически система заявку не отклоняет.

**Почему.** Норма говорит, что проект «подлежит отклонению», а не отклоняется сам. Решение должен
принять тот, у кого есть право отклонять, — комиссия.

**Нужно согласие** на новое действие комиссии и на то, что срок в месяц действует для всех
кредитных линий, а не только для ФРР.

## Вопрос 3. Программа закрыта, а заявки по ней в работе · заказчик · `ЗЗ-6`

**Приняли.** Если программа закрыта, срок её действия истёк или закрыто её госрешение, заявки по
ней, которые уже в работе, не останавливаются. Но кредит по такой программе не формируется.
Специалист получает задание: перевести заявку на действующую программу или отозвать её. Для этого
у заявки появляется действие «Сменить программу». Оно доступно, пока заявка не на рассмотрении у
комиссии. Собранные документы сохраняются, условия приводятся к новой программе.

**Почему.** Выдать кредит под отменённое основание нельзя. Если же отзывать заявку и создавать её
заново, заявителю и отделам придётся проходить весь круг ещё раз.

**Просим ответить:** можно ли довести до кредита заявку, поданную до закрытия программы, по
старой программе. И нужно согласие на действие «Сменить программу».
