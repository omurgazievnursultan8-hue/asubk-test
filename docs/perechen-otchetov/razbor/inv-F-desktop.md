## Файлы, похожие на регулярные отчёты (кандидаты в перечень)

1. `20gruppa.xls` — «Информация по задолженности» на дату (сводный, по группам и областям, с ИТОГО). Сильнейший кандидат.
2. `Сейсултан.xlsx` (Sheet0) — «Информация по погашениям» на дату. Шапка того же вида, но по одному заёмщику — уточнить.
3. `1.pdf` / `2.pdf` / `chakanges/*.pdf` — печатная форма «Расчет показателей задолженности по государственным заемным средствам» (по каждому договору, ФРП/госкредит). Регулярно печатается.
4. `New Folder/ФРП/погашенные/*` и `New Folder/ФРП/Претензии по 7 областям.xls` — помесячные выгрузки погашений и претензий по областям (повторяются по месяцам).
5. `погашен-2026-09-ФРП.xlsx` — помесячная сводка погашений (название), но содержимое сейчас — запрос по модификациям (уточнить у автора).

Не относятся к отчётам (справочники, выгрузки для сверки, документы, тестовые): Result_3/6/8/9, `ставки из БД`, `Ош заемщик адрес менен`, `Untitled 1.xls`, `график_тест.xls`, `список-тест-заемщиков.xls`, сканы 3843/27898, `Кредиты.docx`, `arr-free-frp`.
