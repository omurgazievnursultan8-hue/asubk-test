# Перечень отчётов и бланков к финальному акту — решения и материалы

Разработчики попросили полный перечень отчётов, чтобы при подписании финального акта не было
споров «такого отчёта нет». 28.10.2026 по нему прошёл `/grill-me`: 20 решений, все приняты
рекомендованным вариантом, сводку владелец подтвердил. Здесь записаны эти решения, материалы
разбора, источник перечня и результат шага 1.

## Решения

| № | Решение |
|---|---|
| 1 | Строка считается «сданной», если готовый отчёт или бланк в системе совпадает с карточкой. Что конструктор позволяет его собрать, не засчитывается |
| 2 | Две части: **Отчёты** (таблица по данным на дату или за период) и **Бланки** (документ, который система печатает сама). Выгрузка любого экранного списка в xlsx — одна общая строка-требование. Дашборд, статистика, экраны анализа, журналы и рабочие реестры принимаются по ТЗ своих модулей |
| 3 | Документы, которые официальное ТЗ требует только **учитывать** (иски, заявления, жалобы, мировое, письма в министерства, правоохранительные органы и ПССИ, торги — ¶557–585), — это виды документов в ФО-17 «Реестр принятых мер», а не бланки |
| 4 | Берём всё, что хотим, в одном списке. У каждой строки колонка «основание»: оф. ТЗ ¶ / Порядок №41 п. / ВНД / старая система / ТЗ модуля |
| 5 | Полная карточка: кому/зачем · когда · параметры · строки (группировка, подытоги) · колонки · выгрузка · основание · правило проверки. У бланка: получатель · текст (откуда) · что подставляется · регистрационный номер · формат |
| 6 | Excel. `Перечень.xlsx`: листы «Перечень» и «Приёмка». Папка образцов: на отчёт `ФО-NN.xlsx` с листами «Образец» (как `obrazcy-razrabotchikov/report-temp.xls`) и «Описание»; на бланк `ФО-NN.docx`. Всё собирается скриптом из одного источника |
| 7 | Перечень закрытый, с окном правок до начала этапа отчётности: до этого карточки уточняются свободно, строку можно заменить равноценной. После — только по взаимному согласию. На приёмке проверяется перечень на дату заморозки. Новое после приёмки собирают в конструкторе |
| 8 | Отчёты из старой системы: её форма берётся за основу (шапка, группировка, порядок колонок). Явные недостатки исправляются: номер договора вместо служебных номеров, суммы до тыйына, валюта и ставка в отдельных колонках. Единица сом / тыс. сом — параметр, по умолчанию как в старой форме |
| 9 | Приёмка на контрольном наборе (≈ 20 заёмщиков со всеми случаями; основа — данные макета, их дополнить). В образце обязательны состав строк и колонки, числа — для иллюстрации. Проверка по правилам карточки («ИТОГО = сумма по карточкам кредитов»). Верность самих процентов и штрафов проверяется приёмкой расчётов, а не отчётов |
| 10 | Внутренние документы Порядка №41 и Положений: +5 бланков-служебок, собираемых из данных (исполнение судебного акта п. 37, внесудебное взыскание п. 42, правопреемник п. 53, банкротство п. 58, отказ в доп. залоге — Положение №12). Акт сверки о полном погашении (п. 64) — вид ФО-34. Решения и протоколы комитетов, заключения, планы мероприятий, графики и отчёты выездов, запросы комиссии — учёт в документообороте (видны в ФО-19 и ФО-17) |
| 11 | Охват: кредитный модуль. В шапке оговорка: «Отчёты подсистем «Поручительство», «Корпоративное управление», «СУГС» определяются отдельными перечнями и этим перечнем не закрываются». Поручительство и СУГС из разбора — вне перечня |
| 12 | Методика №16, приложения 1–4 (документальный мониторинг, выезд, АПК, акт о нецелевом использовании) — четыре бланка. Образец — сами приложения. Заключения по этапам мониторинга — учёт. Запросы и предписания — виды «Письма по кредиту» |
| 13 | ОКУ по МСФО 9: новый отчёт «Данные для расчёта ОКУ на дату» (по кредиту: остаток ОД/%/штраф в сомах, дни просрочки, группа платёжеспособности, оценка залога, реструктуризирован). Сам расчёт — у службы рисков, вне системы |
| 14 | «Собрано за месяц» — вид ФО-04. Новый отчёт «Изменения статусов кредитов за период» (оф. ТЗ ¶59). ФО-06 становится план-прогнозом по Методике №17; AI-прогноз отчётом не является, он принимается по ТЗ анализа. Новый отчёт «Кредитный риск портфеля» для Правления раз в квартал, ⚠ состав показателей запросить у службы рисков. Влияние реструктуризации — вид ФО-10 (до/после). Внешние формы (Минфин, Кабмин, Нацстатком, банк-агент) — строки-заготовки с ⚠: без образца к заморозке строка снимается |
| 15 | Образцы практики (`/home/azamat/Desktop/New Folder/ФРП/`): «Претензии по 7 областям» → образец ФО-17, вид «по областям за период»; «погашенные/*» → вид ФО-02 «погашенные за период» (образец «ТАЛАС ПОГАШЕННЫЕ.xls»); «снятие залога по погашенным…» → образец ФО-16; `1.pdf` / `chakanges/*.pdf` → образец ФО-35 (и тела ФО-03); Result_3/6 → вид ФО-25 (месяц × куратор). Региональный отчёт куратора и «СПРАВОЧНАЯ ФРП» (это телефонный справочник) — вне перечня. У ФО-02 набор колонок выбирает пользователь: в образцах два варианта, 17 и 9 колонок |
| 16 | Бланки модулей и исходящие документы ВНД. **Двенадцать отдельных бланков:** выписка по кредиту (вид ФО-41), внутренний акт сверки платежей, расчёт реструктуризации (было/стало), доп. соглашение к кредитному договору, соглашение о переводе долга, соглашение о добровольном исполнении, соглашение о расторжении, расчёт распределения выручки от залога, платёжное требование в банк, заявка на перечисление средств, паспорт предмета залога, доп. соглашение к договору залога. **Один бланк «Письмо по кредиту»** с видами: по реструктуризации уполномоченному органу (п. 18), родственникам умершего (п. 51), запросы по умершему (пп. 51–52), о банкротстве (п. 55), по целевому использованию (Методика №16), снятие запрета нотариусу/рег. органу (Положение №12), согласие на действия с залогом (п. 8), запрос финпакета (ТЗ 21), возврат проекта на доработку (ПКМ №554). Резолюция по шаблону уходит в ТЗ документооборота |
| 17 | Включены: 4 новых отчёта (курсовая разница ¶740, план-факт погашений ¶75, заявки по программам и статусам, план и факт выдачи); 10 новых бланков (опись предметов залога, справка об обеспеченности, извещение о восполнении залога, протокол комиссии, пустые бланки заявки, карточка организации, журнал регистрации, лист ознакомления, опись дела, РКК); ФО-27, ФО-28; формы без данных ФО-05, 08, 15, 18, 19, 20 (данные обеспечивает разработчик). **ФО-21 «Кадры» снят** |
| 18 | Внешние бланки (заёмщику, госоргану, суду, нотариусу) — на русском и кыргызском. Кыргызские тексты даёт заказчик в окно правок; если не дал к заморозке, бланк сдаётся на русском, и это записано в карточке. Внутренние — только на русском. Отчёты — на языке интерфейса |
| 19 | Перечень — приложение к ТЗ 20 и единственный источник состава форм. ТЗ 20 гл. 13 «Стартовый набор» сокращается до ссылки (п. 13.6, 13.12–13.18 снимаются). P23 получает задачу «собрать формы по перечню». Один JSON в репо → скрипт собирает xlsx, образцы и лист приёмки |
| 20 | Два шага. **Шаг 1:** `Перечень.xlsx` со строками — состав закрыт. **Шаг 2:** до заморозки карточки, образцы и лист «Приёмка». Черновики пишут агенты, затем одно ревью и один круг правок |

Нумерация: новые строки продолжают каталог с **ФО-53**. Выданные номера не меняются и не
переиспользуются (правило каталога). Варианты существующей формы записываются как «ФО-NN, вид «…»».
Общие требования, кроме выгрузки списков: отчёт выгружается в xlsx и pdf, бланк — в docx и pdf
(оф. ТЗ: экспорт xls/pdf/doc).

Итог сборки: 33 отчёта + 4 заготовки внешних форм с ⚠, 54 бланка, 2 общих требования; видов —
7 у отчётов и 11 у бланков. Всего 111 строк.

## Шаг 1 — состав строк (сделан 28.10.2026)

Источник — `perechen.json`, руками правится только он. `Перечень.xlsx` собирает
`python3 scripts/build_perechen.py`; при ошибке в строке скрипт падает и файл не пишет.
Листы: «Перечень» (правила, обозначения, строки) и «Вне перечня» (что не входит и где учтено).
Лист «Приёмка» и колонки карточек добавляются на шаге 2.

Новые номера:

| Номера | Что |
|---|---|
| ФО-53…59 | отчёты: курсовая разница, план-факт погашений, заявки по программам, план и факт выдачи, данные для ОКУ, изменения статусов, кредитный риск портфеля |
| ФО-60…69 | бланки решения 17: опись предметов залога … РКК |
| ФО-70…74 | служебные записки решения 10 |
| ФО-75…78 | Методика №16, прил. 1–4 |
| ФО-79…89 | отдельные бланки решения 16 (выписка по кредиту — вид ФО-41, своего номера нет) |
| ФО-90 | «Письмо по кредиту», 9 видов |
| ФО-91…94 | заготовки внешних отчётов (Минфин, Кабмин, Нацстатком, банк-агент); без образца к заморозке снимаются, номер остаётся пустым |

Вычисляется скриптом: язык (внешний бланк — «рус, кырг») и ⚠ «Кыргызский текст» — 41 строка
(30 бланков и 11 видов). Вид «Просрочка свыше 60 дней» из макета в перечень не взят: основания
для него нет, это сохранённый отбор ФО-01.

## Нужно от заказчика до заморозки (⚠ в листе «Перечень»)

- образцы внешних форм для Минфина, Кабмина, Нацстаткома, банка-агента;
- состав показателей отчёта «Кредитный риск портфеля» (служба рисков);
- кыргызские тексты ≈ 30 внешних бланков;
- дата заморозки (согласуется с разработчиками).

## Проверить на шаге 2

- Часть соответствий старой системе агенты установили только по названию: «Извещение (утрата)» → ФО-33,
  «Сведения о заёмщике» → ФО-52, кнопка «Уведомление» → ФО-29. Сверить на легаси-стенде. До сверки
  в колонке «Образец-основа» у этих трёх строк старая система не указана.
- ФО-34: срок «до 1 сентября» по действующему Порядку №41 (в проекте Порядка — «до 1 июля»).
- ФО-35 и ФО-03: образец `1.pdf` подходит обоим. Подтвердить, что ФО-35 — это ФО-03 с подписями отраслевого отдела.
- ФО-90, вид «О снятии запрета на отчуждение»: Положение №12 прил. 3 называет ещё доверенность
  представителю залогодателя. Решение 16 её не упоминает — уточнить у владельца, бланк это или нет.
- ФО-38: получатель — суд (решение 18 относит суд к внешним получателям), в xlsx так и записано.
  В ТЗ 20 п. 13.55 пока «заказавший» — поправить при сокращении главы 13 (решение 19).
