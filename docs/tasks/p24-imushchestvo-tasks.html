Имущество Фонда — задачи для команды разработки

Справка модуля что модулю принадлежит и где его границы
Карта данных модель целиком: сущности, ключи, поля — карточка несёт только дельту
Опись экранов весь интерфейс модуля списком: где что живёт
Словарь слова этой постановки в её собственном значении
Сквозной пример одна квартира от предложения ПССИ до продажи в рассрочку, с числами
Открытые вопросы умолчания, на которых строим; ответ заказчика переносит в следующую редакцию

Порядок сборки — по этапам, не строгой очередью. Между этапами — барьер и приёмка пачкой. Внутри этапа карточка берётся, когда готова названная ею зависимость (значок ↔ P24-Rn) — он указывает только назад, на уже готовую карточку.

Как читать карточку. Свод наверху читается один раз: карта данных, опись экранов, словарь и сквозной пример. Карточка после этого несёт только своё — что строим, зачем, какие поля добавляются, как выглядит экран, шаги, пример с числами и приёмку. Числа во всех примерах взяты из витрины макета, имя записи стоит в строке «Источник».

Разделение источников. Модель, правила, приёмка и границы живут только здесь. Приоритет и статус исполнения — в TODO.md (реестр). Расхождение по логике модуля решает эта постановка, расхождение по виду интерфейса — макет assets.html; все числа примеров сняты с его витрины, сценарии приёмки С-1…С-34 совпадают с разделом приёмки ТЗ.

Вопросы по постановке — общий чат команды. Ответ, полученный там, попадает в карточку и журнал редакции следующего выпуска этого файла (см. «Версионирование», FORMAT.md).
