Открытые вопросы умолчания, на которых строим; ответ ГФХ переносит в следующую редакцию

Порядок сборки — по этапам, не строгой очередью. Внутри этапа карточки независимы и берутся в любом порядке; между этапами — барьер и приёмка пачкой. Зависимость (значок ↔ P16-Rn) указывает только назад — на уже готовую карточку.

Разделение источников. Модель, правила, приёмка и границы живут только здесь. Приоритет и статус исполнения — в TODO.md (реестр). Расхождение по логике модуля решает эта постановка, расхождение по виду интерфейса — макет payments.html.

Вопросы по постановке — общий чат команды. Ответ, полученный там, попадает в карточку и журнал редакции следующего выпуска этого файла (см. «Версионирование», FORMAT.md §6).
