Кураторство — задачи для команды разработки

Справка модуля модель и границы — читается один раз, не карточка

Журнал редакции что изменилось против предыдущей редакции и куда ушли снятые номера

Открытые вопросы умолчания, на которых строим; ответ ГФХ переносит в следующую редакцию

Порядок сборки — по этапам, не строгой очередью. Внутри этапа карточки независимы и берутся в любом порядке; между этапами — барьер и приёмка пачкой. Зависимость (значок ↔ P18-Rn) указывает только назад — на уже готовую карточку.

Разделение источников. Модель, правила, приёмка и границы живут только здесь. Приоритет и статус исполнения — в TODO.md (реестр). Прототип kuratorstvo.html написан по этой модели и исполняет её: при расхождении по логике права постановка, по виду интерфейса — прототип.

Вопросы по постановке — общий чат команды. Ответ, полученный там, попадает в карточку и журнал редакции следующего выпуска этого файла (см. «Версионирование», FORMAT.md).
