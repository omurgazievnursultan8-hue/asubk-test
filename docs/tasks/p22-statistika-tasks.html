Статистика — задачи для команды разработки

Справка модуля что модулю принадлежит и где его границы
Карта данных модель целиком: сущности, ключи, поля — карточка несёт только дельту
Опись экранов весь интерфейс модуля списком: где что живёт
Словарь слова этой постановки в её собственном значении
Сквозной пример одно дело взыскания от входных данных до ответа и выгрузки, с числами
Открытые вопросы умолчания, на которых строим, пока нет ответа заказчика

Порядок сборки — по этапам, не строгой очередью. Между этапами — барьер и приёмка пачкой. Внутри этапа карточка берётся, когда готова названная ею зависимость (значок ↔ P22-Rn) — он указывает только назад, на уже готовую карточку.

Как читать карточку. Свод наверху читается один раз: карта данных, опись экранов, словарь и сквозной пример. Карточка после этого несёт только своё — что строим, зачем, какие поля добавляются, как выглядит экран, шаги, пример с числами и приёмку. Числа во всех примерах взяты из демо-данных макета, имя записи стоит в строке «Источник».

Разделение источников. Модель, правила, приёмка и границы живут только здесь. Приоритет и статус исполнения — в TODO.md (реестр). Расхождение по логике модуля решает эта постановка, расхождение по механике счёта — макет statistics.html, а расхождение по физической схеме — ASUBK-statistika-fizschema.md. Форму фильтра решает постановка: экрана вопросов у модуля нет, и собирает фильтр конструктор отчётности.

Вопросы по постановке — общий чат команды; ответ, полученный там, вносится в карточку.
