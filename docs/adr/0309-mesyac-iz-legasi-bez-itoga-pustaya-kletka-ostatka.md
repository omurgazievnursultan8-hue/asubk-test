# Месяц из легаси без перенесённого итога: клетки остатков пусты «в легаси не собиралось», сдача законна

**Статус:** принято · 2026-10-17 · модуль «Отчётность», межмодульный (статистика, миграция данных) · решение
пользователя по противоречию модели `ОГ-Д12`, вскрытому волной макета 37 (вариант (а) из трёх; частные следствия —
по умолчанию, рекомендованным вариантом) · **уточняет** [ADR-0307](./0307-period-do-zapuska-zakryt-perenosom-iz-legasi.md)
п. 7 (нет данных — честный отказ, а не ноль) и границу `ИО-8` (колонка без снимка делает выпуск предварительным) ·
**опирается на** [ADR-0207](./0207-legasi-istoriya-gruzitsya-zamorozhennymi-strokami.md) (`ИС-41`: легаси-строки
окончательные, период не открывается)

**Нумерация:** максимум по `origin/main` и всем веткам — `0308` (дашборд, `origin/main`); проверено 17.10.2026.

## Контекст

`ADR-0307` п. 7 разрешает переносу объявить состав месяца — «итог на конец месяца **и (или)** события». Значит, бывает
месяц из легаси, перенесённый одними событиями, без итога. Колонка-остаток на его конец попадала под два правила сразу
(волна 37, статус-файл отчётности, `ОГ-Д12`):

- `ИО-8` (канон §3 п. 6): колонка без снимка делает выпуск предварительным. У системного месяца снимок «ещё будет», а у
  месяца из легаси — не будет никогда: форма, касающаяся такого месяца, не сдавалась бы окончательно вовсе;
- `ADR-0307` п. 7 по аналогии: величина, которой нет и не будет, — пустая клетка с причиной, сдача законна.

Макет волны 37 шёл по первому правилу: отказ «нет» в нём не отличался от «ещё нет».

Варианты владельцу: (а) итог не перенесён — все остатки месяца «в легаси не собиралось», сдача законна; (б) закрытие «по
составу»: без итога месяц закрыт для потоков и не закрыт для остатков; (в) перенос обязан давать итог каждого месяца,
«только события» — не перенесённый месяц. Принят (а).

## Решение

1. **Месяц из легаси без перенесённого итога — клетки остатков на его конец пусты с причиной «в легаси не
   собиралось».** Это второй случай `ADR-0307` п. 7 («величину не собирали»), распространённый на все остатки месяца.
   Окончательная сдача законна: число не уточнится никогда, заморозка пустоты честна. Паспорт перечисляет такие клетки.
   Потоки месяца считаются из перенесённых событий как обычно.

2. **`ИО-8` касается только месяцев, у которых снимок ещё может появиться.** «Нет» и «ещё нет» различает источник
   месяца в календаре (`origin`, `ADR-0245` §9): у месяца из легаси нет снимка навсегда, у системного — пока. Отказ
   «без снимка — выпуск предварительный» у месяца из легаси не возникает.

3. **Остаток не восстанавливается** (по умолчанию) — ни из итога соседнего месяца плюс события, ни нулём. Вычисленный
   остаток выдал бы за данные легаси число, которого легаси не давало (`ИС-41`: строки переноса окончательные, не
   пересчитываются).

4. **Месяц перед запуском обязан нести итог** (по умолчанию). Его итог — входящий остаток системы; без него системные
   остатки считать не от чего. Если перенос его не дал, этот месяц — не перенесённый (`ADR-0307` п. 7, первый случай):
   закрытым не объявляется. Это требование к миграции, а не к отчётности.

## Последствия

- **Отчётность:** канон §3 п. 6, `ИО-8` (граница), `ИО-59`, журнал §26, копия `docs/logika/16-otchetnost.md`; ТЗ 20 §18
  (`ИО-59`); `P23` — перечень инвариантов. Макет — следующей волной: месяц стенда, перенесённый одними событиями, клетки
  остатков пусты с причиной, окончательная сдача проходит, `ИО-8` у такого месяца не срабатывает.
- **Миграция данных:** итог месяца перед запуском обязателен; без него месяц не перенесён. Состав остальных месяцев —
  как в `ADR-0307`.
- **Статистика:** шов на конец месяца из легаси без итога отвечает «нет навсегда» (отсутствующее с признаком «из
  легаси»), а не «ещё нет» — чтобы отчётность не держала выпуск предварительным.

## Отвергнуто

- **(б) Закрытие по составу.** Источник перестаёт быть свойством месяца, в календаре появляется закрытие по сорту
  показателя; колонка-остаток на такой месяц навсегда предварительная — ровно то, от чего отказались в `ОГ-Д11`.
- **(в) Итог каждого месяца обязателен, «только события» — не перенесённый месяц.** Если легаси не хранило итога за
  месяц, месяц выпадает целиком и уносит потоки, которые в легаси были.
- **Восстановить остаток из соседнего итога и событий.** Выдаёт вычисленное за перенесённое; при неполных событиях —
  тихо неверное число.
