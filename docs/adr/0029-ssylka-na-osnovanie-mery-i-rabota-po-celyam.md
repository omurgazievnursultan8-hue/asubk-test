# Мера ссылается на породившую её меру; предусловия и сторно работают по каждой цели отдельно

**Статус:** принято · 2026-07-29 · модуль «Взыскание задолженности» · уточняет
[ADR-0021](./0021-rekvizity-mery-v-razreze-trebovaniya.md) и
[ADR-0026](./0026-zhurnal-mer-edinstvennyy-istochnik-sostoyaniya.md)

[ADR-0026](./0026-zhurnal-mer-edinstvennyy-istochnik-sostoyaniya.md) выразил взаимосвязь мер
только предусловиями: «повторная претензия требует, чтобы первичная была вручена», «ИЛ требует,
чтобы решение вступило в силу». Проверка при регистрации проходит — но **какая именно** мера её
открыла, нигде не остаётся. Сама мера при этом бьёт по нескольким требованиям
([ADR-0002](./0002-vzyskanie-edinica-raboty.md)), и по каждой цели условия разные.

Решено, четыре правила:

1. **У меры — одна ссылка «на основании меры» (0..1).** Заполняется при регистрации выбором из
   набора, который назвало предусловие: ИЛ → своё решение суда, повторная претензия → первичная,
   апелляционная жалоба → обжалуемое решение. **Тип связи не хранится** — он выводится из вида
   меры: постановление апелляции по своей природе относится к тому, на что сослалось.
2. **Ссылка ведёт на меру целиком, а область действия — пересечение целей.** ИЛ с одной целью,
   сославшийся на решение с тремя, касается только своей; апелляция с одной целью снимает
   присуждённое по одной строке связи, две другие живут. **Пустое пересечение — дефект
   регистрации**, и предусловие обязано его ловить.
3. **Сторно работает построчно — по цели.** Строка связи «мера × требование» помечается
   сторнированной со своим основанием; мера и остальные цели не затронуты. Сторно **всей** меры
   сохраняется отдельно — для случая, когда ошибочен сам документ. Свёртка читает оба условия:
   мера не сторнирована **и** её строка по этому требованию не сторнирована.
4. **Предусловия проверяются по каждой цели отдельно.** Непрошедшая цель в состав меры не
   входит, причина по ней называется текстом; по прошедшим мера регистрируется.

## Почему

**Ссылка.** Без неё невыразим объект [ADR-0013](./0013-zachet-platezha-i-sloy-resheniya-suda.md):
слой долга **есть** «часть долга, втянутая в конкретное решение суда». Слой обязан адресовать
меру-решение, иначе «конкретное» — фикция, а слоёв по одному кредиту несколько, и это норма.
То же с исполнительным листом: он выдан по решению, а не по требованию вообще.
Тип связи отдельным полем — производная от вида меры, запрещённая
[ADR-0001](./0001-proizvodnye-ne-hranyatsya.md): вид «Постановление апелляционной инстанции» с
исходом «решение отменено» уже говорит всё, а поле `отменяет` можно с ним рассинхронизировать.
Множественность ссылок не нужна: предусловие с двумя фактами (ИЛ выдан **и** денежное исполнение
безрезультатно) имеет один документ-основание — второй факт документом не является.

**Ссылка на меру, не на строку.** Документ ссылается на документ: ИЛ называет решение суда, а не
«решение в части договора №5». Пересечение целей даёт ту же разрешающую способность, что ссылка
со строки, но без второго места, где цели могут разойтись — со строки можно сослаться на
требование, которого нет среди целей самой меры.

**Сторно по цели.** Прямое следствие [ADR-0021](./0021-rekvizity-mery-v-razreze-trebovaniya.md):
всё, что различается по требованию, живёт на связи, а ошибочность адресации именно этим и
различается. Сторно всей меры показало бы в журнале отзыв иска, которого не было: иск подан,
госпошлина уплачена, суд принял.

**Предусловия по цели.** Это зеркальная половина уже принятого КР-10 («решение по договору А не
открывает действие по договору Б»): непригодность договора В не должна запрещать действие по А
и Б. Ровно эту ошибку [ADR-0026](./0026-zhurnal-mer-edinstvennyy-istochnik-sostoyaniya.md)
вычистил из поручения Председателя Правления, где одно поручение открывало иск по всем договорам
заёмщика. Блокировать меру целиком — та же ошибка с обратным знаком. Предупреждение вместо
блокировки отпадает: предусловие — гейт, а гейт по определению блокирует, а не советует.

## Последствия

- Предусловия расщепляются на два сорта: «требуется факт» и «требуется факт, и он даёт ссылку».
- Предусловия применяются только к мерам-**нашим документам**
  ([ADR-0027](./0027-mera-odin-dokument-pometki-rekvizity.md)); у внешних актов проверяется
  только пересечение целей.
- Форма регистрации многоцелевой меры показывает состав целей с отметкой, какая прошла
  предусловия, а какая исключена и почему.
