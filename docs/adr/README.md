# ADR — как нумеруются

Нумерация **сквозная по всему репозиторию**, не по модулям: `NNNN-slug.md`, четыре цифры.
Модуль указывается в строке статуса внутри файла («принято · дата · модуль «…»»), а не
в имени.

## Правило номера

**Номер берётся по максимуму в `main`, а не в своей ветке.** Модули пишутся параллельно, в
разных worktree, и «следующий свободный» у каждой ветки свой. Перед заведением ADR:

```bash
git fetch --all --quiet
git ls-tree -r --name-only origin/main docs/adr/ | sed 's|.*/||' | cut -c1-4 | sort | tail -1
# и то же по живым веткам соседних worktree:
git branch -a --format='%(refname:short)' | grep worktree-
```

Если соседняя ветка уже заняла номер, но ещё не влита — брать следующий за **её** максимумом.
Занять блок вперёд (например четыре номера на волну) дешевле, чем разъезжаться потом.

## Что делать при столкновении

Уступает **тот, кто закоммитил номер позже** (по времени коммита, а не по дате в шапке).
Уступивший сдвигается в свободный блок целиком, сохраняя порядок и слаги. Правятся:
файлы ADR, перекрёстные ссылки внутри них, макет и спека модуля, журнал волн, смоук,
`STATUS.md`, `TODO.md`, ТЗ и пакет передачи, если номера туда дошли.

Диапазоны в тексте («ADR `0055`…`0065`») после сдвига становятся неверными молча — их
искать отдельно: `grep -rn "00[0-9][0-9].\{0,3\}…"`.
