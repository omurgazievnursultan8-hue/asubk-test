## Контекст

Дашборд решил, как объясняет своё число (`ADR-0310`, `ДБ-234`…`ДБ-247`), какие виды добавляет в полосу (`ADR-0308`) и
кто ведёт каталог (`ДБ-200`, `ДБ-202`). По `ОД-1` всё, о чём просит плитка, — возможность отчёта. Макет отчётности
давал провал с тремя колонками (кредит · заёмщик · подразделение) и только «на дату»; в режиме «сравнение двух дат»
провала не было, у доли — список без суммы, поиска и порядка по весу не было. Соавтор общего отчёта был только
человеком, назначенным владельцем; отчёт рос по уровням и не копировался.

## Решение

1. **Список за числом сходится с числом, которое видно рядом, в любом режиме** (`ИО-60`).
   - **На дату** — объекты с ненулевым вкладом, сумма вкладов = числу (`ИО-45`).
   - **В «Изменении»** (сравнение двух дат) — форма «объекты на двух датах»: объекты, бывшие в узле на любой из дат
     (по значению разреза на свою дату), «на базу · сейчас · разница · как изменился»; сумма разниц = изменению узла;
     переход — по `ИО-58` (пришёл · ушёл по причине из записи объекта · выросло / снизилось · перешёл из соседнего
     значения разреза или в соседнее) (`ОД-17`).
   - **У доли a ÷ b** — «в числе | вся группа»: объекты a (сумма = a) или объекты b с признаком «в числе» (сумма = b)
     (`ОД-18`).
   - **Поиск** сужает показ, а не итог: «показано k из n · сумма показанных X из Y» (`ОД-19`).
2. **Колонки, подпись и порядок — из записи объекта в реестре статистики** (`ОД-15`, `ОД-16`): подпись на дату,
   4–6 объявленных колонок, разрез, не закреплённый путём, вклад; «Колонки ▾» помнится у человека на объект. Деньги —
   по вкладу с долей и чертой «80 % числа»; счёт — без «1», по весу; доля и средняя — без суммы, по весу.
3. **Рабочий список и выгрузка — показанный состав** (`ОД-20`, `ОД-21`). Имя по умолчанию — путь узла или путь
   плитки, переданный смотрящим; список — объект отчётности. Выгрузка — предварительный выпуск ключом «провал»
   (паспорт, метка, строка журнала); выше порога `statRows` — отказ с заданием статистики на выгрузку (`ADR-0178`).
4. **Контекст для карточки** (`ОД-22`): отчёт, путь, дата, вклад и доля, «k из n», соседи, адрес возврата. Плашку
   `ОГ-20` рисует карточка модуля-владельца.
5. **«Крупнейшие N» — разрез ответа** (`ОД-23`): N объектов и «остальные M», итог = сумме строк; только у
   складывающихся показателей; ранжирует статистика. **Ряд по разрезу** — форма «ответ» на списке дат с разрезом
   (`ОД-24`), в том числе «период начала» на 24 концах месяца с пустотами по причине; возраст когорты — показ.
   Переходам новой формы не нужно (`ОД-25`).
6. **Соавтор — человек или роль** (`ОД-26`, `ИО-61`): держатели роли читаются у модуля пользователей и ролей на момент
   правки; снятие роли снимает соавторство сразу.
7. **Снятие роли с владельца** общего отчёта с соавтором-ролью — уход владельца для этого отчёта: владелец — старший
   держатель роли, нет держателей — `ADR-0279` п. 6 (`ОД-27`).
8. **Принятие в каталог — копия** (`ОД-28`): предложение открывает держателям роли чтение личного отчёта автора, пока
   ждёт; «Принять» копирует его в новый общий (владелец — принявший, соавтор — роль «Администратор дашборда», круг —
   названный плюс автор, отметка «из личного отчёта <автор> ДД.ММ»); копии дальше не связаны. Проверка «похожий уже
   есть» предлагает принять на найденный общий вместо копии.

## Что меняется в ранее подтверждённом

- `ADR-0279` п. 4 и `ОГ-11`: соавтор был только человеком, назначенным владельцем; теперь — человек или роль.
- `ADR-0279` п. 6: уход владельца был увольнением или переводом; теперь ещё и снятие роли, названной соавтором.
- `ADR-0279` п. 3 и `ОГ-22`: «растёт по уровням, а не пересоздаётся», «свой вид вместо копии»; теперь у принятия в
  каталог законная копия — единственная, с отметкой источника.

## Отвергнуто

- **Список на сегодня в «Изменении»** — не сходится с числом строки. **Два раздельных списка** базы и сегодня —
  разница не сводится глазами.
- **Колонки объявляет автор отчёта** — один кредит выглядит по-разному. **Порядок по подписи** у счёта — 88 единиц
  ничего не объясняют.
- **Только числитель у доли** — знаменатель на дату не проверить.
- **Весь узел в рабочий список при поиске**; **свой список у дашборда** — второй реестр рабочих списков.
- **Отдельный журнал выгрузок дашборда**; **фоновый выпуск отчётности выше порога** — чужие строки под нашим паспортом.
- **Фильтр топ-N вместо разреза** — остальные теряются, итог не сходится.
- **Копировать держателей роли в соавторы** — снятая роль оставляет соавторство. **Особый «отчёт каталога»** — второй
  род общего отчёта.
- **Владение роли, а не человеку** — некому отвечать за архив и круг.
- **Поднять личный до общего с передачей владения** — автор теряет свой отчёт (против `ДБ-200`). **Общий у автора** —
  каталог держится на человеке без роли.
