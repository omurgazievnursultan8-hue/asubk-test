# Архив папок: учёт бумаги, папка целиком, самостоятельный модуль

## Контекст

- Официальное ТЗ (стр. 139–143, 1002–1010) описывает модуль архива документации широко: хранение электронных документов, поиск по
  метаданным, регистрация архивного документа, внесение файла, учёт места бумажного документа, запросы на бумажные варианты, обмен
  файлами между пользователями и чат.
- Сканы документов в системе уже живут у модулей, где документ создан: досье заёмщика, вложения документооборота.
- В старой системе таблица архива (кабинет, полка, колонка, ряд, папка) пуста — учёт бумаги не вёлся.
- Макет документооборота разработчикам не передан, документооборот строится по старой системе.
- Пункт меню «Архив» уже занят: «Поручительства ▸ Архив». «Архивным» называют и закрытый кредит.

## Решение

1. **Архив учитывает только бумагу.** Модуль отвечает на вопрос «где папка и у кого»: постоянное место (помещение · шкаф · ярус),
   держатель, когда взял, когда вернуть. Электронных копий у папки нет. У папки, привязанной к заёмщику, есть ссылка на его карточку.
2. **Единица учёта — папка целиком.** Принимается, выдаётся, возвращается и списывается папка; толстое дело ведётся томами
   (том = папка с той же привязкой). Отдельный документ не регистрируется, описи содержимого нет — только свободное «Содержание».
3. **Поиск по реквизитам папки:** номер, название, ИНН заёмщика, содержание.
4. **Обмен файлами и чат — не архив.** Это функция всей системы. В архиве сотрудники связываются запросом, очередью, передачей,
   просьбой о продлении и узнают о шагах из уведомлений.
5. **Архив самостоятелен.** Место и выдача бумаги ведутся только в архиве; макет документооборота не учитывается. Номенклатурное
   дело архив учитывает как папку своего вида без привязки.
6. **Вид папки решает привязку:** кредитно-залоговое дело и дела по заёмщику привязаны к заёмщику, остальное — без привязки.
7. **Карточка заёмщика показывает врезку «Где бумага»:** его папки, состояние, «Запросить»; папок нет — «не сдано». Данные отдаёт
   архив, врезку строит модуль заёмщика.
8. **Имя в меню — «Архив папок».**

## Отвергнутые варианты

- **Бумага и свои электронные копии.** Один скан жил бы и в досье, и в архиве; непонятно, какой главный.
- **Всё по ТЗ: копии, обмен файлами, чат.** Чат и пересылка файлов нужны всей системе, а не архиву; объём максимальный.
- **Учёт по документам, выдача листа из описи.** Опись каждой папки — работа, которую в архиве Холдинга никто не ведёт; выдают
  папку, а не лист.
- **Только кредитные дела** / **любая папка без привязки.** Первое оставляет без учёта протоколы и номенклатурные дела, второе
  теряет связь дела с заёмщиком.
