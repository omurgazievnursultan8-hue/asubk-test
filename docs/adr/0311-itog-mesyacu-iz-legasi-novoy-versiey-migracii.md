## Контекст

`ADR-0309` п. 1 оправдывает окончательную сдачу пустой клетки остатка на конец месяца из легаси, перенесённого без
итога, тем, что «число не уточнится никогда». `ADR-0307` п. 6 разрешает исправлять период из легаси новой версией
миграции. Вместе они не говорили, может ли новая версия **дать итог** месяцу, который первая версия перенесла одними
событиями, — например, когда позже нашёлся архив сальдо (статус-файл отчётности, `ОГ-Д13`, волна 38). Макет волны 38
такую правку отклонял заглушкой.

Варианты: (а) может — новая версия добавляет итог, клетки перестают быть пустыми, выпуски с пустотой метятся «числа
изменились после сдачи» и не переиздаются; (б) не может — состав месяца (итог / события) фиксирует первая версия;
(в) может только до первой окончательной сдачи, касающейся месяца. Принят (а).

## Решение

1. **Новая версия миграции может дать итог месяцу, перенесённому без итога.** Это та же правка перенесённого
   (`ADR-0307` п. 6): версию утверждает человек, основание обязательно, каждая добавленная строка итога ложится в
   журнал перезаписи «было: нет (итог не перенесён) → стало: …». Месяц остаётся закрытым из легаси, «открыть» у него
   по-прежнему нет; его состав по последней версии — «итог и события», с названной версией, которая дала итог.

2. **«Никогда» в `ADR-0309` п. 1–2 читается как «не появится само, прогоном системы».** Различие «нет» / «ещё нет»
   (`ИО-8`) остаётся: у месяца из легаси снимок не ждут, и выпуск из-за пустой клетки предварительным не становится —
   сдача пустоты законна и после этого решения. Но пустота не вечна: её может заменить только явное действие
   человека — версия миграции, — а не ожидание.

3. **Сданная пустота становится расхождением со сданным.** Окончательные выпуски, чей снимок касается месяца
   (периодом выпуска или колонкой-датой), пересчитываются; пустая клетка, получившая число, — расхождение, выпуск
   метится «числа изменились после сдачи: новая версия миграции …», как при перезакрытии (`ИО-34`), и не
   переиздаётся сам. Уточнить сданное можно корректирующим выпуском. Предварительные выпуски не метятся.

4. **Итог дополняется целиком** (по умолчанию). Версия даёт строку итога по каждому договору, действовавшему на
   конец месяца, со всеми величинами, которые перенос даёт в итоге (у стенда — остаток основного долга, дни
   просрочки, состояние). Частичный итог отклоняется поимённо — «не хватает строк …»: остаток портфеля по части
   договоров выдал бы себя за итог месяца (та же причина, по которой `ADR-0309` п. 3 запрещает восстанавливать
   остаток). Величину, которой нет и в найденном архиве, версия объявляет «не собиралось», клетка остаётся пустой.

5. **Симметрично — события** (по умолчанию). Месяцу, перенесённому без событий, новая версия может дать события;
   клетка «события в легаси не перенесены» получает число, выпуски метятся так же.

6. **Не перенесённый месяц версия не закрывает** (по умолчанию, `ADR-0307` п. 7 без изменений). Календарь объявляет
   выпуск миграции один раз, при запуске; версия правит и дополняет **состав объявленного месяца**, а не объявляет
   новых закрытых месяцев. Отсюда и месяц перед запуском без итога (`ADR-0309` п. 4) этим решением не спасается: без
   итога он не перенесён.

## Последствия

- **Отчётность:** канон §3 п. 6, `ИО-8` (граница), `ИО-59`, журнал §27, копия `docs/logika/16-otchetnost.md`; ТЗ 20
  §18 (`ИО-59`); `P23` — перечень инвариантов. Макет — волной 39: правка «итог июлю 2025 г. по архиву сальдо»
  проходит, пустые клетки формы «Портфель к прошлому году» получают числа, сданный выпуск метится, частичный итог
  отклоняется; заглушка `ОГ-Д13` снята.
- **Миграция данных** (постановки ещё нет): версия миграции, кроме замены перенесённых чисел, может дополнять состав
  объявленного месяца — итогом (целиком) или событиями; журнал перезаписи пишет добавление строкой «было: нет → стало».
  Новых закрытых месяцев версия не объявляет.
- **Статистика:** шов на конец месяца из легаси без итога отвечает «нет» с признаком «не появится прогоном», а не
  «нет навсегда»: после версии, давшей итог, тот же шов отдаёт строки итога. Состав месяца (`periodSource`) читается
  по последней версии и называет версию, давшую итог.

## Отвергнуто

- **(б) Не может: состав фиксирует первая версия.** Найденное число в систему не попадает никогда, хотя механизм
  правки перенесённого уже есть и честно метит сданное; «нет навсегда» держится запретом, а не природой данных.
- **(в) Может только до первой окончательной сдачи.** Правило зависит от случайности — успели ли сдать форму; после
  сдачи — (б) со всеми его потерями, до сдачи — (а) без метки, которая и так ничего не стоит. Метка `ИО-34` уже
  говорит получателю, что сданное устарело, — запрет ради неё не нужен.
- **Переиздавать выпуски с пустотой автоматически.** Сданное не переписывается (`ИО-34`); уточнение — корректирующим
  выпуском, который решает человек.
- **Дописывать итог по частям.** Остаток по части договоров — неполный портфель, выданный за итог.
