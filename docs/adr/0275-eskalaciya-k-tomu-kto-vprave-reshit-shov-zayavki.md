# Эскалация — к тому, кто вправе решить; заявка отдаёт заданиям шаги на передачах и два новых действия

**Статус:** принято · 2026-10-11 · модули «Задания», «Заявка / Комиссия по заявкам» ·
опирается на [ADR-0271](./0271-shag-dokumenta-zadanie-povod-dokument.md) (исполнение у владельца,
отпадение с атрибуцией), [ADR-0274](./0274-zakrytoe-osnovanie-programmy-zadanie-a-ne-kaskad.md)
(вычисляемая проверка «программа принимает заявки») · `ЗЗ-2`, `ЗЗ-4`, `ЗЗ-6`, `ЗЗ-13`

**Нумерация:** `0275` — следующий за `0274`, максимумом по `origin/main` и всем живым веткам.
Проверено 11.10.2026.

## Контекст

Заявка — первый сосед заданий, у которого рабочий процесс проходит через пять исполнителей
подряд (специалист → головной филиал → отделы → комиссия → оформление) и у которого есть свои
очереди дел (ТЗ 03 §7.6 «Требуют вашего действия», §9.4 «Ждут моего голоса»).

Общее правило просрочки заданий (`ЗН-16`) — на 5-й р.д. задание **руководителю исполнителя**,
который может переназначить, продлить или снять. У двух видов заявки этот адресат ничего решить
не может:

- **голос члена комиссии** — личное право члена; руководитель по должности не голосует и не
  переназначает голос. По P3-R4 #5 «Крайний срок» члена принуждается уведомлением председателю;
- **«Дополнить заявку»** — по п. 66 Типового положения (ПКМ №554) неустранённые за месяц недостатки
  ведут к отклонению проекта. Отклоняет комиссия, а по графу ТЗ 03 §3.2 из «Требуется доп.
  информация» отклонить нельзя вовсе.

Вторая дыра — отложенный из `ЗКП-4` повод: программа перестала принимать заявки (`ADR-0274`), а
поданные по ней заявки в работе. Блок `ADR-0274` закрывает только **новые** заявки; у идущей
заявки нет действия, которым её можно перевести на другую программу.

## Решение

1. **Шаги — только на передачах работы** (`ЗЗ-2`). Свой «Новый» специалист ведёт без задания;
   задания возникают, когда работа ушла к другому или вернулась: «Подтвердить комплект» (ГФ),
   «Дать заключение» (на каждый назначенный отдел), «Предварительно изучить», «Проголосовать»
   (каждому члену), «Вынести решение», «Дополнить заявку», «Сформировать кредит», «Привязать
   решение и программу», «Зарегистрировать договоры». Исполнение — в карточке заявки, задание
   отпадает сменой состояния с атрибуцией (`ADR-0271`). Очереди внутри заявки остаются контекстом
   карточки.
2. **Новый реквизит вида повода — «эскалация»:** по умолчанию общая (`ЗН-16`/`ЗН-19`); вид может
   объявить «нет» или назвать другого адресата. Эскалация уходит к тому, кто вправе решить:
   - «Проголосовать» — срок объявляет запись комиссии («Крайний срок»), просрочка — уведомление
     председателю; эскалации к линейному руководителю и переназначения нет (`ЗЗ-4`);
   - «Дополнить заявку» — срок 1 календарный месяц (п. 66 ПКМ №554); по истечении в очередь роли
     «Комиссия» — задание «Отклонить за неустранение недостатков» (`ЗЗ-13`).
3. **Два новых действия заявки:**
   - **переход «Требуется доп. информация → Отклонена»** — действие комиссии, с причиной и записью
     в аудит (`ЗЗ-13`);
   - **«Сменить программу»** — действие специалиста в «Новый» и «Требуется доп. информация»:
     выбор только из программ, принимающих заявки (`ADR-0274`), переприменение конверта условий
     и пакета документов, причина в аудит. Заявку «На рассмотрении» комиссия сначала возвращает
     (`ЗЗ-6`).
4. **Гейт на «Сформировать кредит»:** кредит не формируется по программе, которая не принимает
   заявки (та же вычисляемая проверка `ADR-0274`). Заявка до этого шага не блокируется — её
   судьбу решает задание «Перевести заявку на действующую программу или отозвать» (`ЗЗ-6`).

## Почему не иначе

- **Общая эскалация для всех видов.** Руководитель получает задание, которое не может исполнить:
  голос не переназначается, отклонять заявку не его право.
- **Автоотклонение по истечении месяца.** Решение без человека; норма говорит «подлежит
  отклонению», а не «отклоняется»; ошибку срока (праздники, документ в пути) не отыграть.
- **Довести заявку по закрытой программе.** Кредит под отменённое основание — то, от чего
  `ЗГ-6`/`ADR-0274` защищают программы.
- **Только отозвать и пересоздать клоном.** Заявитель и отделы проходят весь круг заново —
  ГФ, заключения, комиссия — ради смены одной ссылки.
- **Шаг на «Новом» и шаг на документ.** Задание на собственный черновик — шум (как `ЗГ-10`);
  десятки заданий на заявку — дробность, которую уже держит очередь §7.6.

## Последствия

- ТЗ 03 §3.2/§3.4: переход «Требуется доп. информация → Отклонена» у комиссии; действие
  «Сменить программу»; гейт «Сформировать кредит» по проверке `ADR-0274`. До правки ТЗ — долг
  модуля заявок (канона у него нет; записан в каноне заданий §13).
- Модуль заданий: реквизит вида «эскалация»; семейство заявки — 9 шагов и 3 повода по данным
  (`ЗЗ-5`). Сроки, кроме нормы п. 66, — позиция проекта на подтверждение заказчику (`ЗЗ-12`).
- Запись комиссии отдаёт в ответе «Крайний срок» члена и состав с ролями (председатель).
