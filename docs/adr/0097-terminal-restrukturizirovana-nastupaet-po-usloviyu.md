# Терминал «Реструктурирована» наступает по условию, а веха регистрируется всегда

**Статус:** принято · 2026-08-05 · модуль «Реструктуризация» · правит
[ADR-0053](./0053-terminaly-i-universalnaya-proverka-trekov.md) · соседствует с
[ADR-0044](./0044-karantin-zakrytiya-dela.md) и
[ADR-0063](./0063-pauza-priostanavlivaet-predmet-a-ne-zhurnal.md) · дополняет `CONTEXT.md`
(«Терминальный исход»)

Допсоглашение покрыло один транш из трёх; по двум другим просрочка жива, и работа по
требованию продолжается. Терминальный исход «реструктурирована» закрыл бы требование, по
которому есть что взыскивать, — и закрыл бы навсегда: терминал есть конец маршрута.

## 1. Веха — всегда, терминал — по условию

Каждое зарегистрированное допсоглашение даёт акт журнала мер об утверждении
реструктуризации. Терминальным исходом этот акт становится только тогда, когда по кредиту не
осталось **непокрытой просрочки** — то есть когда ДС закрыл всё, из-за чего требование
открывалось.

## 2. Условие выводится, а не отмечается

Непокрытая просрочка считается по кредиту после применения ДС: наступившие и неоплаченные
взносы всех траншей, включая оставшиеся на прежних условиях. Галочки «это полная
реструктуризация» нет — она разъехалась бы с расчётом при первой же частичной сделке.

## 3. Не наступил — взыскание идёт с сохранённой фазы

Пауза снимается, фаза восстанавливается свёрткой
([ADR-0063](./0063-pauza-priostanavlivaet-predmet-a-ne-zhurnal.md): пауза приостанавливает
предмет, а не журнал), работа продолжается. Промежуточного состояния «частично
реструктурирована» не заводится: частичность видна разбивкой долга, а состоянием требования
не является.

## 4. Общие правила закрытия не отменяются

Универсальная проверка треков ([ADR-0053](./0053-terminaly-i-universalnaya-proverka-trekov.md) §2)
и карантин закрытия дела ([ADR-0044](./0044-karantin-zakrytiya-dela.md)) применяются к этому
терминалу как ко всем прочим: выполненного условия мало.

## Отвергнуто

- **Терминал по факту регистрации ДС** — закрывает требование, по которому продолжается
  работа, и делает это необратимо.
- **Отдельный терминал «частично реструктурирована»** — состояние не терминальное: по нему
  ведётся взыскание.
- **Ручная отметка полноты** — расходится с расчётом, и разойдётся молча.

## Последствия

- Один ДС по кредиту с двумя требованиями закрывает то из них, чью просрочку он покрыл, и не
  трогает второе.
- Подгруппа заёмщика меняется только у закрытых требований: у терминалов старшинство
  (`CONTEXT.md`, «Подгруппа»).
- Категория риска реструктуризацией не гасится. Дни просрочки обнуляются **датой вступления
  ДС** и не раньше, а фактор категории держится своим сроком и снимается только решением
  комитета ([ADR-0065](./0065-faktor-kategorii-dvigaet-tolko-resheniem-komiteta.md)).
