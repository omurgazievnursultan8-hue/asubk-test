# Итоги шире зоны видимости — отдельное право; просмотр строк объектов пишется в журнал

**Статус:** принято · 2026-10-11 · модуль «Отчётность» · решение пользователя в гриллинге модуля с корня ·
**уточняет** [ADR-0152](./0152-tri-shva-po-voprosu-i-oblast-vidimosti.md) §3 (агрегат считается только по видимым —
правило по умолчанию; исключение — названное право) · опирается на
[ADR-0230](./0230-granicy-podsistemy-uvedomleniya-vnutri-audit-i-chislo-snaruzhi.md) (аудит — свойство каждого
модуля) · `ОГ-7`, `ОГ-33`

**Нумерация:** блок `0279`–`0288`, проверено 11.10.2026.

## Контекст

Строки и итоги отчёта режутся областью видимости (`ADR-0152` §3, канон §13 п. 2). Для анализа это оставляет без
ответа главный вопрос оценки: «14,2 % просрочки в моём районе — это много?» Без строки «Ошская в целом» и «по
стране» число ни о чём не говорит. Если система не даёт сравнения, его присылают из головного офиса в Excel или в
мессенджере — данные уходят всё равно, но мимо контроля.

Второй вопрос — след. Выгрузки и сдачи пишутся в журнал (`ОГ-14`, `ОГ-16`), а просмотр списка из двух тысяч
заёмщиков с ФИО и суммами — такой же доступ к данным, только без файла. ТЗ требует «детального аудита всех действий
пользователя».

## Решение

1. **По умолчанию строго (`ОГ-7`).** Отчёт не показывает ни одного числа за пределами зоны видимости.

2. **Право «итоги шире зоны».** Выдаётся ролям, которым сравнение нужно (начальникам филиалов, кураторам, аналитикам
   головного офиса — состав подтверждает заказчик). С правом за пределами зоны видны **только итоги**:
   - без строк объектов и без провала (`ADR-0280` §5);
   - уровень не мельче объявленного (например, «область»);
   - в группе не меньше N объектов (например, 5); иначе ячейка — «скрыто».

   Официальная сдача на это право не опирается: окончательно сдаёт тот, за кем обязательство (`ИО-25`).

3. **Журнал просмотров (`ОГ-33`).** Пишется каждый показ, где видны **строки объектов** — отчёт-список, провал,
   рабочий список: кто, какой отчёт, фильтры, дата состояния, число строк, когда. Показы одних итогов не пишутся:
   персональных данных в них нет, а миллион записей «переставил разрез» никто не прочтёт. Журнал читает служба
   безопасности или администратор; пользователь видит свою историю как «Недавние отчёты». Срок хранения —
   требование безопасности заказчика (на подтверждение).

## Отвергнуто

- **Строго для всех.** Сравнение со средним уходит в Excel и мессенджеры, где защиты нет вовсе.
- **Итоги шире для всех.** Не каждой роли нужна страна, а без запрета мелких групп итог раскрывает заёмщика.
- **Писать всё.** Важное тонет в шуме движений настройки.
- **Писать только выгрузки.** При утечке нельзя установить, кто видел строки.

## Последствия

- Канон: §13 пп. 8–9; заведены `ИО-48`, `ИО-55`.
- Пользователи и роли: право «итоги шире зоны» с параметрами «уровень не мельче» и «N» — долг модулю пользователей.
- Глоссарий: «Итоги шире зоны».
