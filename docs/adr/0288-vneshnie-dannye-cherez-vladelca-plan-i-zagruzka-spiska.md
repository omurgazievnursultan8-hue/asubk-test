# Внешние данные входят через владельца: справочник плановых показателей и загрузка рабочего списка по номерам

**Статус:** принято · 2026-10-11 · модули «Отчётность», «Статистика», «Дашборд» (межмодульный) · решение
пользователя в гриллинге отчётности с корня · **частично переигрывает** `ДБ-23`
([ADR-0278](./0278-dashbord-obzor-i-ochered-segodnya-po-umolchaniyu-vynos-so-shtampom.md) п. 2: «цели сверху —
только лимит кредитной программы») — на сверку с дашбордом · **подтверждает** там же: внешние данные входят импортом
модуля-владельца, а не в плитку · опирается на [ADR-0150](./0150-pokazatel-obyavlennyy-istochnik-a-ne-formula.md) ·
`ОГ-32`

**Нумерация:** блок `0279`–`0288`, проверено 11.10.2026.

## Контекст

Анализу постоянно нужно то, чего в кредитной системе нет. План сбора на год по областям утверждают на совещании и
держат в Excel; «% выполнения» считают там же. Минфин присылает перечень из 120 договоров «под проверку» и просит
остатки и просрочку по ним. ТЗ (§5.3) упоминает «интеграцию с внешними источниками (API, базы данных, Excel)»; канон
внешние источники запрещал. `ДБ-22`/`ДБ-23` свели план-факт к «ожидалось по графику» и «Плану» кредита, а цели
«сверху» — к лимиту программы.

## Решение

1. **План — справочник «Плановые показатели» с владельцем.** Годы × области × программы (разрезы — из реестра);
   владелец — подразделение, утверждающее план (например, планово-экономический отдел, подтверждает заказчик).
   Загрузка из Excel **по шаблону**, с проверкой разрезов. Загруженный план становится обычным показателем реестра:
   в отчёте рядом «план», «факт» и своей формулой «% выполнения».
2. **Внешний перечень — рабочий список по номерам.** Загрузка списка номеров договоров сопоставляет их с объектами:
   «118 найдено, 2 не найдены: …» поимённо. Дальше это обычный рабочий список (`ОГ-21`): фильтр в любом отчёте,
   выгрузка, отметки.
3. **Отчёт ничего не подклеивает сам.** Произвольный Excel пользователя к отчёту не присоединяется.

## Отвергнуто

- **Свой Excel к отчёту.** У трёх людей три плана; чужое число в отчёте выглядит как данные системы; склейка по
  названиям («Ошская» / «Ошская обл.») молча теряет строки.
- **Внешних данных нет.** План-факт — один из главных вопросов руководства; без него «% выполнения» живёт в Excel.

## Последствия

- Статистика: объект или показатель «план» с владельцем справочника — долг статистике и справочникам.
- Дашборд: `ДБ-23` пересмотреть вместе с этим решением — долг дашборду.
- Канон отчётности: §9 (загрузка списка), §11; заведён `ИО-54`.
