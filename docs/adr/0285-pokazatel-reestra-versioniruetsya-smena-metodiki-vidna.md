# Показатель реестра версионируется; смена методики видна в отчётах

**Статус:** принято · 2026-10-11 · модули «Отчётность», «Статистика» (межмодульный) · решение пользователя в
гриллинге отчётности с корня · опирается на [ADR-0150](./0150-pokazatel-obyavlennyy-istochnik-a-ne-formula.md)
(показатель — объявленный источник), [ADR-0177](./0177-obratnye-ssylki-hranit-vladelec-reestra.md) (обратный индекс
потребителей), [ADR-0175](./0175-zapis-fiksacii-neset-redakciyu-svoey-formy.md) · `ОГ-24`

**Нумерация:** блок `0279`–`0288`, проверено 11.10.2026.

## Контекст

На один показатель реестра опираются десятки отчётов: личные, общие, официальные, виды, подписки, сигналы,
плитки. Пример: с 1 ноября получатель требует считать «просроченную задолженность» без пени. Если показатель
меняется молча, в ноябре «просрочка упала на 4 %», руководство радуется, а ушла пеня; официальная форма уходит по
новой методике, хотя её утверждали по старой. Если же каждый отчёт хранит копию определения, через год в системе
пятнадцать «просрочек».

## Решение

1. **У показателя — версии с датами действия и основанием.** «Версия 1 до 31.10.2026 — с пеней; версия 2 с
   01.11.2026 — без пени (основание: письмо …)». На прошлые даты действует версия, действовавшая на дату.
2. **Смена видна везде, где показатель используется.** В шапке каждого зависимого отчёта — «показатель изменён
   ДД.ММ: что». Сравнение и динамика через дату смены помечены «методика изменилась между датами — сравнение
   некорректно».
3. **Официальные формы не переключаются молча.** Уполномоченный получает уведомление «показатель формы изменился —
   подтвердите новую редакцию»; до подтверждения форма помечена «ожидает решения по методике».
4. **Сданное не трогается.** Выпуск заморожен; паспорт хранит, по какой версии показателя он посчитан.
5. **Переименование доходит само**: отчёты ссылаются на показатель, а не на название.
6. **Удалить показатель с потребителями нельзя** — его выводят из обращения, держатели зависимых отчётов
   предупреждены (обратный индекс, `ADR-0177`).

## Отвергнуто

- **Изменение молча доходит везде.** Смена правила читается как событие в портфеле; официальная форма меняет
  методику без решения.
- **Каждый отчёт хранит копию определения.** Пятнадцать «просрочек»; исправление ошибки до отчётов не доходит.

## Последствия

- Статистика: версия показателя с датами действия и основанием; выбор версии по дате среза; признак смены в ответе
  шва — долг статистике.
- Канон отчётности: §4 (неисполнимая редакция — читается вместе с п. 3), §11; заведён `ИО-47`.
