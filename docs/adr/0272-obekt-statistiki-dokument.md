# Объект статистики «документ»; показатели ТЗ по документообороту считаются от действующего срока

**Статус:** принято · 2026-10-10 · модули «Документооборот» и «Статистика» ·
**пересматривает** [ADR-0149](./0149-obekt-statistiki-parametr-reestra-a-ne-vetka-koda.md) §4 ·
опирается на [ADR-0222](./0222-chislo-na-datu-u-statistiki-zhivoy-rekvizit-u-objectrows.md)
(датированное число — у статистики), [ADR-0230](./0230-granicy-podsistemy-uvedomleniya-vnutri-audit-i-chislo-snaruzhi.md)
(`ИЗ-15`) · исполняет ТЗ 711–721 · `ДО-26`, `ДО-43`

## Контекст

ADR-0149 §4 объявил документооборот отсутствующим и обещал: «Появится модуль — появится запись
реестра». Модуль появился (ADR-0265). ТЗ 711–721 требует десять показателей: документы по
видам, в работе, просроченные, исполненные в срок и с опозданием, отказы, процент исполнения.
В старой системе просрочку не считало ничего (легаси §6).

## Решение

1. **Запись реестра объектов — «документ».** Множество определяет документооборот. Одна строка
   на документ на дату. Разрезы: вид · тип · этап · подразделение автора · вид отправителя ·
   исполнитель · месяц регистрации · из старой системы.
2. **Резолюция отдельным объектом не заводится.** Показатели ТЗ — о документах. Объект
   «резолюция» дал бы второй счётчик той же работы рядом с заданиями.
3. **«Исполнен в срок»** — относительно действующего срока с учётом продлений. Отдельная строка —
   «из них с продлением». Срок и продление берутся у заданий по поводу «исполнить резолюцию».
4. **Дата исполнения:** для «требует ответа» — дата отправки ответа; иначе — дата исполнения
   последней резолюции верхнего уровня.
5. **«Отказано в исполнении»:** резолюция верхнего уровня «Отказать» или окончательный отказ
   подписанта (черновик удалён автором после отказа). Возврат на доработку отказом не считается.
6. **Аннулированные — отдельной строкой,** в остальные показатели не входят.

## Почему не иначе

- **Витрина показателей в документообороте.** Второй способ посчитать то же; ADR-0149 запрещает
  витрины по модулям.
- **«В срок» по первоначальному сроку.** Продление, утверждённое руководителем, превращается в
  просрочку, и сотрудники перестают просить продление и начинают закрывать формально.

## Последствия

- Статистике: запись реестра и затравка макета. Объектов теперь больше пяти, ADR-0149 п. 2
  читается вместе с этим решением.
- Документообороту: шов отдаёт множество документов на дату с реквизитами для разрезов.
