# Разрез не теряет объектов — полный список значений, «пусто» по имени, все строки всегда

**Статус:** принято · 2026-10-16 · модуль «Дашборд» · решение пользователя в гриллинге дефектов волны 7 · **уточняет**
[ADR-0296](./0296-polosa-odna-stroka-vidy-strokami-summa-izmenenie.md) п. 4 в части порядка разреза в «Изменении»
(`ДБ-153`) · опирается на [ADR-0176](./0176-razrez-neset-urovni-i-korziny.md) §5 (итог родителя считается по
строкам, объект с незаполненным уровнем не пропадает) и [ADR-0293](./0293-plitka-odna-osnova-pyat-vidov-v-polose.md)
(виды в полосе) · `ДБ-167`…`ДБ-170`, `ДБ-173`

**Нумерация:** максимум по `origin/main` и по всем веткам (`git log --all` по `docs/adr/`) — `0300` (дашборд);
проверено 16.10.2026.

## Контекст

Ревью волны 7 макета (15.10.2026) нашло, что сумма строк разреза не равна итогу в 25 из 518 разрезов (`ДБ-Д39`).
Макет строит строки по объявленному списку значений разреза и отбрасывает два рода объектов:

- **значение не объявлено в списке.** Руководство → «Остаток задолженности» → Разрез по «Срок просрочки» показывает
  852 из 3 856 млн: в списке 1–30 · 31–90 · 91–180 · 181+ нет кредитов без просрочки. Так же пропадают заявки со
  статусом «Закрыта» и обязательства с итогом «ожидается»;
- **значения нет вовсе — признак к объекту не применим.** Категория у закрытого кредита («Выдано с начала года» по
  категории — 309 из 351 млн), решение у заявки на рассмотрении (0 из 18), стадия новой заявки у не новой.

Итог считается по всем объектам и верен, строки с ним не сходятся. Дописать недостающие значения в список мешало
правило канона: упорядоченный разрез печатает все объявленные значения, и у «Просрочено» по сроку встала бы строка
«нет просрочки 0».

У уровней разреза статистика это уже решила (`ИС-24`, `ADR-0176` §5): кредит с областью и без района попадает в
область и не пропадает. У плоского разреза такого правила не было.

## Решение

1. **Объект разреза не пропадает: итог равен сумме строк** (`ДБ-167`, `ИДБ-18`). Каждое значение — своя строка;
   объект без значения — тоже в строке (п. 3).
2. **Список значений разреза полный и ведётся статистикой** (`ДБ-168`). Список в реестре (`ИС-23`) покрывает все
   значения поля: у «Срока просрочки» первая корзина — «нет просрочки» (нет просрочки · 1–30 · 31–90 · 91–180 ·
   181+), у статусов — весь справочник. Значение, которого в списке всё же нет (справочник пополнили раньше
   реестра), печатается строкой после объявленных. Это сигнал реестру, а не норма.
3. **«Пусто» — последнее значение списка со своим именем** (`ДБ-170`). Где признак к части объектов не применим,
   статистика объявляет пустое значение последним и называет его по смыслу: «нет решения», «нет категории», «не
   новая», «нет исхода». Где пусто невозможно (область кредита), такого значения нет.
4. **Строки разреза — все объявленные значения, всегда, нули тоже** (`ДБ-169`). У «Просрочено» по сроку печатается
   «нет просрочки 0», у пустой корзины — «0 · ☰ 0». Неупорядоченный разрез — так же, нулевые строки уходят вниз и в
   «ещё N»; Карта — то же по обеим осям.
5. **Упорядоченный разрез держит свой порядок и в «Изменении»** (`ДБ-173`). Разница рисуется полосой влево и вправо
   от нуля в своей строке; так же в Таблице. Неупорядоченный разрез в «Изменении» — от роста к падению, как было
   (`ДБ-153`).

```
Остаток задолженности · Срок просрочки        На рассмотрении · Решение
нет просрочки   3 004 млн                     Положительное    0
1–30              412                         С условиями      0
31–90             226                         Отрицательное    0
91–180            128                         нет решения     18
181+               86                         Итого           18
Итого           3 856 млн
```

## Последствия

- **Статистике** — заявка: дописать списки разрезов до полных (корзина «нет просрочки» у срока просрочки и у худшей
  просрочки заёмщика; «Закрыта» у статуса заявки; «ожидается» у итога сдачи) и объявить «пусто» со своим именем у
  разрезов, где признак применим не ко всем объектам (категория у кредита, решение и вердикт у заявки, стадия новой
  заявки, исход обращения о реструктуризации).
- **Макет дашборда** — следующей волной: строки по полному списку, «пусто» последним, нули печатаются, порядок
  упорядоченного разреза в «Изменении» и Таблице. Проверка смоука №246 (ровно четыре корзины у «Просрочено»)
  меняется: корзин пять, первая — «нет просрочки 0».
- **Отчётность** показывает те же разрезы; правило полного списка у статистики общее для обоих потребителей.

## Отвергнутые варианты

- **Одна строка-остаток «вне разреза»** (итог минус сумма строк). Итог сходится, но не видно, что за объекты, — тот
  же изъян, что у «прочего» в Движении (`ДБ-Д43`).
- **Отказ разреза, у которого есть объекты вне списка.** Главный разрез «Остатка» по сроку просрочки стал бы
  недоступен.
- **Список только «интересных» значений, остальные — в конец.** «Нет просрочки» встала бы после «181+», порядок шкалы
  потерял бы смысл.
- **Строки от первой до последней со вкладом, пустые внутри — нулём** (рекомендовался). Шкала без дыр и без нулей,
  которые нули всегда, но пустой край шкалы («181+ 0») не печатается. Владелец выбрал печатать всю шкалу.
- **Только строки со вкладом.** Пустая корзина внутри шкалы пропадает незаметно.
- **Общая строка «без значения»** — только когда такие объекты есть (строка то есть, то нет) или у всех разрезов
  всегда («без значения 0» и там, где пусто невозможно).
- **Упорядоченный разрез в «Изменении» — по разнице.** Сроки встают вперемешку.
