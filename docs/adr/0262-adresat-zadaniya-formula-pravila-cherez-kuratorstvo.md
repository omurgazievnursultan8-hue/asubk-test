# Адресат задания — формула правила через кураторство, а не названный сотрудник

**Статус:** принято · 2026-10-05 · модуль «Задания» · снимает временную жёсткую адресацию
поводов соседей (`E4`, волны 2–4) · опирается на [ADR-0228](./0228-tri-reestra-vid-povoda-deystvie-pravilo.md)
(три реестра), [ADR-0227](./0227-zadanie-est-para-povod-deystvie-ishod-vyvoditsya.md)
(снимок условий на момент выдачи), [ADR-0259](./0259-kuratorstvo-rasshireno-imushchestvom.md)
(кураторство по имуществу) · `ЗН-1`, `ЗН-2`, `ЗН-6`, `ИЗ-18`, `ИЗ-19`, `ИЗ-23`

**Нумерация:** `0262` — следующий за `0261`, максимумом по всем веткам. Проверено 05.10.2026.

## Контекст

Волны 2–4 подключили три соседа, но все их поводы уходят администратору модуля: в ответе
маршрутизации сотрудников не было реквизита «руководитель исполнителя на дату», а адресат,
которого нет, дал бы задание, невидимое никому. Хардкод был объявлен временным.

С тех пор кураторство отвечает «кто ведёт объект на дату» по заявке, кредиту, предмету залога,
требованию, а теперь и по предложению и объекту имущества. Сотрудники отвечают «кто действует
вместо него» и «кто его руководитель».

## Решение

1. **Адресат — формула в правиле, вычисляется на дату выдачи.** Правило называет **роль
   кураторства** по объекту повода; для объекта без кураторства (подразделение, обязательство
   по форме, вид повода) — подразделение или должность.
2. **Действующего при замещении называют Сотрудники.** Ответственный остаётся закреплённым,
   работу получает действующий.
3. **Цепочка запасных адресатов:** закрепления нет → руководитель подразделения-владельца вида
   повода → администратор модуля. Падение на администратора само есть повод самоопроса
   «адресат не найден» — хардкод перестаёт быть тихим.
4. **Адресат — снимок на момент выдачи** (как и прочие условия работы, `ИЗ-9`).
5. **Смена закрепления переадресует только непринятое.** Задание в состоянии «поручено»
   переезжает к новому ответственному событием «переадресовано»; принятое в работу остаётся у
   исполнителя, новый ответственный получает видимость. Видимость получает пятое основание —
   ответственный по кураторству на дату.
6. **Переназначение — решение человека.** Автор или руководитель исполнителя по цепочке, в любом
   нетерминальном состоянии, с основанием. Исполнитель сам не передаёт — у него есть отказ.
   Установленный срок при переназначении не обнуляется.

## Почему не иначе

- **Фамилии в правиле** — вторая таблица ответственных рядом с кураторством, расходящаяся при
  первой ротации.
- **Администратор-диспетчер** — хардкод, ставший нормой; эскалация «руководителю исполнителя»
  вырождается, потому что исполнитель всегда один.
- **Задание всегда следует за текущим куратором** — выдёргивает начатую работу посередине.
- **Задание навсегда у снимка** — при ротации повисают десятки чужих заданий.

## Последствия

- Сотрудникам: реквизит «руководитель исполнителя на дату» в ответе маршрутизации.
- Кураторству: ответ «ответственный по роли на дату» для всех объектов закрепления.
- Хардкод `E4` в трёх видах повода снимается при сборке макета.
