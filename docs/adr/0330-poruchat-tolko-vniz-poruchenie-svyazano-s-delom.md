# Поручать можно только вниз; поручение связано с делом

**Статус:** принято · 2026-11-04 · модуль «Задания» · в шапке называет соседей: документооборот, анализ, навигацию ·
уточняет `ADR-0276` (`ЗА-2`, подстановка куратора) · гриллинг 03–04.11.2026, решения `ЭЗ-13`, `ЭЗ-14`

## Контекст

Кому можно давать свободное задание, раньше не решалось, ТЗ порядка не задаёт. В макете любой из 39 сотрудников поручал любому, хотя
подчинённые есть у 14 из 39, а все четыре поручения в данных идут вниз. Объект указывается только при поручении по обзору: у всех четырёх
поручений дело названо только в тексте, ссылки и поиска нет. ТЗ, стр. 1051, требует видеть объекты задания.

## Решение

1. **Кнопка «Поручить» только у руководителей, исполнитель — подчинённый по цепочке.** Замещающий поручает за руководителя. Просьба в другой
   отдел идёт через общего руководителя или служебной запиской в документообороте.
2. **Необязательное поле «Дело»:** поиск по заёмщику, заявке, кредиту, залогу и взысканию; можно указать несколько или ни одного. В строке
   первое дело со ссылкой и «ещё N»; задание видно в карточке дела.
3. **Подстановка куратора в поручении по обзору** работает, только если он подчинённый автора; иначе автор выбирает сам.
4. Контролёр по умолчанию автор, можно заменить. Срок обязателен и не подставляется. Поля важности нет.

## Последствия

- Нужен общий поиск по делам: долг навигации и соседям.
- Анализ: автор поручения по обзору не всегда может поручить куратору объекта.
- Отказ ставить задание вверх или вбок делает служебную записку единственным формальным путём для просьбы в другой отдел.

## Отвергнутые варианты

- **Вниз и руководителям других подразделений:** задание идёт вверх, нужно правило «кто кому равен».
- **Любому:** кнопка у всех, задания без права спросить.
- **Обязательное поле «Дело»:** не всякое поручение относится к делу.
- **Только текст:** нет ссылки и поиска.
