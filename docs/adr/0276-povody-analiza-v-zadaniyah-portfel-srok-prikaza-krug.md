# Поводы анализа в заданиях: период закрывает обзор портфеля, срок — из приказа, адресат — внутри круга

опирается на [ADR-0250](./0250-porucheniya-po-obzoru-zhivut-v-zadaniyah.md) (поручения по обзору

## Контекст: два вида повода объявлены, но не доведены до задания

`ADR-0251` объявил, что анализ отдаёт заданиям два вида повода: «обзор требует решения, поручений
нет» и «обзора за период нет». Подключение к движку заданий показало, что объявление отвечает на
вопрос «что входит в множество» и не отвечает на пять других.

- **Что гасит повод.** Ключ «шаблон × период», но обзор хранит ещё закреплённые значения разрезов.
  В квартале по одному шаблону законно бывает несколько обзоров (`ИА-34`). Если повод гасит любой,
  приказ «анализ портфеля ежеквартально» исполняется обзором по одной области.
- **Чем гасится «поручений нет», когда поручать нечего.** Если только поручением, то при
  отсутствии нужды в нём руководитель заведёт фиктивное, и это обход `ИА-11`.
- **Откуда срок.** Приказ, объявивший периодичность, почти всегда объявляет и срок. Если срок живёт
  у правила заданий, новый приказ исполняет администратор чужого модуля.
- **Замена обзора.** Ключ «поручений нет» — номер обзора. Поручения по заменённому заменяющему
  либо засчитываются, либо нет, и выбор нужно сделать.
- **Адресат вне круга.** Адресат видимости не меняет (`ИА-24`, `ADR-0252` §4). Обзор, направленный
  подразделению вне круга шаблона, рождает задание по документу, который его исполнитель не может
  открыть.

## Решение

**1. Рамка.** Для заданий анализ — источник двух поводов и основание свободных поручений. Оба вида
подключаются записями трёх реестров (`ADR-0228`). Свободное задание получает реквизит «основание»,
а задания отдают шов «задания по основанию». Особого типа «поручение по обзору» нет: это был бы
второй путь выдачи рядом со свободным заданием (`ЗА-1`).

**2. Поручение по обзору — свободное задание.** Исполнителя называет автор. Форма подставляет
куратора объекта на дату, автор вправе заменить его. Контролёр — автор (`ЗА-2`).

**3. «Поручений нет» гасит поручение или решение «без поручений».** Шов «задания по основанию»
считает только поручения. Первое поручение даёт «исполнено» с атрибуцией. Поручать нечего — адресат
закрывает «снято: решение без поручений» с обязательным основанием, и ключ не переиздаётся, пока
жив (`ЗН-14`, `ЗА-3`).

**4. Период закрывает только обзор по всему портфелю.** Повод «обзора за период нет» гасит
утверждённый обзор по шаблону за период **без закреплённых значений разрезов**. Обзор по области
остаётся законным документом, но период не закрывает: п. 6.7 Порядка говорит об анализе «по
портфелю бюджетных кредитов». «Поглощение периодом» — **нет**: пропущенный период следующим
обзором не прощается (`ЗА-11`, `ЗН-10`).

**5. «Обзора за период нет» — заведующему отделом анализа.** Это запасная ветка формулы правила для
объекта без кураторства: подразделение-владелец → его руководитель. Основание — п. 8 Порядка:
организация мониторинга на заведующих отделами (`ЗА-13`, **переигрывает `ЗА-5`** — очередь роли «Сотрудник отдела анализа», принятую параллельной веткой той же сессии; владелец подтвердил при слиянии 11.10.2026). Эскалация — по `ЗН-16` вышестоящему заведующего, а не по `ЗН-19`. «Поручений нет» уходит руководителю
названного адресата (`ADR-0252` §3).

**6. Срок «обзора за период нет» — из приказа, полем шаблона.** Рядом с периодичностью и ссылкой на
приказ у шаблона стоит «N р.д. после закрытия периода». Анализ отдаёт его реквизитом повода, а
задание берёт как собственный срок повода. База — день закрытия периода. Пусто — умолчание правила
20 р.д. (`ЗА-6`, числа — на подтверждение заказчику). У «поручений нет» — 5 р.д. у правила, от даты утверждения.

**7. Поручения по заменённому обзору заменяющему не засчитываются.** Новый подписанный текст требует
нового решения. Закрыть его дёшево: «без поручений» с основанием «поручено по ОБ-…». Открытое
задание по заменённому снимается «обзор заменён» (`ЗА-7`, `ЗА-14`).

**8. Эскалация — по умолчанию** (`ЗН-16`), особого адресата у видов анализа нет (`ЗА-10`).

**9. Адресат вне круга шаблона — отказ при утверждении.** Это четвёртое условие подписи рядом с
тремя `ADR-0249`, и отказ называет причину словами. Задание видимости документа не даёт (`ЗА-12`).

## Отвергнуто

- **Любой обзор за период гасит повод.** Ревизор видит «исполнено», хотя портфель целиком не
  разобран.
- **Разрез вместе с периодичностью у шаблона** («ежеквартально по каждой области»). Приказ
  становится матрицей, а поле шаблона — второй строкой расписания. Это уже отвергнуто `ADR-0251`.
- **Очередь роли «аналитик»** для «обзора за период нет»: пока задание не взято, персонально не
  отвечает никто. **Автор прошлого обзора** — угадывание адресата.
- **Срок у правила заданий.** Новый приказ исполняет администратор другого модуля.
- **Засчитывать поручения по цепочке замены.** Новый вывод заменяющего обзора не читает никто.
- **Задание открывает обзор своему исполнителю.** Это второй контур доступа, против `ИА-24`.
- **Только поручение гасит «поручений нет».** Фиктивное поручение — обход `ИА-11`.
