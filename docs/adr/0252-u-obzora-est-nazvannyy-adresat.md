# У обзора есть названный адресат — без него утверждения нет

**Статус:** принято · 2026-09-21 · модуль «Анализ» ·
опирается на [ADR-0157](./0157-vypusk-s-poluchatelem-vtoraya-zamorozka.md) §2 (окончательный
выпуск бывает только с названным получателем),
[ADR-0251](./0251-analiz-otdaet-zadaniyam-dva-povoda.md) (повод адресуется получателю обзора),
[ADR-0152](./0152-tri-shva-po-voprosu-i-oblast-vidimosti.md) §3 (область видимости ответа) ·
уточняет модель обзора (§2.4 канона анализа)

## Контекст: документ для руководства, у которого нет получателя

Обзор — суждение о множестве, написанное **для кого-то**: правления, отраслевого
департамента, регионального представительства. В модели этого «кого-то» не было: обзор хранил
номер, шаблон с редакцией, период, дату среза, разрез, закреплённые значения, состояние,
автора, текст, вывод, ленту корректировок и два чужих номера. Подписанный документ ложился в
реестр и ждал, пока его откроют.

Вопрос стал предметным, как только обзор без поручений сделался поводом для задания: повод
надо кому-то адресовать. Вывести адресата из разреза не выходит — разрез это **признак
среза**, а не адресная книга: «область = Чуйская» не называет человека ни при каком правиле,
«отрасль = сельское хозяйство» тем более, а «куратор = Асанов» называет того, кто поручать не
вправе. Единственный случай, где вывод работает, — разрез по подразделению, то есть один из
четырёх.

У соседа приём обратный и давно принят: окончательный выпуск отчётности **не бывает** без
названного получателя, «иначе по строке потом не найти, что именно на этом выпуске стоит»
(`ADR-0157` §2). Утверждение обзора и есть такой выпуск.

## Решение

**1. У обзора появляется реквизит «кому направлен».** Называет его автор при утверждении;
значение — подразделение (не человек: привязка к человеку ставит документ на отпуске и едет
с кадровым движением, как уже решено для круга шаблона у отчётности).

**2. Без адресата утверждения нет.** Отказ называет причину теми же словами, что у соседа:
документ без получателя не находится по строке и не адресуется никому.

**3. Задание по поводу «обзор без поручений» уходит руководителю названного подразделения.**
Угадывания из разреза нет ни в одном случае.

**4. Адресат не расширяет и не сужает видимость.** Круг читателей обзора по-прежнему —
круг шаблона (`ИА-24`); «кому направлен» говорит, **кому адресовано суждение**, а не кому
открыт документ. Смешать их значило бы завести у анализа свой контур доступа, которого он не
заводит.

**5. У черновика адресата нет** — как нет у него ни выпуска, ни охвата: он появляется вместе
с подписью, одним действием с ней.

## Отвергнуто

- **Выводить адресата из закреплённых значений разрезов.** Работает в одном случае из
  четырёх, в остальных — угадывание или отказ.
- **Адресовать всем подразделениям круга шаблона.** Трое получают три задания об одном
  документе и ждут друг друга; персонально не отвечает никто.
- **Обойтись без адресата, оставив обзор «документом для всех, кто видит».** Тогда повод
  некуда отправить, а подписанный документ остаётся в реестре до случайного читателя.

## Следствия

- канон анализа §2.4 (что обзор хранит), §4 (порядок утверждения), §10 (экраны: колонка в
  реестре и строка в документе) дополняются реквизитом;
- макет: поле при утверждении, отказ без него, колонка в реестре;
- постановка: карточка утверждения обзора переписывается.
