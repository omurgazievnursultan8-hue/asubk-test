# АСУБК — логика по модулям

Двадцать четыре файла, по одному на модуль: **вся текущая логика системы**, изложенная так,
чтобы каждый файл читался **отдельно и без доступа к репозиторию** — для обсуждения с ИИ или
человеком на стороне.

**АСУБК** — система управления бюджетным кредитованием ОАО «Госфинхолдинг» (ФКФ, Кыргызская
Республика). Новое приложение — Jmix-на-Vaadin, русскоязычный бэк-офис; заменяет старую систему
ФКФ.

## Что чем является

**Файлы 05–16 — копии живых спецификаций модулей**, лежащих рядом с макетами
(`mockups/*/ASUBK-*-logika.md`). Здесь они собраны в одну папку для выгрузки. **Оригинал —
там**: правки вносятся в `mockups/`, копию надо обновлять заново.

**Файлы 01–04 и 17–24 — написаны здесь** (сентябрь 2026) для модулей, у которых собственного
файла логики не было: логика была рассыпана по разделам ТЗ, коду макетов, решениям (ADR) и
журналам волн. Каждый собран по одному образцу:

1. краткая суть — решения, определяющие модуль;
2. сущности и поля;
3. состояния и переходы;
4. правила и инварианты;
5. швы с соседними модулями;
6. что решено и почему (таблица «решение → причина»);
7. открытые вопросы и долги;
8. словарь терминов.

## Как выгрузить наружу

Папку можно брать целиком как есть — все 25 файлов настоящие, ссылок нет:

```bash
cp -r docs/logika /куда-нибудь/logika
```

Обновить копии 05–16 из оригиналов:

```bash
python3 scripts/logika_sync.py          # показать расхождения
python3 scripts/logika_sync.py --write  # перезалить копии
```

## Чего здесь нет

- **Кода приложения** — это не исходники, а описание логики.
- **Дефектов и задач** — они живут в `notes/qa-findings.md` и `TODO.md`.
- **Постановок разработчикам** — они в `docs/tasks/`.
- **Обоснований решений целиком** — в файлах пересказаны причины, полные тексты в `docs/adr/`.
- **Модулей вне разбора** — СУГС, поручительства, корпоративное управление исключены заказчиком.

## Оговорка о достоверности

Модули находятся на разных стадиях. Часть описывает **целевую модель** (спроектирована, есть
макет и решения, в приложении ещё нет), часть — **действующее приложение** (обследовано живьём),
часть — **и то и другое с разделением**. Каждый файл говорит о своём статусе в шапке; там же —
дата состояния и первоисточники.

Раздел «Открытые вопросы и долги» в каждом файле — не список недоделок текста, а перечень
**действительно нерешённого**.
