## 1. Что это, кому принадлежит и где границы

**Модуль по имуществам ведёт вещи и имущественные права, которые Фонду предлагают или уже
передали в счёт задолженности по бюджетным кредитам, — от предложения до ухода вещи из
собственности Фонда.** Глагол модуля — «принимает и отчуждает».

Владелец — **Сектор по работе с активами Департамента правового обеспечения** (Инструкция п. 5,
`ИМ-96`); в регионах работу по его материалам ведут региональные представительства. В листе
согласования ТЗ (стр. 1102–1103) — «Управление по работе с активами»: такого типа узла в
оргструктуре нет. Предложения ССИ первым получает отдел по работе с проблемными кредитами (Инструкция
п. 8).

### 1.1. Где модуль начинается и кончается (`ИМ-1`)

```
 ВЕЩЬ ДОЛЖНИКА (собственник — должник/залогодатель)         ВЕЩЬ ФОНДА (собственник — Фонд)
 ────────────────────────────────────────────────┐          ┌───────────────────────────────────
  залог / иное имущество                          │          │
     ▼                                            │          │  на учёте
  обращение взыскания — ВЗЫСКАНИЕ                 │          │     ▼
     ▼                                            │ ПЕРЕХОД  │  объявления, заявки → договор КП
  торги ПССИ / залогодержателя — ЗАЛОГ (P13)      │  ПРАВА   │     ▼
     ├─ состоялись → выручка → ADR-0054           │ ═══════► │  оплачен / передан / выбыл /
     └─ не состоялись ─┐                          │          │  возвращён → СНЯТ С УЧЁТА
                       ▼                          │          │
            ┌──── ПРЕДЛОЖЕНИЕ ИМУЩЕСТВА ──── решение органа ── акт ┘
            │  (+ банкрот через спецадминистратора, должник,
            │     залогодатель, третье лицо — добровольно)
            └──────────────── МОДУЛЬ ПО ИМУЩЕСТВАМ ─────────────────────────────────────────►
```

- **Вход** — предложение от любого из пяти источников (`ИМ-17`). Модуль рассматривает его и
  решает «принять» или «отказать» по каждой позиции (п. 35: «принятие **либо отказ**»).
- **Середина** — переход права (`ИМ-20`): с него вещь Фонда, и с него же погашен долг.
- **Выход** — один из пяти путей выбытия, после которого объект снят с учёта (`ИМ-7`).

### 1.2. Чего в модуле нет

| что | где живёт | почему |
|---|---|---|
| торги по предмету залога, начальная продажная цена, раздел выручки по п. 48 | Залог (P13) публикует, Взыскание делит | `ADR-0004`, `ADR-0054`; модуль их **читает** |
| деление суммы принятия между кредитами | Взыскание (`ИМ-4`) | правило одно на вещь, кто бы её ни отчуждал |
| разнесение внутри кредита, сторно, корректировка суммы, курс | Платежи | `ADR-0058`, `ADR-0061`, `ADR-0090`; один реестр денег |
| учёт задолженности должника | Кредит и Платежи | `ADR-0020`: модуль владеет фактами, а не долгом |
| бухгалтерский учёт объекта (баланс, амортизация, проводки) | бухгалтерия Фонда вне АСУБК | `ИМ-11` |

| регресс поручителя к заёмщику | спор сторон, Фонд не участник | `ИМ-27` |
| уведомления и поручения | Задания | `ИМ-15`; модуль объявляет поводы |
| числа на дату и отчётные формы | Статистика и Отчётность | `ИМ-22`, `ADR-0222` |
| долг по поручительствам Госфинхолдинга | будущая подсистема поручительств | `ИМ-95`: модель готова, вид долга недоступен до подсистемы |

## 2. Единица учёта

### 2.1. Три сущности (`ИМ-2`)

```
 Предложение имущества П-1   (источник · обязанное лицо · отчуждатель · документ · срок ответа)
 ├─ Позиция 1 ── итог: ПРИНЯТА ──► Объект имущества ИО-1 ─► … ─► снят с учёта
 ├─ Позиция 2 ── итог: ОТОЗВАНА источником
 └─ Позиция 3 ── итог: ОТКАЗАНА решением органа
```

- **Предложение имущества** — обращение одного источника. Короткий процесс: регистрация,
  рассмотрение, решение органа, закрытие.
- **Позиция предложения** — одна вещь внутри предложения. Несёт своё решение и итог.
- **Объект имущества** — вещь или право Фонда. Длинная жизнь: годы, если продана в рассрочку.

Уровни разведены потому, что у них разные сроки и разные финалы: отказанной позиции нужен
след решения, но не нужен баланс, а объекту не нужен срок ответа источнику.

### 2.2. Реквизиты предложения (`ИМ-17`, `ИМ-27`, `ИМ-32`)

| реквизит | смысл | правило |
|---|---|---|
| источник | ПССИ · спецадминистратор / ликвидационная комиссия · должник · залогодатель · третье лицо | закрытый перечень; задаёт вид документа, основание цены и отчуждателя по умолчанию |
| вид долга | **бюджетный кредит** · поручительство Госфинхолдинга | второй вид виден, но недоступен, пока нет подсистемы поручительств (`ИМ-95`) |
| обязанное лицо | чей долг гасится: **заёмщик или поручитель** | ссылка на обязанное лицо взыскания (`ADR-0024`), не на заёмщика вообще |
| отчуждатель | чья вещь до перехода права; кому причитается доплата | ссылка на субъекта (`ADR-0016`), не ввод ФИО |
| документ-основание | постановление ПССИ, нотариальное соглашение об отступном со спецадминистратором, ликвидационной комиссией, должником, залогодателем или третьим лицом | реквизиты + вложение (`ИМ-34`) |
| срок ответа | из документа источника; иначе — умолчание настроек по источнику | `ИМ-32` |
| кредиты | какие кредиты обязанного лица затронуты | для проекции во взыскание и деления (`ИМ-4`) |

**Таблица источников:**

| источник | документ-основание | основание цены (§4.1) | отчуждатель по умолчанию | счёт доплаты (`ИМ-81`) |
|---|---|---|---|---|
| ПССИ | постановление о передаче нереализованного имущества взыскателю + акт | цена последних торгов в постановлении (Инструкция п. 11) | должник (или залогодатель — по предмету) | депозит ССИ, пока производство открыто; иначе счёт отчуждателя |
| спецадминистратор / ликвидационная комиссия | нотариальное соглашение об отступном по конкурсной или ликвидационной массе | цена последних торгов в соглашении (п. 16) | банкрот / ликвидируемое юрлицо | счёт банкрота у спецадминистратора / счёт ликвидируемого юрлица |
| должник | нотариальное соглашение об отступном | отчёт оценщика Фонда (п. 19) | должник | должник |
| залогодатель (не должник) | нотариальное соглашение об отступном / по п. 49 | отчёт оценщика Фонда (п. 19) | залогодатель | залогодатель |
| третье лицо | соглашение об исполнении за должника | отчёт оценщика Фонда (п. 19) | третье лицо | третье лицо |

Ликвидационная комиссия — не шестой источник (`ИМ-97`): у неё те же правила, что у
спецадминистратора, меняются только слово в документе и счёт. **Оставление предмета залога за
собой** после несостоявшихся торгов (Инструкция п. 17, Закон «О залоге» ст. 76) идёт источником
по залогодателю, но с особым основанием цены — протоколом о результатах торгов (`ИМ-85`, §4.1).

Поручитель шестым источником **не является** (`ИМ-27`): он обязанное лицо, и его вещь идёт
источником «должник» с обязанным лицом = поручитель и отчуждателем = поручитель. Гасится его
линия во взыскании, а с ней — в той же сумме — долг заёмщика.

**Пробный случай.** Брат должника Х отдаёт свой гараж: источник — третье лицо, обязанное
лицо — Х, отчуждатель — брат. Долг гасится Х, доплата уходит брату. При «отчуждатель =
должник» доплата ушла бы на счёт Х — ошибка с деньгами, ради которой реквизиты и разведены.

### 2.3. Реквизиты позиции

| реквизит | правило |
|---|---|
| вид имущества | общий справочник видов с Залогом (`ИМ-12`, `ИМ-35`) |
| характеристики | по схеме параметров вида; у вещи из залога — **ссылка «происходит из предмета залога»** |
| заключения | осмотр, оценка, ликвидность, расходы на содержание — готовит специалист |
| стоимость принятия | по основанию цены источника (§4.1): из документа или из отчёта оценщика Фонда; в валюте документа (`ИМ-3`, `ИМ-84`, `ИМ-24`) |
| ожидаемая доплата | производная на дату расчёта: стоимость минус остаток долга обязанного лица после ранее принятых позиций того же решения, в порядке плановой даты перехода права; при равных датах — по номеру позиции; показывается органу как цена решения (`ИМ-5`, `ИМ-43`) |
| решение | ссылка на решение органа + итог по этой позиции |
| итог | принята · отказана · отозвана · принятие не состоялось (`ИМ-33`, `ИМ-21`) |

### 2.4. Объект имущества

Возникает **только** двумя путями (`ИИ-1`):

1. из принятой позиции — актом приёма-передачи;
2. вводом остатка при запуске системы (`ИМ-29`, §13).

Характеристики при возникновении из залога **копируются снимком** на дату акта (`ИМ-12`):
собственник сменился, и у двух записей дальше разные истории. Ремонт Фонда не должен
переписать обследования предмета залога, по которым, может быть, шёл суд.

### 2.5. Вид имущества — признаки справочника

Справочник видов общий с Залогом. Модулю нужны от него три признака (`ИМ-ДС-12`):

| признак | на что влияет |
|---|---|
| **право подлежит госрегистрации** | дата перехода права = дата регистрации, а не акта (`ИМ-20`) |
| **делимая** | доступно ли разделение (`ИМ-28`) |
| **класс: вещь / имущественное право** | у права выключены осмотры, местоположение и разделение; кураторство режет по месту регистрации или эмитента (`ИМ-35`) |

## 3. Предложение: рассмотрение и решение

### 3.1. Жизненный цикл

```
 Предложение:  ЗАРЕГИСТРИРОВАНО ─► НА РАССМОТРЕНИИ ─► РЕШЕНИЕ ВЫНЕСЕНО ─► ЗАКРЫТО
                 входящий документ    заключения по       решение органа:     у каждой позиции
                 срок ответа          позициям; ответ     итог по каждой      есть итог
                                      в срок / промежут.  позиции
                                      письмо

 Позиция:   предложена ─► на рассмотрении ─► ПРИНЯТЬ ─► акт ─► [переход права] ─► Объект
                 │               │              │         └─► право не перешло ─► НЕ СОСТОЯЛОСЬ
                 │               │              └─► (до акта) ─► ОТОЗВАНА
                 │               └─► ОТКАЗАТЬ (основание) ─► ОТКАЗАНА
                 └───────────────┴─► ОТОЗВАНА источником (документ)
```

Состояние предложения и позиции — производная от фактов, как и у объекта (`ИМ-13`).

Предложение «закрыто», когда у каждой позиции есть итог. Принятая позиция при этом ещё ждёт
акта: пока акта нет, она остаётся исполнимой, а по истечении порога ожидания Задания получают
повод `pk-im-act-pending` (§9, `ИМ-42`). Из ожидания акта три выхода: акт, отзыв источником
(§3.4) или решение о прекращении принятия (§4.3).

### 3.2. Кто решает (`ИМ-6`)

**По позиции всегда решает коллегиальный орган.** Решение — документ органа с номером и
датой, **одно на предложение, итог — по каждой позиции**: одно заседание вправе принять дом и
отказаться от трактора.

- Орган — ссылка на общий справочник коллегиальных органов взыскания (§11 канона взыскания,
  `ADR-0089`). Решает **всегда Комитет по вопросам правового обеспечения и управления
  активами** (`ИМ-49`): из пятёрки нормы это его профиль — по п. 44 Порядка он же решает начало
  внесудебного обращения взыскания на залог. Название — по п. 44 («…управления активами»).
- **Порога по сумме нет** (`ИМ-49`): мебель за 40 000 решает тот же Комитет, что квартиру.
  Порог по сумме потребовал бы ещё и правила «сумма по позиции или по решению», а нормы под ним нет.
- Гейта «принятие имущества» в таблице гейтов взыскания пока нет — `ИМ-ДС-2`.
- Инструкция это подтверждает (п. 6): вопросы принятия и отчуждения рассматривает
  «соответствующий Комитет», порога нет. Вопрос выносится служебной запиской председателю
  Комитета; предложение ССИ вносит отдел по работе с проблемными кредитами в течение 1 р.д.
  (п. 8), остальные — Сектор.
- Отказ в принятии — письменный ответ заявителю с причинами (п. 7), бланк Отчётности.

Почему не единолично: принятие гасит долг и может потребовать доплаты — необратимо и стоит
денег; P9-R8 уже ставит «принятие имущества» в ряд действий, разрешаемых комитетом.

### 3.3. Срок ответа (`ИМ-32`)

- Срок — **реквизит предложения из документа источника**: у ПССИ он записан в постановлении,
  у спецадминистратора задан процедурой, у добровольного предложения его может не быть.
- Нет в документе — подставляется умолчание из настроек **по источнику**, со своим источником
  значения (норма · Инструкция · внутренний акт). Для ССИ и спецадминистратора умолчание — 5 р.д.
  на письмо о принятии (Инструкция пп. 9, 16); после ответа ССИ ещё 5 р.д. на акт (п. 9).
- Любой срок Инструкции продлевает курирующий заместитель Председателя Правления резолюцией на
  служебной записке (п. 5) — факт «срок продлён» с документом и новой датой (`ИМ-99`).
- Ответом в срок считается решение органа **или промежуточное письмо** («рассматриваем, просим
  продлить») — факт документа с номером и датой.
- Истёкший срок без ответа — повод для Заданий (§9).
- **Решение после срока не блокируется**: оно выносится с пометкой «вынесено после истечения
  срока ответа». Запрет оставил бы вещь, которую источник ещё не отозвал, без решения навсегда.

### 3.4. Отзыв источником (`ИМ-33`)

- До акта приёма-передачи источник вправе отозвать **любую позицию** — фактом «отозвана» с
  документом (постановление ПССИ о возврате должнику, письмо должника).
- Решение органа «принять», если оно было, остаётся в истории **неисполненным**.
- После акта отзыва нет. До перехода права выход — только прекращение принятия (`ИИ-20`,
  §4.3); после перехода права вещь уходит от Фонда только путём «возврат» через суд (`ИМ-14`).
- «Отозвана» и «отказана» — **разные итоги**: отказ — решение Фонда, отзыв — решение
  источника. Смешение сделало бы ложным отчёт «Фонд отказал в N % предложений».

### 3.5. Рассмотрение не останавливает долг (`ИМ-19`)

Пока предложение рассматривается, **пени начисляются до перехода права, меры взыскания
продолжаются**. Нормы о паузе нет (у реструктуризации она есть — п. 18, у предложения нет);
выдуманная пауза дала бы должнику рычаг «предложил неликвид — взыскание встало»; решение `М-7`
взыскания: «пауза останавливает действия Холдинга, а не обязательство должника». Давят только
сроки ответа. Инструкция паузы не ставит — `ИМ-57` подтверждён.

Своей паузы модуль не ставит и при добровольном предложении (`ИМ-57`). Если Комитет сочтёт
нужным остановить меры, он делает это решением о приостановлении **во взыскании** (Порядок,
стр. 251: «приостановлена по решению соответствующего комитета») — механизм соседа, модулю по
имуществам ничего добавлять не нужно.

## 4. Принятие и деньги

### 4.1. Стоимость принятия (`ИМ-3`, `ИМ-84`, `ИМ-85`)

**Модуль стоимость принятия не вычисляет: она берётся из основания цены, которое задаёт
источник** (§2.2). Модуль вводит её, прикладывает документ и выносит на решение органа.

| источник | основание цены | правило |
|---|---|---|
| ПССИ | постановление ССИ | цена, установленная на последних торгах (Инструкция п. 11) |
| спецадминистратор / ликвидационная комиссия | соглашение об отступном | цена последних торгов (п. 16) |
| должник · залогодатель · третье лицо | **отчёт оценщика, привлечённого Фондом** | последний отчёт на дату решения органа; цена в заявлении и в соглашении значения не имеет (п. 19) |
| оставление предмета залога за собой | протокол о результатах торгов | **не ниже 90 % цены повторных торгов** (п. 17, Закон «О залоге» ст. 76); цену торгов модуль читает у Залога |

- **Отчёт оценщика Фонда обязателен** для трёх добровольных источников (`ИМ-84`): пока у позиции
  его нет, вопрос на Комитет не выносится. Стоимость принятия равна сумме отчёта, другой суммы не
  ввести; соглашение об отступном пишется на неё. Правило работает в обе стороны: не даёт ни
  занизить цену, чтобы не доплачивать, ни завысить, чтобы погасить больше долга.
- **Проверка 90 %** (`ИМ-85`) — норма закона, а не настройка: цена ниже порога не вводится.
- Сверки стоимости ПССИ и спецадминистратора с чем-либо нет (`ИМ-47`): цена записана в документе
  источника, опечатку ловит второй ключ, ошибку после публикации лечит исправление (`ИМ-23`).
- Расход на оценку возникает до объекта и записывается на позицию; актом он переходит в журнал
  расходов объекта (§6).

Принятие — это **погашение, а не списание** (`ADR-0076` §2): ценность получена.

### 4.2. Дата погашения — переход права (`ИМ-20`, `ИМ-88`)

**Долг гасится на дату перехода права** — Инструкция п. 24 называет её «моментом удовлетворения
кредиторских требований»:

- вид с признаком «право подлежит госрегистрации» — **дата регистрации**: для недвижимости —
  госрегистрации права собственности, для транспорта и самоходной техники — регистрации в органе
  учёта; если акт подписан позже регистрации — дата акта (п. 24 требует обе даты);
- прочие виды — **дата акта приёма-передачи**.

Между актом и регистрацией объект в состоянии **«принят, ждёт регистрации»**: Фонду он ещё не
принадлежит, погашения ещё не было, продавать его нельзя (`ИИ-9`).

**Какие виды несут признак** (`ИМ-88`, переигрывает `ИМ-58`):

| признак «право подлежит госрегистрации» | виды |
|---|---|
| есть | недвижимость — квартира, жилой дом, гараж, нежилое помещение, склад, **земельный участок**; доля в уставном капитале; **автомобиль, трактор, спецтехника** |
| нет | оборудование, зерно, скот |

Прежняя позиция «учёт в ГАИ — учётная запись, право переходит актом» (`ИМ-58`) снята: п. 24
связывает момент погашения движимого с датой его регистрации. Перечень — демо-значения
справочника видов; окончательно его задают юристы Фонда.

### 4.3. Отказ регистратора и прекращение принятия (`ИМ-21`, `ИМ-41`)

- **Устранимый отказ** (не хватает справки) — просто факт; объект продолжает ждать
  регистрации, документы подаются повторно.
- **Окончательный отказ** (арест третьего лица на годы) или **решение органа о прекращении
  принятия** (`ИМ-41`) — закрывается состоянием **«принятие не состоялось»** (объект, если акт
  уже подписан; иначе только позиция). Денег не движется: погашения не было.
  Позиция получает итог «принятие не состоялось» с основанием. Повторить можно новой позицией
  или новым предложением, если препятствие снято.
- **Решение о прекращении принятия.** Выносится, когда право не перейдёт, а окончательного
  отказа регистратора нет. Причина обязательна, перечень закрытый: отчуждатель уклоняется от
  регистрации · вещь погибла или утрачена до перехода права · отчуждатель умер, правопреемника
  нет · иное (с пояснением). Инициатор — куратор предложения (после акта — куратор объекта),
  обычно по поводу `pk-im-act-pending` или `pk-im-registration-pending` (§9); решение выносит
  орган по §3.2; публикует специалист вторым ключом (§10.2). Применяется к принятой позиции без
  акта (§3.1) и к объекту до перехода права; в первом случае объекта ещё нет (`ИИ-1`), итог
  получает позиция.
  Гибель или утрата до перехода права — не «выбытие» (§5.3): путь «выбытие» только для объекта
  на учёте. Риск гибели и страховое возмещение до перехода права — у отчуждателя, вне модуля:
  вещь Фонду ещё не принадлежала (`ИМ-37`).
  Пример: акт на квартиру ИО-1 от 12.03.2027, регистрации нет; 15.05.2027 Комитет решает
  «отчуждатель уклоняется» → ИО-1 «принятие не состоялось», погашения и сторно нет, долг не
  тронут.
- Это **не путь выбытия** и **не возврат**: пять путей `ИМ-7` описывают выход из собственности
  Фонда, а здесь собственности не было.

### 4.4. Три шага, три владельца (`ИМ-4`)

Принятие проходит тот же шов, что выручка от торгов (`ADR-0054`):

```
  МОДУЛЬ ПО ИМУЩЕСТВАМ           ВЗЫСКАНИЕ                          ПЛАТЕЖИ
  публикует факт принятия  ──►   делит между кредитами        ──►   поступление вида «имущество
  (стоимость, дата перехода      обязанного лица:                   в счёт погашения» по каждому
   права, обязанное лицо,        залог — по отнесениям и п. 48;     кредиту → разнесение обычной
   вещь, связь с залогом)        иное имущество — ИМ-ДС-1           матрицей (слой решения суда
                                 → «распределено» + «не вошло»      первым, затем пени → % → ОД)
```

Модуль **не делит и не разносит** (`ИИ-5`). Правило деления одно на вещь, кто бы её ни
отчуждал: ПССИ на торгах или Фонд на баланс.

Делить взыскание обязано по долгу на дату перехода права, **уже уменьшенному** прежними
принятиями того же обязанного лица (`ИМ-43`, `ИМ-ДС-1`): объекты с разными датами перехода права
публикуются и делятся по очереди этих дат, а не вместе.

Отмена раннего принятия (`ИМ-14`) меняет долг на даты поздних переходов права: поздние позиции
переделяются исправлением (`ИМ-44`, §8.1), а не только пересчётом оценки.

**Пробел у соседа.** Канон взыскания (§13, стр. 920) задаёт деление только для предмета залога.
Для иного имущества (п. 33) правила нет — `ИМ-ДС-1`.

Тем же швом идёт **погашение из выручки** (`ИМ-91`, §6.1): часть выручки от продажи объекта,
которая по очереди Инструкции гасит остаток долга заёмщика, публикуется модулем, делится
взысканием и разносится Платежами точно так же, как само принятие.

### 4.5. Доплата (`ИМ-5`, `ИМ-79`…`ИМ-83`)

Если стоимость принятия больше задолженности обязанного лица на дату перехода права, разница
причитается бывшему собственнику — отчуждателю. **Сумма фиксируется на дату перехода права, а
выплачивается после продажи** (Инструкция пп. 46–49, `ИМ-79`):

| что | правило |
|---|---|
| **сумма доплаты** | стоимость принятия − распределённое взысканием на шаге 2 на дату перехода права (производная, `ADR-0001`); дальше не меняется — ни ценой продажи (`ИМ-82`), ни судьбой вещи |
| **к выплате** | сумма доплаты − расходы Инструкции п. 43 на дату выплаты, не меньше 0 (п. 49) |
| **срок выплаты** | 30 дней со дня поступления выручки (п. 46); при рассрочке — доля каждой оплаты по мере поступления (п. 48); срок — правило по источнику в настройках |
| **без выручки** | обращение в госсобственность и гибель без страховки — через расходную часть республиканского бюджета (п. 47), состояние «к выплате через бюджет»; гибель со страховкой — 30 дней от поступления возмещения (`ИМ-83`) |
| **просрочка бывшего собственника** | на дату выплаты модуль спрашивает у Кредита и Платежей его просрочку по бюджетным кредитам; есть — выплата **удержана**, повод куратору, 30 дней считаются заново с даты, когда просрочки нет; зачёта нет (`ИМ-80`) |
| **получатель** | отчуждатель; счёт — по источнику, таблица §2.2 (`ИМ-81`) |
| **исполнение** | сущность «Возврат» в Платежах (§2.3 канона платежей: «получатель бывает не заёмщиком… привязки к кредиту может не быть»), источник денег — республиканский бюджет |

Состояния доплаты: **зафиксирована** (на дату перехода права) → **к выплате** (выручка
поступила или вещь ушла без продажи) → **удержана** (есть просрочка) → **выплачена** (Возврат
исполнен). Это производная фактов, как состояние объекта (`ИМ-13`).

**Доплата продажу не блокирует.** Прежний флаг ⚑ «принятие не завершено» с запретом продажи
(`ИМ-5`, `ИИ-9`) снят: при выплате после продажи он дал бы тупик — продать нельзя до выплаты,
выплатить нельзя до продажи. Неисполненная доплата видна в карточке и реестре как сумма и
состояние.

При решении органу показывается **ожидаемая доплата** на дату расчёта — как цена решения. Если
принято несколько позиций, она считается **нарастающим итогом** по плановым датам перехода права
(`ИМ-43`). Плановая дата: для вида без госрегистрации — дата акта (пока акта нет — дата
решения органа); для вида с госрегистрацией — дата акта, пока регистрации нет, затем дата
регистрации. Она нужна только для очерёдности; при равных датах — номер позиции.

Пример: долг 1 000 000, оборудование 500 000 (акт 15.03), квартира 700 000 (переход права 01.06).
Оборудование: 500 000 против долга 1 000 000 → доплаты 0. Квартира: 700 000 против остатка 500 000 → 200 000. На 15.03 «не вошло» 0, на 01.06 — 200 000;
доплата 200 000 фиксируется только по квартире. Каждая позиция отдельно против полного долга дала
бы 0 + 0 при реальных 200 000. На дату перехода права доплату по-прежнему считает взыскание по
живому долгу. Долг обязанного лица на дату для оценки модуль читает по запросу у Кредита и
Платежей (владельцы долга, §1.2) и не хранит; окончательно делит взыскание. Это оценка: она
пересчитывается при каждом новом факте (акт, регистрация, прекращение принятия выпавшей позиции);
окончательная сумма известна только на дату перехода права, потому что долг до неё живёт
(`ИМ-19`).

**Доплата обязательна; отказ — всегда право органа** (`ИМ-48`). У позиции два исхода решения:
«принять» (с доплатой, если она возникнет) или «отказать» (п. 35 Порядка). Третьего итога
«принять без доплаты» нет. Обнулить доплату ценой в соглашении больше нельзя: у добровольных
источников стоимость принятия равна отчёту оценщика Фонда (`ИМ-84`, переигрывает `ИМ-48` в этой
части).

Вариант «разница остаётся Фонду бесплатно» отвергнут: Фонд получал бы вещь дороже своего
требования, ничего не платя, — прямое основание для иска. Вариант «принятие запрещено, если
доплата > 0» отвергнут: Фонд терял бы ликвидную вещь из-за сома доплаты.

### 4.6. Валюта (`ИМ-24`)

- Стоимость принятия хранится **в валюте документа-основания**; учётная стоимость объекта — в
  ней же, навсегда.
- Пересчёт в валюту кредита делают **Платежи** по курсу на дату перехода права (§2.4 канона
  платежей: курс — реквизит связи, справочник курсов НБКР, «нет курса на дату — действует
  последний установленный»).
- Модуль курсов не знает (`ИИ-18`). Второй конвертер разошёлся бы с первым на копейки — ровно
  там, где родилась «сирота 0,01» (E2E-13/14).

### 4.7. Сквозной пример

Должник Х: кредит К-1 (сомы), долг 900 000; кредит К-2 (сомы), долг 900 000. Кредиты обеспечены
залогом квартиры ПЗ-88 (отнесения 50/50). Двое торгов ПССИ не состоялись.

| дата | факт | кто | что меняется |
|---|---|---|---|
| 10.01.2027 | постановление ПССИ, срок ответа 5 р.д. → предложение П-1: квартира, гараж, трактор | отдел по работе с проблемными кредитами | П-1 зарегистрировано; записка председателю Комитета до 11.01 (1 р.д.); проекция в журнал дела Х |
| 15.01.2027 | промежуточное письмо «рассматриваем» | специалист | срок соблюдён |
| 01.02.2027 | ПССИ отзывает гараж | специалист | позиция 2: отозвана |
| 20.02.2027 | решение Комитета: квартира — принять за 2 400 000, трактор — отказать (неликвид) | секретарь органа | позиция 1 принята; позиция 3 отказана; ожидаемая доплата ≈ 550 000 |

### 5.3. Пути выбытия (`ИМ-7`)

Закрытый перечень из пяти. Пути различаются поведением денег, а не названием:

| путь | документ | деньги | конец |
|---|---|---|---|
| продажа разовая (в том числе выкуп, `ИМ-94`) | договор КП | поступление цены через Платежи → очередь выручки (§6.1) | снят с учёта, когда оплачен |
| продажа в рассрочку | договор КП с графиком и процентами | поступления по графику → очередь выручки; проценты — Госфинхолдингу | снят с учёта после последнего платежа (`ИМ-9`) |
| обращение в государственную собственность | решение + акт передачи; основание из перечня (`ИМ-98`) | нет — потеря стоимости; доплата — через бюджет (`ИМ-83`) | снят с учёта на дату акта |
| выбытие (гибель, утрата, снос) | акт о гибели / утрате | нет — потеря стоимости | снят с учёта на дату акта |
| возврат (принятие отменено) | судебный акт | **сторно погашения**, долг восстановлен (`ИМ-14`) | снят с учёта на дату акта |

- Снятие с учёта — **только следствие** завершённого пути (`ИИ-7`).
- Шестой путь — правка модели с ADR, а не строка справочника. Намеренно: справочник не скажет
  движку, что делать с деньгами нового пути.
- Расторжение договора КП — **выход из пути**, а не новый путь: объект возвращается «на учёт».
- **Обращение в госсобственность** (Инструкция пп. 50–51, `ИМ-98`) заменило «безвозмездную
  передачу». Основание — из закрытого перечня: не отчуждён в срок, установленный гражданским
  законодательством · нужен государственному органу или органу местного самоуправления · вклад в
  уставный капитал хозяйственного общества. Если государство отказалось принять — вопрос о
  дальнейшем распоряжении выносится на Комитет, объект остаётся «на учёте».

### 5.4. Разделение делимого объекта (`ИМ-28`, `ADR-0261`)

**Путь выбытия всегда берёт объект целиком** (`ИИ-7`). Делимая вещь (зерно, скот, мешки) уходит
по частям только через разделение:

```
 ИО-410 зерно 120 т · 1 440 000 ──разделение (основание)──► ИО-410/1  50 т ·   600 000 → продан А
                                                          ├► ИО-410/2  65 т ·   780 000 → продан Б
                                                          └► ИО-410/3   5 т ·    60 000 → выбыл
 исходный ИО-410 — «разделён» (не путь выбытия: вещь от Фонда не ушла)
```

- Учётная стоимость частей — пропорционально количеству; **сумма частей равна целому до
  копейки**, остаток округления — последней части (`ИИ-8`).
- Части наследуют всё от исходного: источник, дату перехода права, снимок характеристик,
  ссылку на происхождение. Их история начинается с даты разделения, история исходного до неё
  остаётся у исходного.
- Разделение доступно только видам с признаком «делимая». Для квартиры его нет. Допустимые состояния — §5.4а.
- Разделение публикуется вторым ключом: оно меняет учётную стоимость объектов.

### 5.4а. Из каких состояний доступен путь

| действие | допустимые состояния на дату факта | действующее объявление |
|---|---|---|
| выбытие | «на учёте» или «выставлен на продажу» | снимается; заявкам — отказ с причиной |
| возврат по суду | «на учёте» или «выставлен на продажу» | снимается; заявкам — отказ с причиной |
| обращение в госсобственность | только «на учёте»: без действующего объявления и договора КП | — |
| разделение | только «на учёте»: без действующего объявления и договора КП | — |

Продажа — по `ИИ-9` и `ИИ-10`: только «на учёте», без открытого преимущественного права, одно
объявление, один договор. До перехода права ни один путь не доступен (`ИИ-20`).

### 5.5. Обременение (`ИМ-31`)

Факт «на вещи висит чужое право»: вид (аренда, пользование, арест третьего лица, ответственное
хранение, иное), даты с–по, документ. **Денег, графика и дохода у обременения нет** — договор
использования ведётся вне системы (`ИМ-30`).

**Гейт объявления:** активное на дату объявления обременение его не запрещает, но требует
отметки в объявлении: «продаётся с обременением» или «после снятия» (`ИИ-17`). Без гейта признак
не читают в тот единственный момент, когда он важен.

### 5.6. Характеристики и связь с предметом залога (`ИМ-12`)

```
 Предмет залога ПЗ-88 (собственник: должник)       Объект ИО-1 (собственник: Фонд)
 вид: квартира · 54 м² · кадастр …                 вид: квартира · 54 м² · кадастр …  ← снимок на 12.03
 состояние: удовл. (обследование 2025)             состояние: после ремонта (2027)    ← своя жизнь
 статус: ПЕРЕШЁЛ К ФОНДУ (финал, только чтение) ◄── происходит из: ПЗ-88
```

- Справочник видов и схема параметров — **общие с Залогом**: «квартира» не значит разное в
  двух модулях, статистика режет сквозным разрезом.
- Объект из залога копирует характеристики **снимком**; ссылка на предмет — только происхождение.
- У Залога появляется финальное состояние предмета **«перешёл к Фонду»** — с ним же снимается
  обременение и показывается трек взыскания «реализация завершена» (`ИМ-ДС-4`).
- Вещь не из залога (иное имущество, отступное) заводится по той же схеме с нуля.

## 6. Стоимость, оценки, расходы, выручка (`ИМ-11`, `ИМ-91`, `ИМ-100`)

```
 стоимость принятия      2 400 000   ← учётная стоимость; долг погашен этой суммой на дату перехода права
 + расходы                  90 000   ← журнал расходов объекта (Инструкция п. 43)
 = цена объявления       2 490 000   ← по умолчанию (п. 34); снижение — по ИМ-53
 − цена продажи          2 250 000
 ══════════════════════════════════
 результат по объекту     −240 000   ← производная, не хранится; подпись: «без учёта доходов
                                        от использования — они учитываются вне АСУБК»
```

| величина | правило |
|---|---|
| **учётная стоимость** | = стоимость принятия; не меняется ни переоценкой, ни курсом (`ИИ-4`); меняется только исправлением (`ИМ-23`) или разделением (пропорционально) |
| **оценка** | справочная история: дата, оценщик, сумма, валюта, документ; основание цены принятия у добровольных источников (§4.1), цены выкупа жилья после отказа (§7.6) и снижения цены (`ИМ-53`) |
| **расход** | журнал: дата, статья, сумма, валюта, документ. Статьи — перечень Инструкции п. 43 (`ИМ-100`): оценка · объявления · регистрация и оформление документов · налоги · демонтаж и передислокация · охрана и сохранность · организация и проведение торгов · страхование · ремонт · иное (коммунальные, хранение — с пояснением). Страхование — только по согласованию с Комитетом (п. 26). Расходы финансирует Госфинхолдинг до отчуждения (п. 52) |
| **результат по объекту** | цена продажи − учётная стоимость − расходы; у обращения в госсобственность и выбытия цена = 0 (или страховое возмещение, `ИМ-37`); производная |

Расходы **включаются в цену объявления** (п. 34, 43) и **вычитаются из доплаты** (п. 49, §4.5).
Охрана — в течение 5 дней после перехода права (п. 25), мониторинг — не реже раза в полгода
(п. 27, §9).

### 6.1. Очередь выручки (`ИМ-91`)

Выручка от продажи — **не деньги Фонда целиком**: Инструкция (пп. 42–45) раскладывает её по
очереди. Модуль раскладывает каждое поступление по договору КП нарастающим итогом — сначала
заполняется первая очередь, затем вторая:

| очередь | предел | куда | что с долгом |
|---|---|---|---|
| 1. в счёт принятия | стоимость принятия | республиканский бюджет — деньги за погашение, зачтённое при переходе права (п. 42) | не меняется |
| 2. расходы | расходы п. 43 на дату поступления | Госфинхолдинг (п. 44) | не меняется |
| 3. остаток долга | остаток долга заёмщика по бюджетным кредитам на дату поступления | **погашение из выручки**: модуль публикует, взыскание делит, Платежи разносят (§4.4) | уменьшается |
| 4. доход | остаток | доход республиканского бюджета (п. 45) | — |

- По активам из поручительств (`ИМ-95`) очередь та же, получатели другие: очереди 1 и 3 —
  восполнение средств поручительства на счёт Госфинхолдинга (п. 42), очередь 4 — доход
  Госфинхолдинга (п. 45).
- Проценты рассрочки (§7.2) в очередь не входят: они идут на счёт Госфинхолдинга (п. 58).
- Продажа **ниже** стоимости принятия долг не меняет (`ИИ-19`): вся выручка уходит в первую
  очередь, расходы остаются потерей Фонда. Этим принятие по-прежнему отличается от торгов по
  залогу, где расходы реализации уменьшают выручку, гасящую долг (п. 48 Порядка).
- Доплата бывшему собственнику (§4.5) от очереди не зависит: её сумма зафиксирована на дату
  перехода права, поступление выручки задаёт только срок выплаты.
- Читаем п. 42 так: первая очередь — перечисление денег в бюджет за уже зачтённое погашение, а не
  второе погашение долга. Подтверждение — `ИМ-ВЗ-13`.

Пример: долг 3 000 000, квартира принята за 2 400 000 — остаток долга 600 000; расходы 90 000;
продана за 2 800 000 → в бюджет 2 400 000, Госфинхолдингу 90 000, погашение из выручки
310 000 (остаток долга 600 000 → 290 000), доход 0.

Бухгалтерский учёт объекта — вне модуля: ТЗ просит «характеристику с указанием стоимости» и
мониторинг, а не проводки.

## 7. Продажа

### 7.1. Объявление и заявки (`ИМ-86`, переигрывает `ИМ-10` и `ИМ-52`)

Фонд продаёт **через объявления, а не через торги** (Инструкция пп. 33–41): объявление собирает
заявки, каждую заявку решает Комитет, договор КП заключается только по его решению или по итогу
открытых торгов, которые он назначил.

```
 объявление ──► публикации (газеты, сайт, площадки) ──► окно заявок 30 к.д.
     │                                                       │
     │                         заявка А, заявка Б … ─────────┤ каждая — на Комитет за 7 р.д.
     │                                                       ▼
     │                 одна заявка: продать / отказать   ·   две и больше: открытые торги
     │                                                       │
     └── нет заявок → новое объявление через 30 к.д. ◄───────┴──► договор КП (§7.2)
```

**Объявление** — у объекта не больше одного действующего (`ИИ-10`):

| реквизит | правило |
|---|---|
| цена | по умолчанию учётная стоимость + расходы на дату (п. 34); иная — с основанием: отчёт оценщика или решение Комитета (`ИМ-53`); у жилья после отказа бывшего владельца — отчёт оценщика (п. 31) |
| условия | разово · в рассрочку (рассрочка — только при выполнении §7.2) |
| публикации | площадка (республиканская газета · местная газета · сайт Госфинхолдинга · интернет-площадка), дата; в объявлении — наименование, местонахождение, цена (п. 34) |
| окно заявок | 30 к.д. со дня последней публикации (п. 38); после окна продажа на тех же условиях возможна до нового объявления с другими условиями |
| риэлтор | отметка; вознаграждение — наценка к цене, не больше 5 % (п. 36) |
| отметка об обременении | обязательна, если на дату есть активное обременение (`ИИ-17`) |

**Заявка на покупку** — заявитель (ссылка на субъекта), условия (цена, разово или рассрочка),
дата. По заявке на рассрочку — финансовый анализ заявителя с отраслевым управлением (п. 39).
Каждая заявка выносится на Комитет в течение 7 р.д. (п. 40); итог по заявке — продать ·
отказать (письменный ответ с причинами, п. 41) · торги.

**Открытые торги** назначает Комитет, когда заявок две и больше; порядок утверждается его
протоколом (п. 40). Ход торгов — у площадки: участники, ставки и задатки в модуле не ведутся,
второй аукцион у себя разошёлся бы с официальным протоколом. В модуле — решение о торгах и итог:
победитель и цена или «не состоялись».

- **Без решения Комитета договора КП нет** (`ИИ-24`): Комитет решает и по одной заявке, и о
  торгах; продажа без решения — главное место злоупотреблений у госхолдинга.
- **Сроки** (§9): первое объявление — не позже 30 к.д. после перехода права, затем раз в 30 к.д.
  (п. 35); у жилья и доли — от отказа или истечения срока ответа (§7.6).
- **В первой очереди интеграции нет** (`ИМ-51`): публикации, итоги торгов и дата регистрации
  права вводятся руками с документом. Какая госсистема имеется в виду в ТЗ (стр. 541) — по-прежнему
  `ИМ-ВЗ-5`; Инструкция её не называет.
- Слово «торги» в модуле используется только для открытых торгов по решению Комитета; мера
  взыскания по предмету залога (`ADR-0028`) — у Залога.
- Объявление невозможно до перехода права, при открытом преимущественном праве (§7.6) и при
  действующем договоре КП (`ИИ-9`, `ИИ-10`).

### 7.2. Договор купли-продажи (`ИМ-8`, `ИМ-89`, `ИМ-90`)

Решение Комитета или итог торгов порождает договор КП. **Не более одного действующего договора на
объект** (`ИИ-10`).

| реквизит | правило |
|---|---|
| покупатель | ссылка на субъекта |
| цена, валюта | из решения Комитета или итога торгов |
| вид | разовый · рассрочка |
| первый взнос | обязателен при рассрочке (п. 63) |
| график | у рассрочки: даты и суммы платежей; строит модуль (`ИМ-90`) |
| проценты | у рассрочки: **3 % годовых на полную цену** (п. 58); по активам из поручительств ставку может задать Комитет |
| неустойка | ставка и база из договора — простое правило, без расчётного ядра кредита |
| сохранение права | «право переходит после полной оплаты» (`ИМ-9`) |

**Когда рассрочка доступна** (`ИМ-89`, Инструкция пп. 57, 63):

- не раньше 120 дней после перехода права, если за это время объявление вышло на сайте
  Госфинхолдинга, **не меньше 3 раз в республиканских и 3 раз в местных газетах** и на
  интернет-площадках;
- предельный срок — по цене с расходами: **до 1 млн — 3 года · от 1 до 5 млн — 5 лет · от 5 млн —
  10 лет**; длиннее не ввести;
- заявка на рассрочку проходит финансовый анализ заявителя (п. 39).

**Проценты — плоско** (`ИМ-90`): проценты = цена × ставка × срок в годах, поровну на платежи
графика. Пример: цена 2 490 000, первый взнос 249 000, 3 года, 36 платежей → проценты 224 100,
платёж 62 250 + 6 225 = 68 475. На остаток долга покупателя было бы ≈ 103 650; «на полную
стоимость или на остаток» — `ИМ-ВЗ-14`, ответ «на остаток» меняет только формулу графика.

**Деньги — только через Платежи** (`ИИ-6`). Оплата по договору КП регистрируется в Платежах как
поступление **вида «оплата по договору купли-продажи»** с адресатом «договор», а не кредит
(`ИМ-ДС-3`). Проценты — отдельной статьёй платежа на счёт Госфинхолдинга; цена — в очередь выручки
(§6.1). Так оплата попадает в сверку с казначейством и в окно ожидания зачисления, как любое
поступление.

Модуль сопоставляет поступления с графиком и сам считает **немного**: график, факт по графику,
просроченную сумму, дни просрочки, неустойку по ставке договора. Это ведение договора, а не
кредит.

Почему не кредит: у рассрочки нет ни госрешения, ни программы, ни заявки — цикл 01→05 держится
именно на них, и «кредит без основания» сломал бы инварианты корня.

После регистрации договора Сектор служебной запиской передаёт его в подразделение, которое
вносит сведения в АСУБК (Инструкция пп. 56, 62, 75); в модели это ввод договора КП с вторым ключом
(§10.2).

### 7.3. Право переходит после полной оплаты (`ИМ-9`)

```
 договор КП в рассрочку                         при неоплате
 ─────────────────────────────                  ──────────────────────────────────────────
 объект «продан в рассрочку», НЕ снят с учёта   досудебное урегулирование → решение органа →
 оплаты по графику … последний платёж           расторжение (с отделом по работе с проблемными
 → путь завершён → СНЯТ С УЧЁТА                 кредитами, п. 65) → объект снова «на учёте» →
                                                уплаченное: удерживается неустойка по условию
                                                договора, остаток — Возвратом
```

- Пока идёт рассрочка, право у Фонда: покупатель не перепродаст вещь, а при неоплате Фонд
  возвращает вещь, а не судится годами за деньги.
- **Расторжение — выход из пути**, а не новый путь.
- **Продление** (`ИМ-89`, Инструкция пп. 66–70): по заявлению покупателя с обоснованием — решение
  Комитета и дополнительное соглашение; не больше чем на 3 года; ставка с даты продления — 5 %
  годовых на ту же базу; отказ — ответ с причинами.
- Судебная работа против покупателя (не освобождает склад) — **журналом мер по договору**: дата,
  вид, документ, итог. Без машины фаз взыскания: долг покупателя — не бюджетный кредит, Порядок
  №41 к нему не относится.
- Режим «право переходит при подписании» **не строится** (`ИМ-50`): он тянет залог Фонда на
  проданную вещь со своим обращением взыскания и торгами. Инструкция момент перехода права при
  рассрочке не называет, упоминая лишь «регистрацию договора купли-продажи в рассрочку» (п. 62) —
  `ИМ-ВЗ-4` остаётся открытым.

### 7.4. Обращение в госсобственность и выбытие

- **Обращение в государственную собственность** (`ИМ-98`) — решение + акт передачи с основанием
  из перечня §5.3; второй ключ. Денег нет; результат по объекту = −(учётная стоимость + расходы).
  Доплата, если есть, — через расходную часть бюджета (п. 47, `ИМ-83`).
- **Выбытие** (гибель, утрата, снос) — акт; второй ключ. Если объект был застрахован, страховое
  возмещение — поступление в Платежах; в результате по объекту оно учитывается как цена
  (`ИМ-37`), доплата выплачивается в 30 дней от его поступления.
- Объект, принятый из залога в процессе банкротства, отчуждается в течение 3 лет (п. 17);
  за 90 к.д. до конца срока — повод (§9).

| дата | факт | состояние ИО-1 |
|---|---|---|
| 05.04.2027 | переход права; доплата 550 000 зафиксирована | на учёте |
| 15.04.2027 | уведомление бывшему владельцу о выкупе жилья через «Тундук», ответ до 15.05 | на учёте, преимущественное право открыто |
| 15.05.2027 | срок ответа истёк — отказ | на учёте |
| 20.05.2027 | объявление: 2 490 000 (2 400 000 + расходы 90 000), газеты, сайт, House.kg | выставлен на продажу |
| 19.06.2027 | окно заявок истекло без заявок | на учёте |
| 25.06.2027 | новое объявление на тех же условиях | выставлен на продажу |
| 01.07.2027 | заявки А (разово 2 490 000) и Б (разово 2 600 000) | выставлен на продажу |
| 09.07.2027 | Комитет: две заявки — открытые торги | выставлен на продажу |

### 7.6. Преимущественное право: жильё и доля (`ИМ-92`, `ИМ-93`)

**Жильё** — признак **объекта**, а не вида: жилой дом (в том числе с надворными постройками и
землёй под ним) или квартира, предназначенные и используемые для постоянного проживания
(Инструкция п. 30). Квартира под офис жильём не считается.

| шаг | правило |
|---|---|
| уведомление | бывшему владельцу по месту жилья или через «Тундук» — не позже 30 дней после перехода права; в нём предложение выкупа и срок ответа, не больше 30 к.д. |
| ответ | согласие · письменный отказ · срок истёк (молчание — отказ, п. 31) |
| согласие | договор КП с бывшим владельцем или близким родственником **без объявления**, по решению Комитета; цена = стоимость принятия + остаток долга + расходы |
| отказ | объявление третьим лицам по цене оценщика (п. 31); срок первого объявления (п. 35) отсчитывается от отказа |

Пока право открыто, объявление третьим лицам не открыть (`ИИ-9`): иначе Фонд продаёт квартиру
постороннему, пока у бывшего владельца не истёк срок, — прямое основание для иска о переводе прав
покупателя. Это тот же приём, что у обременения: право проверяется в момент продажи.

**Доля в общей собственности** (п. 32) — тот же гейт: извещение остальным участникам с ценой и
условиями; объявление третьим лицам — после их отказа или через **1 месяц** (недвижимость) /
**10 дней** (прочее имущество) со дня извещения.

### 7.7. Выкуп после погашения долга (`ИМ-94`)

Инструкция, раздел 8 (пп. 71–76): после полного погашения долга покупатель — сам должник или
другое лицо — вправе выкупить объект.

- Заявление → Комитет в течение 2 р.д. (п. 71) → договор КП **без объявления**.
- Цена — выкупная стоимость (по умолчанию стоимость принятия, `ИМ-ВЗ-15`) + расходы п. 43 (п. 72).
- Покупатель-должник — только при нулевом долге; у другого покупателя погашение долга должника не
  проверяется (п. 72).
- **Деньги должника после перехода права — оплата объекта** (п. 76): хвост его платежа в кредит
  сверх долга Платежи **переносят на договор выкупа** вместо Возврата (`ИМ-ДС-17`).
- Выручка — по очереди §6.1.

Пример: долг 3 000 000, квартира принята за 2 400 000, остаток долга с пенями 650 000, расходы
90 000. Должник вносит в кредит 3 140 000: 650 000 гасят остаток, хвост 2 490 000 переносится на
договор выкупа; договор оплачен → объект снят с учёта; в бюджет 2 400 000, Госфинхолдингу
90 000.

## 8. Возврат и исправления

### 8.1. Возврат — принятие отменено (`ИМ-14`)

Суд признал принятие недействительным (например, оценка занижена), вещь возвращается
отчуждателю.

- Модуль публикует факт **«принятие отменено»** с судебным актом — путь выбытия «возврат».
- Бухгалтер в Платежах делает **сторно поступления** «имущество в счёт погашения» задним числом
  — механизмом §4.1 канона платежей (`ADR-0058`). Сторнированное остаётся видимым.
- Пеня за разрыв «дата перехода права → дата отмены» **выводится, но помечается спорной** и
  уходит на Комиссию по спорным начислениям (§4.4 канона платежей, `ADR-0089`): чья вина в
  разрыве — заранее не ясно.
- Доплата отменённого принятия: ещё не выплачена (обычный случай, `ИМ-79` — выплата после
  продажи) — обязательство прекращается вместе с принятием; уже выплачена — её возврат Фонду —
  **требование к отчуждателю** (§8.3, `ИМ-54`); взыскивается вне модуля (`ИМ-ВЗ-7`).
- **Отмена раннего принятия после поздних (`ИМ-44`).** Если у того же обязанного лица позже
  перешло право на другую вещь, её деление считалось по долгу, уменьшенному отменённой вещью
  (`ИМ-43`), и теперь неверно. Лечится не правкой, а **исправлением** поздней позиции (`ИМ-23`,
  `ИИ-21`): новый факт «стоимость распределена» с основанием «отмена более раннего принятия»,
  с датой перехода права поздней позиции; исходный остаётся видимым. Платежи делают
  **корректировку суммы** поступления (§8.3 канона платежей), не сторно; взыскание переделяет.
  Доплата поздней позиции пересчитывается; если она уже выплачена, излишек — разница между
  выплаченной и пересчитанной — требование к отчуждателю (§8.3), взыскивается вне модуля
  (`ИМ-ВЗ-7`); если не выплачена — меняется только её сумма. Пример: долг 1 000 000 по П-1; оборудование ИО-1 500 000 (переход права
  15.03.2027), квартира ИО-2 700 000 (01.06.2027): распределено 500 000, не вошло 200 000;
  квартира продана 09.06.2027, оплата поступила 12.06.2027, доплата 200 000 выплачена 20.06.2027.
  10.09.2027 суд возвращает оборудование: сторно 500 000, долг
  восстановлен. На 01.06.2027 долг был 1 000 000, квартира покрывает 700 000 целиком, доплата
  должна быть 0. Исправление ИО-2: распределено 500 000 → 700 000, не вошло 0; корректировка
  поступления +200 000; требование к отчуждателю 200 000. Долг по П-1 после всех шагов 300 000.
- **Возврат возможен, только пока объект «на учёте» или «выставлен на продажу»** (§5.4а). Если вещь уже продана третьему лицу, суд
  обычно присуждает деньги: это не путь выбытия, а денежная компенсация отчуждателю через
  Возврат в Платежах (`ИМ-ВЗ-7`).

**Оговорка.** У поступления «имущество в счёт погашения» нет строки казначейства — денег не было.
Сверка с ЦК обязана такие поступления пропускать (`ИМ-ДС-5`).

### 8.2. Исправление опубликованного факта (`ИМ-23`)

**Публикация** — момент, когда факт уходит наружу: решение органа, акт, переход права,
исполнение доплаты, решение Комитета по заявке, итог торгов, договор КП, разделение, документ выбытия.

- **До публикации** черновик правится свободно: предложение на рассмотрении, позиция без
  решения, объявление и заявка до решения Комитета.
- **Факт, ждущий второго ключа**, тоже ещё не опубликован: автор правит его и отзывает. Заведующий
  Сектором возвращает его **с причиной**: факт уходит автору черновиком, причина видна в
  черновике; факт не удаляется (`ИМ-78`).
- **После публикации** факт неизменяем (`ИИ-12`). Ошибка лечится **исправлением** — новым фактом
  с основанием (исправленный документ или решение органа), который **замещает исходный с даты
  исходного**. Видны оба; исходный помечен «исправлен».
- Соседи получают «факт исправлен» и пересчитывают свою часть: Платежи — **корректировкой суммы
  поступления** (§8.3 канона платежей), не сторно; взыскание переделит.
- Исправление публикуется вторым ключом.

Пример: в акте набрали 2 040 000 вместо 2 400 000, погашение уже разделено, месяц закрыт в
статистике. Исправление → корректировка поступления на +360 000 с даты перехода права →
переделение → закрытый месяц статистики **помечается** (`ИС-50`), и видно почему.

Сторно здесь не подходит: оно сделало бы пени за три недели спорными и вынесло вопрос на
Комиссию — механизм для отмены принятия, а не для опечатки.

### 8.3. Требование к отчуждателю (`ИМ-54`)

Возникает, когда отчуждатель получил от Фонда деньги, которые теперь должен вернуть: исполненная
доплата по отменённому принятию (§8.1) или её излишек после переделения поздней позиции
(`ИМ-44`). Случай редкий, но сумма не должна теряться в журнале фактов.

| что | правило |
|---|---|
| факт «требование к отчуждателю» | сумма, валюта, должник по требованию (отчуждатель), основание (судебный акт, исправление); публикует модуль вместе с фактом, который его породил — тем же вторым ключом |
| где видно | карточка объекта (блок «Требование к отчуждателю · не погашено»), фильтр реестра объектов, колонка статистики (`ИМ-ДС-15`) |
| контроль | повод `pk-im-claim-open`, если требование открыто дольше порога (§9); адресат — куратор объекта |
| взыскание | **вне системы**: претензия, иск — без журнала мер и без машины фаз; отчуждатель не заёмщик, Порядок №41 к нему не относится |
| закрытие | факт «требование погашено» со ссылкой на поступление в Платежах (`ИИ-6`); частичная оплата — тот же факт на часть суммы, остаток = сумма − погашено (производная) |
| невозможность взыскать | факт «требование прекращено» с основанием (решение органа); остаток уходит в результат по объекту как потеря |

Деньги приходят обычным поступлением в Платежах без привязки к кредиту; второй адресат платежа
(`ИМ-ДС-3`) для требования не нужен — связь держит факт «погашено» в модуле.

Пример (продолжение §8.1): 10.09.2027 исправление ИО-2 порождает требование к брату 200 000.
На 09.11.2027 (60 к.д.) оплаты нет — повод `pk-im-claim-open` куратору ИО-2. 01.12.2027 брат
платит 200 000 — специалист вводит «погашено» со ссылкой на поступление; блок в карточке
закрывается.

## 9. Мониторинг и поводы (`ИМ-15`)

**Модуль публикует поводы, Задания поручают.** Модуль ведёт журнал осмотров и объявляет
критерии; модуль Задания забирает их **опросом** (`ADR-0229`, ключ «вид + объект + период») и

  Сроки Инструкции стоят с источником «Инструкция»; где Инструкция молчит — «внутренний акт».
  Продлённый срок (п. 5, факт «срок продлён») сдвигает порог повода по этому объекту.
- **Просрочка рассрочки — 5 к.д.** (`ИМ-55`): то же умолчание, что у окна ожидания зачисления
  во взыскании (Р-8, ≤ 7 к.д.). Платёж, сделанный в срок через банк, казначейство зачисляет с
  задержкой; порог в один день будил бы куратора по заплатившему покупателю. Неустойка по
  договору считается от даты графика, как в договоре, — порог касается только повода.
- **Порог осмотра — по виду** (`ИМ-56`): в Настройках модуля таблица «вид → порог»; пустая
  строка берёт умолчание 6 мес. Заполняются только исключения (скот, зерно — 1 мес.). Справочник
  видов Залога не трогается: у Залога периодичность задаёт своя матрица (Р-3 канона залога),
  платёжеспособность должника для вещи Фонда смысла не имеет.
- Ключ повода устойчив: вид + id объекта + период (месяц для «давно не осматривали», номер
  платежа для просрочки; для `pk-im-act-pending` — id предложения + номер позиции + месяц; адресат — куратор
  предложения).
- **Журнал осмотров**: дата, участники, состояние, фото и видео, документ. Без него повод «давно
  не осматривали» нечем измерить, а решения о снижении цены и о выбытии опираются на акт осмотра.
- Реестр объектов дополнительно даёт **фильтры** поверх поводов — удобство, а не контроль.
- Мониторинг **не видит** просрочку арендатора (`ИМ-30`) — осознанная граница.

## 10. Кураторство, роли и второй ключ

### 10.1. Кто ведёт (`ИМ-16`, `ADR-0259`)

Кураторство расширяется: в закрытые списки добавлены **два объекта закрепления** — предложение
имущества и объект имущества — и **одна роль** — куратор имущества.

- Правило холдинга называет подразделение — по умолчанию Сектор по работе с активами Департамента правового обеспечения (`ИМ-96`).
- Правило подразделения называет работника по признакам: **область и район местоположения**,
  вид имущества (для права — место регистрации или эмитента).
- Для **предложения** признаки (область, район, вид) берутся с позиции с наименьшим номером
  среди позиций без итога «отозвана» и «отказана»; когда она получает такой итог, признаки
  берутся со следующей. Предложение без таких позиций держит фолбэк (`ИМ-46`). Объекты, рождённые из других позиций,
  получают своих кураторов по своему местоположению.
- Пороги давности фолбэка для имущества — в кураторстве (`docs/logika/20-kuratorstvo.md` §7):
  предложение 2 р.д., объект имущества 10 р.д.; умолчания, источник «внутренний акт»
  (`ИМ-45`, `ИМ-ВЗ-8`). Порог — сколько рабочих дней предложение или объект может оставаться без
  работника у заведующего отделом; после порога объект подсвечивается отделу.
- Ответ «кто ведёт» — только закреплением на дату (`ИИ-16`); поля «ответственный» у объекта нет.
- Куратор кредита объект **не ведёт**: другая работа, другое подразделение, а долг после
  принятия может быть закрыт, тогда как склад остаётся.
- Задания берут адресата поводов отсюда; без этого — хардкод адресата, как `E4` в волне 4 заданий.

### 10.2. Роли доступа и второй ключ (`ИМ-26`)

Роли доступа — не роли кураторства (глоссарий). **Специалист по имуществу** — право вводить
факты модуля; куратором конкретного объекта он становится закреплением.

| действие | готовит | публикует вторым ключом |
|---|---|---|
| предложение, позиции, заключения, осмотры, оценки, расходы, обременения | специалист по имуществу; предложение ССИ — отдел по работе с проблемными кредитами (Инструкция п. 8) | — (черновик / денег не движет) |
| решение органа по позициям | секретарь органа | — (документ органа сам контроль) |
| акт приёма-передачи, переход права, отказ регистратора, решение о прекращении принятия | специалист | **заведующий Сектором по работе с активами** |
| исполнение доплаты | бухгалтер (в Платежах) | — (контур Платежей) |
| объявление, публикации, заявка; уведомление о выкупе и ответ | специалист | — (денег не движут) |
| решение Комитета по заявке, о торгах, о выкупе, о продлении рассрочки | секретарь органа | — (документ органа сам контроль) |
| итог открытых торгов | специалист | — (итог из протокола торгов) |
| договор КП, условия рассрочки, продление, расторжение | юрист | заведующий Сектором |
| разделение | специалист | заведующий Сектором |
| обращение в госсобственность | специалист | заведующий Сектором + решение органа |
| выбытие | специалист | заведующий Сектором |
| возврат по суду (сторно погашения, `ИМ-14`) | специалист | заведующий Сектором |
| исправление опубликованного | любая роль модуля | заведующий Сектором |
| исправление позднего принятия при отмене раннего (`ИМ-44`) | специалист | заведующий Сектором |
| требование к отчуждателю (`ИМ-54`) | возникает вместе с порождающим фактом | тем же ключом, что порождающий факт |
| требование погашено (ссылка на поступление) | специалист | — (деньги уже в контуре Платежей) |
| требование прекращено (остаток — потеря) | специалист | заведующий Сектором + решение органа |
| вводный объект из черновика миграции (`ИМ-59`) | специалист | заведующий Сектором |

Второй ключ — **только на факты, двигающие деньги или стоимость** (`ИИ-15`): ключ на всё
превратил бы начальника в штамп, и контроль пропал бы именно там, где нужен. Состав ролей в
модуле пользователей — `ИМ-ДС-10`.

- **Одна очередь второго ключа** (`ИМ-72`). Все неопубликованные факты и дополненные черновики
  миграции собраны в один список «Ждут второго ключа»; число — в меню модуля. В карточках и
  реестрах — только строка «ждут здесь: N» со ссылкой на очередь. Заведующий Сектором
  публикует или возвращает с причиной, автор правит и отзывает своё (§8.2).
- **Поступления в модуле не вводятся** (`ИМ-73`). Оплата по договору КП и исполнение доплаты
  приходят из Платежей (§7.2, `ИМ-5`); в «Ввести факт» их нет, в журнале фактов автор — Платежи.
  Роли «Бухгалтер» в модуле остаётся только исправление.

### 10.3. Журнал

Каждый факт несёт: кто ввёл, кто опубликовал, когда, документ. Исправления и замещённые факты
видны. Аудит пользовательских действий — общий модуль аудита, не этот.

- **Документ факта** — номер, дата и файл (`ИМ-69`); у осмотра — ещё фото и видео (§9). Файл —
  вложение подсистемы документооборота (`ADR-0270`), модуль хранит ссылку на него (`ИМ-34`).
- В журнале номер документа ведёт к файлу; новые факты — сверху (`ИМ-75`).

- Меры-проекции не правятся и не заводятся руками во взыскании: один факт в двух местах — копия,
  запрещённая `ADR-0004` и `ADR-0026`.
- **Продажа объекта Фондом в дело должника не попадает** — кроме погашения из выручки (`ИМ-91`):
  объявления, заявки и договор КП долга не меняют, а третья очередь выручки меняет и потому видна в
  деле мерой-проекцией. Вторую меру ТЗ («реализация принятого имущества») закрывает сам модуль:
  объявления и договор КП и есть она.
- Как машина фаз реагирует на проекции — решает канон взыскания (`ИМ-ДС-7`); предложение
  модуля — проекции фазу **не двигают**, фазу закрывает погашение по обычным правилам.

### 11.2. Статистика и отчётность (`ИМ-22`)

Модуль — производитель строк на дату; число на дату берётся только у статистики (`ADR-0222`).

| объект статистики | показатели | разрезы |
|---|---|---|
| **17 — объект имущества** (`stat_row_asset`) | количество; учётная стоимость; расходы содержания; результат по объекту; дней на учёте; число объявлений и заявок; по договору КП — остаток к оплате, просрочено (сумма, дни), проценты; доплата — сумма, к выплате, удержано, выплачено; выручка по очередям; требование к отчуждателю — остаток (`ИМ-54`, `ИМ-ДС-15`, `ИМ-ДС-22`) | состояние на дату, вид, класс, область/район, источник, вид долга, путь выбытия, состояние доплаты, ⚑ обременён, ⚑ жильё |
| **18 — предложение имущества** (`stat_row_asset_offer`) | количество; позиций принято / отказано / отозвано / не состоялось (шт., стоимость); дней рассмотрения; ответов после срока | источник, итог, орган |

Договор КП отдельным объектом статистики не заводится: у объекта не больше одного действующего
договора, поэтому его показатели — колонки объекта. Набор минимален и весь производен; расширять
его — дело статистики без правки модуля.

- Три реестра отвечают на три разных вопроса разных людей: «что предлагают и где ответ
  просрочен» (куратор), «что у нас лежит» (руководство, куратор), «кто нам должен за проданное»
  (юрист, бухгалтерия).
- Фильтр «состояние на дату» — прямое следствие `ИМ-13`: не текущий статус, а вычисление.
- Вкладка «Обременения» добавлена к составу `ИМ-25` решением `ИМ-31`.
- Кнопок «сменить статус» нет — только «ввести факт» (§5.1).
- Во взыскании предложение видно проекцией (`ИМ-18`), отдельного входа там не нужно.
- «Миграция из легаси» — отдельный пункт, а не низ реестра объектов (`ИМ-61`): это разовая работа к
  запуску. После закрытия миграции пункт убирается, отчёт миграции остаётся только для чтения.
- Поводы для Заданий списком — не экран модуля (`ИМ-62`): по ним работают в Заданиях, в карточках
  поводы показаны полосой (`ИМ-63`). В «Настройках» — только пороги.
- «Печать» в обеих карточках открывает бланки Отчётности (`ИМ-ДС-11`, окно «Печать» `ВБ-14`).

  «Промежуточное письмо» — разные пункты с разными подписями.
- «Документы» — у объекта вкладкой, у предложения блоком после журнала фактов (`ИМ-70`, заявка

  видимости документооборота: право видеть объект не даёт права видеть его документы.
- Правила экрана (`ИМ-60`, `ИМ-66`, `ИМ-74`, `ИМ-76`, `ИМ-77`):
  - рабочая область — во всю ширину;
  - над каждым реестром «Показано N из M», шапка таблицы закреплена; сортировка и постраничный
    вывод — стандартные;

  - ошибка формы — у поля, обязательное по правилу поле помечено;
  - автор факта везде называется «Ввёл».

## 13. Вводный остаток и миграция (`ИМ-29`)

На дату запуска у Фонда уже есть объекты, принятые в прошлые годы. Старая система экранов
имущества не имеет (`requirements/legacy/`), погашения по ним прошли видом «принятие имущества
в счёт погашения».

- Объект возникает **вводом остатка**: основание — документ бухгалтерии (выписка, ведомость);
  стоимость принятия, дата перехода права, обязанное лицо, источник — из документов, если есть.
- Ссылки на предложение и решения органа нет; фиктивные предложения не заводятся — это были бы
  ложные документы в системе с аудитом.
- **Вводный остаток погашения не порождает** (`ИИ-3`): оно уже прошло и переносится вместе с
  платежами. Иначе долг уменьшится второй раз.
- **Контроль миграции:** сумма мигрированных погашений вида «имущество в счёт погашения» по
  каждому обязанному лицу сходится с суммой стоимостей его вводных объектов; расхождение —
  блокирующий отчёт миграции.
- Дальше вводный объект живёт как любой другой: осмотры, объявления, выбытие.
- Где сейчас учитывается имущество и в каком виде его отдадут — `ИМ-ВЗ-11`.

### 13.1. Скелет из легаси (`ИМ-59`)

Список того, что Фонд когда-то принял, **строится из легаси, а не ждёт бухгалтерию**. В старой
системе экранов имущества нет, но каждое принятие прошло платежом вида «принятие имущества в
счёт погашения» (`requirements/legacy/12-dictionaries.md:86`) — с заёмщиком, датой и суммой; у
мер взыскания есть событие 18 «Принятие имущества» (`requirements/legacy/20-e2e-cycle-plan.md:452`).

```
 легаси: платёж «принятие имущества»          АСУБК: черновик вводного объекта
 Х · 2021 · 2 400 000 ────────────────────►   обязанное лицо Х · дата 2021 · стоимость 2 400 000
                                               вид, место, характеристики — пусто
                                               состояние на запуск — не указано
                                                  │ Сектор дополняет по документам
                                                  ▼
                                               дом · Бишкек · продан 2023 (факт выбытия)
                                               → вводный объект «снят с учёта»
```

- **Один платёж легаси — один черновик.** Если одним платежом погашено несколько вещей,
  черновик делится на несколько при дополнении; сумма частей = сумма платежа.
- **Дополняет Сектор по работе с активами** по документам: вид, местоположение,
  характеристики, источник и, главное, **что с вещью сейчас** — на учёте, продана, передана,
  выбыла. Проданная до запуска вещь мигрирует **вместе с фактом выбытия**: иначе статистика за
  прошлые годы врёт, а контроль миграции не сходится.
- **Черновик без документов** — строка «не подтверждён» в отчёте миграции; он **блокирует
  миграцию**, пока не подтверждён или не снят решением с основанием («вещь не найдена,
  погашение — ошибка легаси» уходит в разбор платежей, а не в имущество).
- Контроль «Σ погашений = Σ стоимостей» по каждому обязанному лицу сходится **по построению**;
  ловит он теперь только незаполненные черновики.
- Вопрос заказчику сужается: не «где у вас учёт», а «дайте документы по этим N объектам»
  (`ИМ-ВЗ-11`).
