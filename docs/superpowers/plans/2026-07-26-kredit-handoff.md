### 1.2 Ключевые архитектурные решения мокапа (Р-1…Р-21)

Полный список — в шапке `credit.html`. Костяк:

- **Р-1** транш = единица учёта, кредит = агрегат.
- **Р-5…Р-10, Р-16** зеркала чужих модулей — read-only.
- **Р-11** производные (покрытие, долг, оси, резерв) считаются в рантайме,
  ни одно не хранится в модели. Одна чистая функция `derive(credit)`.
- **Р-19** состав колонок реестра.
- **Р-20** терминальные состояния, физического удаления нет.
- **Р-21** условия = записи на параметр на транше: `param · value · effectiveFrom ·
  basis · note`. Действующий комплект и исторический срез — производные
  (`conditionsAt`, `creditConditionsAt`), не хранятся. Реестр `PARAMS` из 10 ключей.
  `basis.kind` ∈ application / agreement / court / govAct.

## 5. Правила репозитория, обязательные для субагентов

- Репозиторий — **координация, QA и документация**, не исходники приложения.
- Нумерация: `Pn-NN` — дефекты в `notes/qa-findings.md`; `Pn-Rn` — рекомендации
  в `TODO.md`. Счётчики независимые, не смешивать. В `requirements/legacy/*`
  префикс `Pn` означает **модули старой системы** — это третье, несвязанное значение.
- Обозначения этого модуля: **Р-\*** решения · **Г-\*** гейты (жёсткий блок с причиной) ·
  **§** разделы канона.
- Шкала важности: 🔴 блокер · 🟠 крупный · 🟡 мелкий · 🔵 косметика.
  Приоритеты в `TODO.md`: 🔴 Высокий / 🟡 Средний / 🟢 Низкий.
- Любое утверждение о поведении приложения подкрепляется проверкой с датой и ссылкой
  на скрипт инспекции.
- При правке `STATUS.md` обновлять строку «Last updated».
- Правка `TODO.md` через инструменты Claude Code запускает хук синхронизации с Google Sheet.
  Правка внешним редактором — нет.
- `service-account.json` в корне — git-ignored, **никогда не коммитить**.
- Язык всех артефактов — русский.
