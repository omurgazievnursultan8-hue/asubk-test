# «Условия»: карандаш в заголовке карточки вместо ленты с кнопкой — дизайн

**Дата:** 2026-08-11 · **Макет:** `mockups/loan-credit/credit.html`
**Основание:** Р-21 (версионные записи условий), гейты Г-9/Г-10/Г-22
**Смежное:** [ADR-0111](../../adr/0111-vid-ds-razvodit-marshruty-izmeneniya-usloviy.md) —
сужает эту дверь до зоны «вне п. 89»; в объём волны не входит
**Спека логики:** [ASUBK-kredit-logika.md](../../../mockups/loan-credit/ASUBK-kredit-logika.md)

## Задача

Вкладка «Условия» открывается лентой `.gtoolbar` с единственной кнопкой «Изменить
условия» (`credit.html:6522–6531`, `btn btn-primary btn-sm`). Лента занимает целую
строку плюс 14px отступа, справа от кнопки — пустота во всю ширину вкладки.

Действие при этом оторвано от того, что правит: параметры лежат в карточках «Ставки»
и «Погашение» ниже, а кнопка висит над обеими. В том же файле уже есть противоположный
образец — «Реквизиты договора» (`credit.html:6346`) держит карандаш **в своём заголовке**,
`roleIconBtn(...svgPencil())` в `.section-h` с `justify-content:space-between`.

После [ADR-0111](../../adr/0111-vid-ds-razvodit-marshruty-izmeneniya-usloviy.md) вес
действия ещё и упал: прямое доп. соглашение правит шесть параметров из шестнадцати
(`penaltyMain` · `penaltyInt` · `reserveRate` · `dayMethod` · `earlyRepayMoratorium` ·
`earlyRepayFee`), остальные заперты за конвейером реструктуризации. Главная кнопка
вкладки обещает больше, чем дверь даёт.

## Решения (приняты владельцем 11.08.2026)

1. **Лента удаляется целиком, карандаш встаёт в заголовок карточки.** По карандашу в
   «Ставках» и в «Погашении». Отвергнуто: иконка в полосе вкладок — `.detail-tabbar`
   (`credit.html:1249`) это горизонтальный скролл с шевроном в `right:8px`, свободного
   края нет; карандаш у каждого поля — шесть иконок в зоне «вне п. 89» дают шум, а одно
   ДС на два поля всё равно требует пакетной модалки.
2. **Модалка фильтруется по группе карточки.** Карандаш обещает «правлю вот это» —
   модалка обязана держать обещание. Иначе карандаш у «Погашения» показал бы и ставку.
   Отвергнуто: чистый перенос без фильтра (минимальный дифф, но два входа в одно и то же).
3. **В отказе карандаш гасится, а не исчезает.** Три причины (терминал · роль · ЖЦ) —
   каждая уходит в `title` и в toast по клику. §0.3 запрещает молчаливый отказ: при ЖЦ
   «Проект» пользователь обязан прочитать, что условия там правятся напрямую (Г-22),
   а не обнаружить пустой заголовок.
4. **Группа `repay` считается вычитанием из `PARAM_KEYS`.** Ленты наверху больше нет, и
   параметр, не попавший ни в одну группу, остался бы вовсе без двери. Тот же приём, что
   у `MATRIX_ZONE_REPAY` (`credit.html:1774`).
5. **Группы карандашей ≠ `MATRIX_ZONE_*`.** В зонах сводной матрицы льготы отнесены к
   «Ставкам» (двухколоночная раскладка матрицы), а карточка «Ставки» льгот не рисует —
   переиспользование зон сделало бы фильтр модалки враньём. Два реестра, каждый со своим
   комментарием о назначении.
6. **Карточку «Приостановки начисления» не трогаем.** У неё своё действие своей кнопкой
   внизу (`credit.html:6566`) — это другой документ и другой гейт, не запись условия.

## Реализация

### Удаляется

`credit.html:6522–6531` — `<div class="gtoolbar" style="margin-bottom:14px">` вместе с
IIFE, разводящей три состояния кнопки. Каскад причин переезжает в `condIconBtn` без
изменения смысла. Блок ретро-предупреждения выше (`warn-inline` с «Перейти к
перегенерации графика», Д-5) остаётся на месте — он не в удаляемой ленте.

### Реестр групп

Рядом с `MATRIX_ZONE_*` (`credit.html:1772–1774`):

```js
/* Группы карандашей вкладки «Условия»: ровно то, что рисует карточка.
   НЕ MATRIX_ZONE_*: там льготы отнесены к «Ставкам» — это раскладка сводной
   матрицы, а карточка «Ставки» льгот не показывает. REPAY считается вычитанием,
   чтобы новый параметр не остался без двери: ленты с общей кнопкой больше нет,
   и ключ, не попавший в группу, стал бы недоступен для правки вовсе. */
const COND_CARD_RATES = ['rate','reserveRate','penaltyMain','penaltyInt'];
const COND_CARD_REPAY = PARAM_KEYS.filter(k => !COND_CARD_RATES.includes(k));
```

### Хелпер гейта

`roleIconBtn` (`credit.html:6062`) не подходит: он знает терминал и роль, но не ЖЦ.
Рядом с ним:

```
condIconBtn(title, onclick) → HTML иконки-карандаша
    terminal(c)                          → погашена, terminalReason(c)
    !canRole(role,'addConditionRecords') → погашена, «Роль … не имеет права»
    ЖЦ ∉ {Зарегистрирован, Действует}    → погашена, текст Г-22
    иначе                                → активна
```

Погашенное состояние — тот же приём, что у `disabledBtn`: `opacity:.45`,
`cursor:not-allowed`, `title`, `onclick="CR.toast(...,'warn')"`.

### Заголовки карточек

| Было | Стало |
|---|---|
| `<div class="section-h">Ставки</div>` | `.section-h` + `display:flex;align-items:center;justify-content:space-between` + `condIconBtn('Изменить ставки', "CR.openCondModal('rates')")` |
| `<div class="section-h">Погашение</div>` | то же, `condIconBtn('Изменить условия погашения', "CR.openCondModal('repay')")` |

Инлайн-стиль — копия `credit.html:6346`, не новый класс: образец в файле уже инлайновый,
а второй способ записи того же самого разошёлся бы с ним при первой правке.

### Модалка

`CR.openCondModal(group)` (`credit.html:7811`) — необязательный аргумент:

- `'rates'` / `'repay'` → `CR.PARAMS.filter(p => COND_CARD_*.includes(p.key))`;
- без аргумента → все шестнадцать (вызовов не остаётся, но сигнатура не ломается).

Заголовок модалки — «Изменение условий — ставки» / «— погашение» / «Изменение условий».
Остальное без изменений: тип основания, номер/дата/скан ДС, дата вступления, примечание,
транши, предпросмотр «было → станет». `condRecalcDefaults` и `condPreview` ходят по
`CR.PARAMS` целиком и отсутствующие в DOM поля уже пропускают (`if(!el) return`) —
правки не требуют.

## Приёмка

- `node scripts/inspect/credit-check.mjs` — без регрессий; смоук растёт со `112/112`
  до `114/114`: два новых кейса в БЛОКе 3 (слой рендера, DOM-заглушка) — разбиение
  `PARAM_KEYS` группами и два карандаша на вкладке «Условия». Скрипт сам впечатывает
  стамп в шапку `credit.html`, поэтому файл меняется и попадает в коммит;
- `npm run test:credit` (`mockups/loan-credit/tests/scope.test.mjs`, JSDOM, 38 тестов) —
  T2-4 рендерит «Условия» и проверяет только блок расхождений; правок в тестах не нужно;
- визуальная проверка: лента исчезла, вкладка начинается с карточек; карандаш в обоих
  заголовках; под ролью без права и при ЖЦ «Проект» карандаш виден погашенным и объясняет
  причину; модалка из «Ставок» показывает четыре параметра, из «Погашения» — остальные;
- запись КВ-25 в `mockups/loan-credit/ASUBK-status-razrabotki.md`.
