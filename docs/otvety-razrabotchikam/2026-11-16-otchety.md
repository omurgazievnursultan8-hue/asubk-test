# Ответы на вопросы по отчётам

Числа в примерах условные. Если ответ требует правки постановки, она названа в конце ответа и собрана в последнем

## Общий вопрос

### 1. Отчёты за прошлые периоды

**Граница — дата запуска системы.** С этой даты история полная: всё ведётся в системе.

**Месяцы до запуска закрываются переносом из старой системы**, один раз, при запуске:

- глубина — не меньше чем с декабря позапрошлого года по месяц перед запуском. Иначе колонке «аналогичный период» на
  начало прошлого года не на что опереться. Пример: запуск 01.01.2027 → перенос декабрь 2025 … декабрь 2026, 13 месяцев;
- перенос даёт итог на конец каждого месяца по каждому договору и события платежей;
- перенесённые числа окончательные: система их не пересчитывает, такой период не открывается. Исправить их можно только
  новой версией переноса. Её утверждает ответственный, каждая изменённая строка пишется в журнал;
- если новая версия изменила число, по которому отчёт уже сдан, сданный выпуск получает отметку «числа изменились после
  сдачи» и сам не переиздаётся.

**Формирование отчёта не запрещается, общая отметка «неполный» не ставится.** Неполнота показывается в той клетке, где
она есть, с причиной:

| Случай | Что видно в отчёте | Окончательная сдача |
|---|---|---|
| месяц после запуска | свои числа | можно после закрытия месяца |
| месяц перенесён | числа; у колонки сноска «из старой системы, перенос от …» | можно |
| месяц перенесён, но такую величину старая система не собирала | пустая клетка «в старой системе не собиралось», **не 0** | можно |
| перенесён итог месяца, но не события | клетка потока пуста: «события не перенесены» | можно |
| месяц перенос не закрыл (глубже переноса) | отчёт формируется только предварительным | нельзя: отказ перечисляет месяцы — «до запуска системы, переносом не закрыт» |

У колонки, которая пересекает дату запуска (например, «с начала года» при запуске в середине года), сноска называет,
какие месяцы перенесены, какие свои.

**Пока не определено:** переносятся ли планы, документы, задания и события взыскания. Это решит постановка переноса
данных. Если не переносятся, в отчётах по ним (ФО-06, ФО-54, ФО-17, ФО-19, ФО-20) клетки периода до запуска пусты с
причиной «до запуска не велось».

## Кредиты, платежи и риск

### 2. ФО-02 — «Возвратность, %»

**Формула:** погашено основного долга с начала кредита ÷ основной долг, срок которого по графику наступил с начала
кредита. Обе суммы — по дату состояния.

| | Правило |
|---|---|
| Что входит в «погашено» | основной долг, закрытый деньгами, зачётом или принятым имуществом. **Не входят:** списание, прощение при реструктуризации, отменённые платежи |
| По какому графику «наступило» | по графику, **действующему на дату состояния**. После реструктуризации — по новому графику: перенесённая просрочка перестаёт быть наступившей. Поэтому возвратность меньше 100 % тогда и только тогда, когда есть просрочка по основному долгу |
| Досрочное погашение | у каждого кредита «погашено» ограничивается наступившим: **не больше 100 %**. Внесённое досрочно засчитывается по мере наступления сроков |
| Знаменатель 0 (срок ещё не наступал) | клетка **«—»**, не 0 % и не 100 % |
| Строки разрезов и ИТОГО | сумма ограниченных «погашено» ÷ сумма «наступило», **не среднее процентов**. Кредиты с «—» в расчёт не входят |
| Валютный кредит | у кредита — в валюте договора; в итогах обе части переводятся одним курсом на дату состояния |

Пример:

| Кредит | Наступило | Погашено | Возвратность |
|---|---|---|---|
| Ак-Дан | 2 600 | 2 600 | 100,0 % |
| Нарын-Агро | 2 100 | 1 400 | 66,7 % |
| досрочник | 1 000 | 1 800 | 100,0 % (без ограничения было бы 180 %) |
| новый, льготный период | 0 | 0 | — |
| **ИТОГО** | 5 700 | 5 000 в расчёте | **87,7 %** (без ограничения было бы 101,8 %, и долг Нарын-Агро был бы не виден) |

### 3. ФО-04 — по какой территории группировать

**По территории кредита — месту реализации проекта.** Не по адресу заёмщика: юрлица часто зарегистрированы в Бишкеке,
и региональная картина ушла бы в столицу.

- территория кредита — поле кредита, четыре уровня справочника: область › район или город › айыл окмоту › село;
- при регистрации кредита заполняется из заявки, дальше правится с датой действия;
- отчёт за период берёт территорию на дату платежа, отчёт на дату — на дату состояния;
- не заполнено → строка «Территория не указана», кредит из отчёта не пропадает;
- адрес заёмщика — разрез отчётов по заёмщикам, в отчётах по кредитам не используется.

### 4. ФО-06 и ФО-54 — план 0

**План месяца может быть 0,00.** Это записанное решение «в этом месяце ничего не ждём» (льгота, суд, отсрочка), и оно
отличается от отсутствия плана:

| | ФО-06 (клетка месяца) | ФО-54 |
|---|---|---|
| план 0,00 | **0,00** | месяц с планом: его факт идёт в «погашено в месяцы с планом» и в исполнение уровня; исполнение самого месяца «—» |
| плана нет | **пусто** | месяц без плана: факт справочно, в исполнение не входит |

Пример: ДАК, март. По другим кредитам план 1 000, факт 900. Кредит в льготе с планом 0,00 неожиданно заплатил 50.
Исполнение ДАК = (900 + 50) ÷ 1 000 = 95 %.

Снять план остаётся отдельным действием. **Правка постановки:** ТЗ 05, проверка Г-30 — «сумма больше нуля» →
«сумма не меньше нуля».

### 5. ФО-06 и ФО-54 — состав плана и редакция

**План утверждается по статьям.** Официальное ТЗ требует сумму по плану и невыполненную планом сумму «всего, по
основной сумме, процентам и штрафам».

- план месяца — три суммы, каждая не меньше 0: основной долг, проценты (вместе с накопленными), штрафы (вместе с
  накопленными). «Всего» — их сумма. Месяц с планом — тот, у которого есть запись, даже если все три суммы нулевые;
- подсказка при заведении: основной долг и проценты — из прогноза, штрафы — 0;
- ФО-06: «За год» — всего и по статьям; кварталы и месяцы — одной суммой;
- ФО-54: исполнение — по сумме строки; к «Недобору к плану» добавляется «в том числе» по статьям.

Пример: КЗ-03, сентябрь. План: основной долг 30,000, проценты 4,667, штрафы 0. Погашено: основной долг 15,333, проценты
4,667. Исполнение: основной долг 51,1 %, проценты 100 %, всего 57,7 %.

**Какую редакцию показывать.** У обоих отчётов есть параметр «План на»: по умолчанию сегодня, с правками, внесёнными по
вчерашний день. Можно выбрать любую дату — план показывается таким, каким был на эту дату. Каждая правка плана хранится:
кто, когда, прежнее значение. Колонка «План изменён» — дата последней правки.

### 6. ФО-08 — прекращение права на неосвоенный остаток

**Основание — документ из справочника видов основания.** У основания: вид, номер, дата, файл.

1. Дополнительное соглашение о прекращении освоения (по согласию сторон).
2. Решение уполномоченного органа Фонда (кредитного комитета или Правления) о прекращении финансирования — одностороннее,
   например при нецелевом использовании.
3. Письменный отказ заёмщика от остатка, принятый решением Фонда.

Срока освоения как поля нет. Само по себе истечение срока основанием не служит, нужен один из документов выше.

**Дата закрытия — дата вступления основания в силу.** Кто и когда внёс, хранится отдельно. С этой даты:

- в ФО-08 «Не освоено» = 0, состояние «Освоение закрыто» с датой и основанием;
- плата за неосвоенный остаток не начисляется; начисленное до этой даты остаётся долгом;
- если дата попадает в закрытый период — действует общий порядок открытия периода.

Пример: КЗ-12, договор 6 000, освоено 4 500. Решение кредитного комитета № 7 от 10.10.2026, внесено 15.10.2026. ФО-08 на
12.10: не освоено 0, «Освоение закрыто 10.10.2026»; плата с 10.10 не начисляется.

**Правка постановки:** ТЗ 05 §6 — «Освоение закрыто — договор закрыт при неосвоенном остатке» заменить на «неосвоенный
остаток закрыт основанием; кредит продолжает действовать».

### 7. ФО-09 — условия кредита

**Разная периодичность основного долга и процентов возможна.** Пример: проценты ежеквартально, основной долг раз в
полгода после 12 месяцев льготы.

- у транша отдельно периодичность и месяцы платежей для основного долга и для процентов;
- день платежа один, срок окончательного погашения один;
- льготы по основному долгу и по процентам — как сейчас, отдельно;
- ФО-09 показывает обе периодичности в группе «Погашение».

**Правка постановки:** реестр условий транша (ТЗ 05) — вместо `freq`/`payMonths` четыре ключа: `freqMain`,
`payMonthsMain`, `freqInt`, `payMonthsInt` (15 → 17 ключей).

**Плата за неосвоенный остаток применяется**, если её ставка больше 0. У большинства кредитов ставка 0, тогда платы нет
вовсе.

- пять условий **уровня кредита**, не транша: ставка, начало начисления, периодичность, день платежа, пеня по плате;
- утверждаются **кредитным договором**. Кредитная программа даёт значения по умолчанию, они приходят из заявки; меняются
  дополнительным соглашением — как обычное условие с основанием и датой действия;
- база — сумма договора минус всё освоенное по кредиту, включая сумму, ещё не распределённую по траншам;
- начало начисления — условие договора, по умолчанию дата договора. Начисление идёт с начала, а не с момента просрочки
  выборки. Останавливается, когда база стала 0 или когда закрыт неосвоенный остаток (вопрос 6);
- оплата: долг по статье «Проценты» на отдельном транше платы. В очереди погашения стоит на месте процентов, внутри
  статьи — последним. Кредит не закрывается, пока плата не погашена.

### 8. ФО-10 и ФО-58 — где реструктуризация как событие

**В ФО-58 реструктуризации нет.** ФО-58 показывает изменения статуса кредита и смену заёмщика: регистрацию, вступление
в действие, закрытие с причиной, перевод долга. Реструктуризация меняет условия, а не статус и не заёмщика.

Реструктуризация как событие видна:

- в **ФО-10** «Обращения о реструктуризации за период» — обращение, его стадии, исход и соглашение;
- в **ФО-09**, вид «Изменения условий кредитов за период» — дополнительное соглашение и что оно изменило (было → стало).

**Несколько соглашений по одному кредиту за период — каждое отдельной строкой:**

- в ФО-09 «Изменения условий» строка — одно дополнительное соглашение (номер, дата, что изменилось);
- в ФО-10 строка — одно обращение; соглашение — в строке своего обращения.

Ссылки на ФО-58 в описаниях ФО-10 и ФО-09 устарели и будут убраны.

### 9. ФО-11 — прощение при реструктуризации и возврат списанного

**Прощение при реструктуризации входит в ФО-11 отдельным видом.** Прощение уменьшает начисленное без поступления
денег — это списание. Колонка «списано» в ФО-07 равна ФО-11, поэтому без прощения отчёты разойдутся.

- новая колонка «Основание списания»: «списание безнадёжной задолженности» или «прощение при реструктуризации»;
  по ней доступны разрез и отбор; по умолчанию показываются оба вида;
- колонка «Вид списания» (весь долг / часть долга) остаётся.

**Вид «Списанная задолженность на дату» показывает только списание безнадёжной задолженности.** Прощённый долг
прекращён, ждать по нему нечего. Списанный безнадёжный долг остаётся требованием, взыскание может продолжаться.

**Возврат ранее списанного** — поступление по кредиту с датой после даты списания, сверх несписанной задолженности:

- считаются деньги, зачёт, принятое имущество, взысканное в ходе взыскания;
- в пределах списанной суммы; излишек — переплата, общий порядок;
- отменённые поступления не считаются;
- при списании части долга поступления сначала гасят несписанный остаток по обычной очереди; в возврат списанного идёт
  только то, что сверх него.

Пример: КЗ-08 списан 17.09.2026 на 900 500 (весь долг); 10.10 по исполнительному листу поступило 50 000. На 31.10: списано
900 500, поступило после списания 50 000, не возвращено 850 500.

**Правка постановки (платежи):** принимать поступление на кредит с нулевым остатком и списанным долгом и помечать его «в
погашение списанной задолженности».

### 10. ФО-24 — без группы, старые обозначения, перевод долга

**Заёмщик без группы** — значение «Нет группы», последним, и в группе на начало, и в группе на конец. В колонке
«Основание» — причина: новый заёмщик · вне области действия классификатора · не хватило данных для расчёта. Последнее —
сбой, его надо видеть отдельно от законного «вне области».

**Смена редакции классификатора:**

- группа на каждую дату берётся в редакции, действовавшей на эту дату;
- значение с тем же кодом в обеих редакциях — одна группа; подпись — из редакции на конец периода;
- значение, которого в новой редакции нет, показывается с пометкой «(ред. N, снято)» — после действующих, перед «Нет
  группы»;
- переход, вызванный только новой редакцией, — обычный переход с основанием «новая редакция классификатора от …»;
- таблицы соответствия «старое значение → новое» нет: приравнять значения разных редакций — методическое решение, отчёт
  его не принимает.

**Перевод долга** — две строки:

| Заёмщик | Группа на начало → на конец | Остаток основного долга | Основание |
|---|---|---|---|
| прежний | 1.1 → 5.1 | 1 200 → 0 | перевод долга, соглашение № … от … |
| новый | Нет группы → 1.1 | 0 → 1 200 | то же |

Остаток уходит вместе с кредитом, ИТОГО не меняется. Если новый заёмщик уже был со своей группой, его группа
пересчитывается по всем его кредитам.

### 11. ФО-28 — что такое «проблемный кредит»

**Проблемный — кредит заёмщика групп 2.1, 2.2, 2.3, 3.1, 3.2, 4**: суд, исполнительные листы, банкротство, безнадёжные
долги. Это участок отдела по работе с проблемными кредитами. Просрочку до суда показывают ФО-01 и категория риска.

- признак «проблемный» стоит **у значения классификатора**. По умолчанию — у перечисленных групп. Заказчик может
  переназначить его новой редакцией классификатора, без релиза;
- группы 5.1 (погашенные) и 5.2 (списанные) — вне портфеля, в долю не входят;
- одно правило для ФО-28, ФО-59 и плиток.

**Шкала групп во всех отчётах — девять групп Порядка №41:** 1.1 · 2.1 · 2.2 · 2.3 · 3.1 · 3.2 · 4 · 5.1 · 5.2.
Группа 1.2 не используется: вся досудебная работа, включая просрочку, — группа 1.1. Образцы ФО-24 и ФО-28 будут
приведены к этой шкале.

### 12. ФО-53 — капитализация неустойки

- капитализированная неустойка становится **основным долгом**; отдельно в неустойке её больше нет, на неё начисляются
  проценты;
- дата — день вступления дополнительного соглашения в силу (не дата ввода и не дата подписания, если они различаются);
- если соглашение и прощает, и капитализирует, сначала прощение, потом капитализация;
- ФО-53: колонка «капитализировано» между «выдано» и «погашено»: начало + выдано + капитализировано − погашено − списано
  ± курсовая разница = конец; валютный кредит — по курсу дня вступления соглашения;
- ФО-07: у процентов и у штрафов колонка «капитализировано» со знаком минус. Без неё ведомость на таком кредите не
  сходится. Откуда пришла капитализация (проценты или неустойка), видно в ФО-07, поэтому в ФО-53 колонка не делится.

Пример: соглашение от 08.09 капитализирует неустойку 40 и проценты 60. ФО-53 за сентябрь: капитализировано +100. ФО-07:
проценты −60, штрафы −40.

### 13. ФО-58 — документы и дата закрытия и перевода

**Дата — дата вступления в силу**, указанная в действии над кредитом («Дата изменения»). Дата внесения — колонка
«Внесено», рядом «Кем внесено». Изменение, внесённое задним числом, показывается и в месяце изменения, и в месяце
внесения.

| Изменение | Документ-основание | Дата изменения |
|---|---|---|
| закрытие: погашен | последнее поступление, обнулившее задолженность (деньги или имущество), + акт сверки, если есть | день, когда задолженность стала 0 (см. ниже) |
| закрытие: списан | решение уполномоченного органа о признании задолженности безнадёжной и о списании | дата решения |
| закрытие: расторгнут | соглашение о расторжении (средства не получены) | дата вступления соглашения |
| перевод долга | соглашение о переводе долга с согласия Фонда | дата вступления соглашения |

**Закрытие погашением:** кредит закрывает человек, условие — нулевой остаток по всем статьям и закрытое взыскание.
Дата по умолчанию — день, когда задолженность стала 0: дата последнего поступления либо дата закрытия взыскания, если
оно закрылось позже. Раньше этого дня поставить нельзя, позже — только с указанием причины.

Пример: последний платёж 14.08, кредит закрыли 02.09. Строка «Закрытие: погашен, 14.08.2026, внесено 02.09.2026» есть и в
отчёте за август, и в отчёте за сентябрь.

**Правка постановки:** ТЗ 05 — добавить причину закрытия «расторгнут» (сейчас только «погашен» и «списан»).

### 14. ФО-59 — показатели риска

Утверждение запрошено у службы риск-менеджмента в форме «подтверждаем» или «иначе: …». **До её ответа строить по
описанию ФО-59**; раздел «Группы платёжеспособности» — по ответу на вопрос 11. Добавленный службой показатель — это
одна строка отчёта, устройство отчёта от состава не зависит.

Состав, отправленный на утверждение. База — кредиты в состоянии «Действует» на каждую дату; колонки — на начало, на
конец, изменение.

| Раздел | Показатели | Правило |
|---|---|---|
| Портфель | заёмщиков; кредитов (+ вступили в действие, − закрыты); остаток основного долга (+ освоено − погашено − списано ± курсовая разница); не освоено по договорам | остаток = ФО-02, движение = ФО-53, не освоено = ФО-08 |
| Просроченная задолженность | кредитов с просрочкой (+ появилась, − не стало); просроченная задолженность (основной долг + проценты + штрафы); остаток основного долга кредитов с просрочкой: до 180 дней / более 180 дней; доля этого остатка в основном долге; средняя длительность просрочки | доля = остаток основного долга кредитов с просрочкой ÷ весь основной долг |
| Группы платёжеспособности | основной долг группы 1.1; основной долг проблемных (2.1–2.3 · 3.1–3.2 · 4); проблемных заёмщиков; доля проблемных | = ФО-28 |
| Концентрация | доля крупнейшего заёмщика; доля пяти крупнейших; пятёрка по именам | по всем кредитам заёмщика; пятёрка своя на каждую дату |
| Обеспеченность залогом | основной долг кредитов с залогом: обеспечен по порогу / не обеспечен; основной долг без залога; недостаёт залога до порога | по залоговой стоимости против порога, не по оценочной |
| Реструктуризация | реструктурированных кредитов; их остаток основного долга; обращений в работе | = ФО-10 |

Вне состава, на решение службы: группы совместного риска; доли «первичных, вторичных, третичных» кредитов в просрочке;
кредиты связанным лицам (в системе нет сведений); резерв и ожидаемые кредитные убытки (ведутся вне системы).

### 15. ФО-95 — погашение имуществом

**Долг погашен на дату перехода права к Фонду:**

| Вид имущества | Документ | Дата погашения |
|---|---|---|
| право подлежит государственной регистрации (недвижимость, доли) | выписка о государственной регистрации перехода права | дата регистрации |
| прочее | акт приёма-передачи | дата акта |

Между актом и регистрацией объект в состоянии «принят, ждёт регистрации»: долг не погашен, кредита в ФО-95 нет.
Окончательный отказ регистратора → «принятие не состоялось», погашения не было. Решение о принятии и акт до перехода
права погашением не считаются. Признак «право подлежит госрегистрации» стоит у вида имущества в справочнике.

**Способ погашения** определяется всеми операциями того дня, в который задолженность стала 0:

- только платежи → «деньгами»;
- только имущество → «имуществом»;
- и то и другое → «деньгами и имуществом»;
- зачёт считается «деньгами».

Новая колонка «в том числе имуществом» — стоимость имущества, принятого в погашение с начала кредита (в пределах долга).
Она уже входит во «Всего погашено».

Пример: задолженность 500; 20.09 платёж 120 и регистрация перехода права на склад стоимостью 380. Способ — «деньгами и
имуществом», в том числе имуществом 380.

### 16. ФО-96 — акты сверки

**Правило подтверждаем: дни сверх срока и порог 60 дней считаются от 1 сентября года**, одна дата на всех заёмщиков.
Срок, записанный в самом акте, не читается. Основание — Порядок №41: п. 9 (акт сверки до 1 сентября) и п. 11 пп. 2
(уклонение от подписания более 60 дней с установленной даты).

Пример: акт передан 20.08, в акте написано «подписать до 15.09». На 05.11 — 65 дней, «свыше 60».

**Карточка заёмщика должна считать так же** — от 1 сентября, а не от срока в акте. Иначе один заёмщик окажется «свыше
60» в отчёте и не окажется в карточке. Порог 60 дней установлен нормой (п. 11 пп. 2), а не макетом.

**Итог «не требуется»:**

- заёмщик закрылся без подписанного акта: все кредиты погашены, списаны или долг переведён;
- заёмщик умер, правопреемник не установлен.

Не «не требуется»: заёмщик в банкротстве (подписывает специальный администратор); заёмщик, подписавший акт и
закрывшийся позже (остаётся «подписан»); заёмщик, появившийся в году (в акт этого года не входит).

Оба случая «не требуется» и дата 1 сентября как «установленная дата» отправлены заказчику на подтверждение; до ответа
действует это правило.

### 17. ФО-97 — возвратность дел взыскания

**База — весь долг** на день первого требования по каждому кредиту дела: основной долг целиком (включая не наступивший),
начисленные проценты и штрафы. Сумма по кредитам дела, в сомах по курсу этого дня. От платежей и начислений база не
меняется, растёт только с новым кредитом в деле. Формулировка «срок которых наступил» в описании ФО-97 будет убрана.

Пример: на день первого требования весь остаток 1 000, из них наступило 300; потом поступило 150. Возвратность 15 %.

**Что засчитывается:** платежи, зачёт, принятое имущество (на дату перехода права) — по кредиту дела, с даты первого
требования по этому кредиту, пока дело открыто. Списание и прощение не засчитываются. Возвратность не ограничена 100 %:
поступления гасят и проценты, начисленные после открытия дела.

**Отменённые операции:** сторнированное поступление не считается. Если его отменили после окончательной сдачи отчёта,
сданный выпуск получает отметку «числа изменились после сдачи» и сам не переиздаётся.

**Поступление, относящееся к нескольким требованиям.** Поступление привязано к кредиту, а не к требованию или мере; его
разносит модуль платежей.

- требования к заёмщику и поручителю по одному кредиту — поступление учитывается один раз, от кого бы оно ни пришло;
- поступление на несколько кредитов делится по разнесению, в дело идут доли его кредитов;
- кредит входит только в одно дело, двойного счёта между делами нет.

### 18. ФО-98 — кредитные программы

**Программа у кредитов из старой системы.** В старой системе у кредита нет программы, но обязательно основание выдачи —
решение правительства. Программу проставляет перенос данных, только когда она однозначна:

- у решения ровно одна программа → эта программа;
- у решения несколько программ → по списку «кредит → программа», который даёт заказчик;
- нет в списке → «Без программы» под своим решением (ИТОГО ФО-98 при этом сходится с ФО-02).

По реквизитам (валюта, источник, цель) программа не угадывается. Пропущенное позже дополняется новой версией переноса с
журналом, а не правкой в карточке кредита.

**Дата закрытия программы:**

- **по сроку** — программа закрывается сама с «Даты по». Документ — решение, которым она утверждена;
- **досрочно** — действие «Закрыть» несёт основание: вид документа (постановление или распоряжение Кабинета Министров
  об отмене или изменении решения, решение уполномоченного органа Фонда), номер, дата, дата вступления, файл. Дата
  закрытия — дата вступления документа; кто и когда нажал «Закрыть» — в журнале;
- закрытие программы не закрывает кредиты: договоры дальше стоят в своей программе.

Пример: программа действует по 31.12.2025, постановление № 45 от 10.06.2025 прекращает её досрочно, «Закрыть» нажали
20.06. Окончание в ФО-98 — 10.06.2025.

**Правка постановки:** ТЗ 02 — у действия «Закрыть» основание-документ с датой вступления вместо текстовой причины.

## Залог, имущество и документы

### 19. ФО-14 — шесть исходов обследования

**Исход акта — справочник из шести значений**, у каждого значения класс действия. Действия системы ветвятся по классу,
как сейчас:

| Исход | Класс действия | Что запускает |
|---|---|---|
| хорошее | в норме | следующая дата обследования |
| удовлетворительное | в норме | то же |
| неудовл. (требует ремонта) | ухудшение | досрочная переоценка |
| неудовл. (повреждённое) | ухудшение | то же |
| неудовл. (аварийное) | ухудшение | то же |
| неудовл. (утраченное) | утрата | недостаточность обеспечения |

- акты из старой системы переносятся со своим значением; пустой исход — «не указан», класс не назначается;
- записи, внесённые с тремя исходами, есть только на тестовом стенде, их данные будут сброшены. Если такие записи всё же
  окажутся, отчёт показывает класс с пометкой «без уточнения» («в норме — без уточнения»);
- утрата по документу без акта — «утрачен по документу».

### 20. ФО-15 — более частое обследование

**Обычное правило** — периодичность по группе платёжеспособности и виду имущества (Положение о работе с залогом,
прил. 2 п. 2.3).

**Чаще обычного обследование назначают только:**

- решение отдела залогового обеспечения, согласованное курирующим заместителем Председателя Правления — по категории
  риска, виду имущества или после ухудшения состояния. Документ — служебная записка (решение) с визой согласования;
- для заёмщиков в банкротстве — договор со специальным администратором.

В системе:

- на предмете хранится индивидуальная периодичность: интервал в месяцах, дата начала, основание (вид, номер, дата,
  файл), причина. Отменяется таким же решением;
- действует более строгое из двух: если обычное правило даёт чаще (например, заёмщик перешёл в группу 2), берётся оно;
- новое значение действует на следующие плановые даты, уже наступившие не пересчитываются;
- в ФО-15 у плановой даты, рассчитанной по решению, указано его основание.

Автоматическое ужесточение по категории риска (коэффициенты и минимум 3 месяца) снимается: в норме этих чисел нет,
интервал называет само решение.

### 21. ФО-16 — снятие запрета

**Какой учёт официальный.** Граница — дата запуска. Снятие с датой до запуска — запись, перенесённая из старой системы,
только для чтения (основание — её текст). После запуска — только новая система; старая новых записей не принимает.

**Одно событие или два.** Снятие привязано к конкретному запрету (орган, номер и дата наложения). Событие — документ
органа о снятии (номер реестровой записи, дата):

- у одного запрета полное снятие бывает один раз; повторная запись получает отказ со ссылкой на существующую;
- при переносе дубли ищутся по паре «запрет + документ о снятии»;
- если в старой системе нет номеров документа, совпадение по предмету и дате само не склеивается, а уходит списком на
  ручную сверку.

**Частичное снятие** фиксируется:

- документом органа о снятии запрета с части имущества (реестровая запись, номер, дата) — это само событие;
- основанием по справочнику оснований снятия, обычно дополнительным соглашением к договору залога об исключении части
  имущества;
- теми же согласованиями, что полное снятие.

**Правка постановки (ТЗ 12):**

1. Отдельная запись снятия в журнале предмета: дата, вид (полное или частичное), основание, документ о снятии, акт
   сверки, реквизиты снятого запрета, сторно. Частичное снятие не пропадает при последующем полном.
2. Стоимость снятой части — поле у частичного снятия. Официальное ТЗ требует «сумму по снятому залогу».

### 22. ФО-17 — отнесение денег и представитель Фонда

**Поступление относится к кредиту, а не к мере** (претензии, иску, листу). Внутри кредита — к части долга по
конкретному решению суда, у которой своя присуждённая сумма и свой исполнительный лист.

| Поступление | Куда идёт |
|---|---|
| от судебного исполнителя, в документе номер исполнительного листа или производства | кредит и часть долга по этому решению → «взыскано по листу» |
| от должника, в назначении номер договора | этот кредит, по очереди погашения |
| без признаков | общий порядок разнесения платежей; неясное разносит куратор вручную |

- «взыскано по листу» — сумма поступлений, разнесённых на часть долга по его решению. Остаток по решению = присуждено −
  взыскано; его отдаёт расчёт задолженности кредита;
- претензия денег не «собирает»: «Поступило за период» в ФО-17 — поступления по кредиту требования; у требования к
  поручителю — поступления поручителя;
- солидарные должники (заёмщик и поручитель) делят одну часть долга: поступление любого из них гасит её.

**Представитель Фонда на судебном заседании** фиксируется у меры «Судебное заседание» — среди её участников, с ролью
«представитель Фонда»: сотрудник, а для внешнего юриста — доверенность (номер, дата). Реестр заседаний и ФО-17 берут
представителя оттуда. Не указан — пусто.

### 23. ФО-18 — комплектность дела

**Перечни обязательных документов ведут модули — владельцы объектов:**

| Объект | Перечень | Где |
|---|---|---|
| заёмщик | модуль «Заёмщик» | справочник документов по виду лица (юрлицо, физлицо, ИП) |
| кредит | кредитная программа | обязательные кредитные документы программы |
| предмет залога | модуль «Залог» | общий перечень + добавка по виду залога (ТЗ 12 §13) |

Документ, которого ещё нет в деле, отдельно не заводится: требование есть, документа нет → строка ФО-18 в состоянии
«нет».

У каждой строки перечня — основание (документ, которым перечень утверждён) и дата, с которой она действует. Новое
требование распространяется на объекты, заведённые с этой даты; на существующие — только если в основании прямо сказано
«распространяется на действующие».

**Замена и отзыв документа:**

- замена — новый документ закрывает то же требование; прежний остаётся в истории со статусом «заменён» и датой.
  Состояние требования берётся по последнему действующему на дату документу;
- отзыв — не удаление, а запись с датой и причиной. С этой даты требование в состоянии «нет» с пометкой «отозван», до
  неё — «есть»;
- отчёт на прошлую дату показывает состояние на ту дату.

Пример: полис принят 10.01.2026, заменён 01.06, новый отозван страховщиком 15.08. На 01.05 — «есть» (полис от 10.01); на
01.07 — «есть» (полис от 01.06, прежний «заменён»); на 01.09 — «нет: отозван 15.08.2026».

Состояния требования на дату: есть (принят) · на проверке · отклонён · просрочен · нет · не требуется. Проверки
документов заявки (специалист и головной офис) уже предусмотрены, выбирать между ними не нужно.

### 24. ФО-19 — документы из внешней системы

**ФО-19 показывает документы и поручения, зарегистрированные в документообороте АСУБК.** Охват напечатан в заголовке:
«документы, зарегистрированные в системе».

- история резолюций, продлений сроков, исполнения, отказов и аннулирования — от модуля документооборота; исполнение
  шагов — от модуля «Задания»;
- документы, перенесённые из старой системы, попадают только в «Зарегистрировано»: истории исполнения у них нет;
- внешней системы документооборота в проекте нет. Если Фонд хочет видеть в отчёте документы из такой системы, это
  отдельное требование на интеграцию: заказчик называет систему, способ обмена и ответственного за выгрузку. В финальный
  акт оно не входит.

### 25. ФО-20 — задания вне системы

**ФО-20 включает все задания, выданные в АСУБК:** задания модулей по их объектам, свободные задания, выданные человеком
в системе, поручения по резолюциям документов, задания контроля исполнения. Охват в заголовке: «задания, выданные в
системе».

- назначение исполнителя, срок и его продления, сдачу, возврат, отказ и итог (исполнено, снято, отпало) хранит только
  модуль «Задания»;
- поручение, выданное служебным документом, попадает в отчёт, если по нему заведено задание (резолюция в
  документообороте его создаёт);
- задания старой системы: если перенос их будет включать (вопрос 1), переносятся только открытые на дату запуска — как
  новые задания с отметкой «из старой системы», без прежней истории;
- для отчёта статистике нужен объект «Задание» — его пока нет.

### 26. ФО-47 — рассрочка и завершение предложения

**Продажи в рассрочку входят в первый выпуск** — официальное ТЗ требует мониторинг имущества, реализованного в рассрочку:

- состояние «продан в рассрочку»: объект остаётся на учёте до последнего платежа, дни на учёте идут;
- цена договора без процентов рассрочки; поступило в счёт цены; выплачено отчуждателю — долями по мере оплаты;
- после расторжения договора счёт дней продолжается от той же даты перехода права.

**Предложение завершено, когда у каждой позиции есть итог:** принята решением Комитета, отказано решением Комитета или
отозвана источником по документу.

- дата завершения — дата последнего итога;
- итог предложения: «принято полностью» · «принято частично» · «не принято» (все позиции отказаны или отозваны);
- принятая позиция без акта предложение открытым не держит — она ждёт акта, в виде «Предложения» с пометкой «ждёт акта».
  Выходов три: акт, отзыв источником, решение о прекращении принятия. Если ожидание затянулось, появляется задание.

Пример: предложение — здание и холодильная камера; 24.02 Комитет: здание принять, камеру — отказать. Предложение
завершено 24.02, «принято частично»; здание на учёте с 20.03 (госрегистрация).

### 27. ФО-55 — кто видит заявки специалиста

**По общему правилу видимости ролей:**

| Кто | Видит |
|---|---|
| кредитный специалист | заявки, где он «специалист заявки» на конец периода. После передачи заявки другому — у нового |
| руководитель подразделения | заявки специалистов своего подразделения и всех нижестоящих (оргструктура на ту же дату); по каждому специалисту — разрезом и отбором «Кредитный специалист» |
| руководство (Правление, курирующий заместитель, руководство Холдинга) | все заявки. Какие роли видят всё, задаётся настройкой роли, не в отчёте |
| остальные роли | не видят |

Итоги показывают только видимое («вам видно: 5»), а не весь портфель; сведения о выпуске называют область видимости.
