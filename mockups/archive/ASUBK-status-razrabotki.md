## Гриллинг 13.11.2026 · модуль с чистого листа

**Рамка:** архив — где лежит бумага: где сейчас физическая папка и у кого.
**Отвергнуты:** «бумага + свои электронные копии» (дубли сканов с досье), «всё по ТЗ с чатом»
(чат и обмен файлами — общесистемные).

Решения:
- [ ] **АХ-1 · Рамка.** Учёт физической папки: место, у кого, когда взял, когда вернуть. Сканы —
  ссылкой на досье/документооборот. Обмен файлами и чат — вне модуля, на подтверждение заказчику.
- [ ] **АХ-2 · Какие папки.** Любая папка архива Холдинга; вид из справочника решает привязку:
  кредитно-залоговое дело → заёмщик, номенклатурное и прочее — без (уточнено АХ-3).
  Один реестр на весь архив; «где бумага» из карточки заёмщика.
- [ ] **АХ-3 · Архив самостоятелен.** Место и выдача бумаги — только в архиве. Макет
  документооборота не учитывается: разработчикам не передан, ДО строится по старой системе.
- [ ] **АХ-4 · Выдаётся папка целиком.** Отдельный лист не выдаётся; толстое дело — тома, том =
  папка с той же привязкой. Опись для выдачи не нужна.
- [ ] **АХ-5 · Справочник мест.** Помещение → шкаф → полка; постоянное место папки сохраняется,
  пока она на руках; «переместить» — отдельное действие. Даёт отбор по полке и инвентаризацию.
- [ ] **АХ-6 · Рождение при приёме.** Архивариус заводит папку, когда принимает её на полку
  (вид, привязка, том, место, кто сдал). «Дело не сдано» — отчётом по привязке, без заготовок.
- [ ] **АХ-7 · Запрос или напрямую.** Запрос в системе (зачем, к какому числу) → архивариус
  выдаёт или отказывает с причиной; либо выдача пришедшему лично. Итог один — выдача.
- [ ] **АХ-8 · Срок всегда.** У каждой выдачи дата возврата; долгая работа — продлением с
  причиной в истории. Бессрочной выдачи нет (п. 19 пп. 2: в ДПО уходят копии).
- [ ] **АХ-9 · Продление по просьбе.** Держатель просит (дата + причина) → архивариус продлевает
  или отказывает. По умолчанию: срок выдачи — настройка архива, 10 р.д.
- [ ] **АХ-10 · Передача из рук в руки.** «Передать» → «Получил»; срок прежний; до подтверждения
  отвечает передающий.
- [ ] **АХ-11 · Очередь на занятую папку.** Держатель видит «ждёт …», может передать напрямую;
  при возврате — выдача первому; при продлении архивариус видит очередь.
- [ ] **АХ-12 · Просрочка.** Уведомление за 2 р.д.; после срока — задание «Вернуть папку» с
  подъёмом к руководителю; закрывается само (возврат, передача, продление). Долг соседям:
  «Задания», «Уведомления».
- [ ] **АХ-13 · Списать папку.** Причина + основание; запись и история остаются; «утрачена» —
  можно восстановить. Срок хранения не моделируется.
- [ ] **АХ-14 · Запуск вручную.** Существующие папки архивариус заводит до запуска формой приёма,
  по одной; экрана загрузки описи нет.
- [ ] **АХ-15 · Сверка — печатью.** Печать списка полки; расхождения — «Переместить» / «Списать».
- [ ] **АХ-16 · Видят все.** Реестр видят все; запросить может любой со «зачем»; архивариус вправе
  отказать. По умолчанию: права на действия — канон §7.
- [ ] **АХ-17 · Сводки в модуле.** По состояниям, «Заёмщики без КЗД», «Журнал движения»; отборы,
  печать, Excel. В перечень отчётов не добавляем.

По умолчанию (владелец может переиграть): срок выдачи 10 р.д.; права на действия (канон §7);
возврат — на постоянное место или первому в очереди; получатель — только сотрудник; «Получил» —
только при передаче из рук в руки, не при выдаче из архива.

На подтверждение заказчику: обмен файлами и чат из ТЗ (стр. 1009–1010) в модуль не входят (`АХ-1`).

## Автогриллинг 13.11.2026 · проход 1 по плану

## Гриллинг 13.11.2026 · проход 3 по экранам

Предмет — каждый экран модуля: что на нём, содержание, кнопки. Макета нет, экраны — из плана §3.
Порядок: карточка папки → «Папки» → «Мои папки» → «Очередь архивариуса» → формы действий →
«Заёмщики без КЗД» → «Журнал движения» → справочники → врезка у заёмщика → печать. Решения
принимает владелец из 2–3 вариантов с рекомендацией.

Решения:
- [ ] **АХ-50 · Карточка — панель поверх списка.** Справа ~900 px, свой адрес; список остаётся,
  следующая папка — клик по строке; один столбец: шапка «где сейчас», кнопки, реквизиты, очередь,
  история. Почему: папка — лёгкая запись, работа всегда начинается из списка (очередь, поиск,
  полка, тома). Переигрывает `АХ-34` в части «два столбца». Отвергнуто: отдельная страница.
  По умолчанию: шапка — номер, название, вид; «где сейчас» крупно по состоянию; реквизиты —

- [ ] **АХ-66 · Возврат и списание во время передачи или просьбы продлить.** Незавершённая передача
  закрывается «отменена: папку вернули в архив / папка выбыла» — событием в истории и уведомлением
  получателю; просьба продлить — «просьба закрыта» с уведомлением просившему. «Отменить передачу» —
  тоже уведомление получателю. Почему: бумага уже на полке или выбыла; получатель иначе видит «вам
  передают» на папку, которой у передающего нет. На подтверждение.
- [ ] **АХ-67 · Заёмщик с выбывшей КЗД — в «Заёмщики без КЗД»** с пометкой «КЗД выбыла: утрачена
  (А-…)». Почему: бумаги в архиве нет — список отвечает на «у кого дела нет»; пометка отличает «не
  сдано» от «потеряно». Отвергнуто: считать выбывшую сданной (утраченное дело пропадает из виду). На
  подтверждение.
- [ ] **АХ-68 · День напоминания считается, когда назначен срок, и всегда рабочий.** При выдаче и
  продлении: N-й рабочий день до срока по значению настройки на этот момент. Почему: `АХ-61` —
  новое значение только на новые выдачи; напоминание в субботу никто не прочтёт. На подтверждение.
- [ ] **АХ-69 · Сроки — позже сегодняшнего.** «Вернуть до» при выдаче, новый срок продления (кроме
  того — позже текущего) и «нужна до» — позже сегодняшнего дня. Срок на выходной не запрещается
  (держатель вернёт в первый рабочий день). На подтверждение.
- [ ] **АХ-70 · Ссылка на место — и через историю.** Полку, где папка когда-то стояла (переехала),

## Автогриллинг 13.11.2026 · страница «Рамка модуля и Очередь архивариуса»

Проход 1 из 7 по страницам макета. Предмет — общая рамка (меню и счётчики, шапка, переключатель
пользователя, стартовый экран по роли, как открываются карточка и окна) и «Очередь архивариуса».
**Рамка:** удобно и ясно ли роли делать здесь ежедневную работу (план §6: архивариус С-1…С-6, С-8,
С-10, С-20; стартовые экраны всех ролей); правила движка и права не меняются. Решения приняты Claude
рекомендованным вариантом, владелец может переиграть. Замеры — живой макет на 1920 × 1080.

Замеры до правок: меню 270 px, шапка 59 px, рабочая область 1650 px. Очередь у архивариуса: поле
«Возврат» 1386 px под стопку из 3–5 номеров по 3 цифры, кнопка у правого края (x ≈ 1709), Enter ничего
не делает; четыре блока — 1 к выдаче, 1 продление, 2 привязки, 1 у уволенного — занимают 754 из 1021 px.
Счётчик меню «5» и «1» — всегда красные. Дата «сегодня» — внизу меню, 12 px серым (y ≈ 1013), а сроки на
странице считаются от неё. Клики архивариуса от стартового экрана: С-2 выдача по брони — 2; С-4 отказ — 2;
С-6 отказ в продлении — 2; С-5 возврат стопкой — ввод + «Принять возврат» + закрыть окно итога = 2;

Решения:
- [x] **АХ-71 · Демо-стенд — одной полосой в шапке.** Пунктирная полоса справа в шапке: «Демо-стенд ·
  сегодня 13.11.2026 · Пользователь ▾ · образец врезки «Где бумага»». Низ меню — только кто вошёл: имя,
  роль · подразделение (подразделение нужно руководителю, С-19). Почему: все сроки на странице — красная
  просрочка, «бронь до», «вернуть до» — читаются от «сегодня», а оно стояло внизу слева 12 px серым;
  управление стендом было в двух местах. Отвергнуто: оставить как есть; всё в низ меню (переключатель —
  главный рычаг стенда, ему место у заголовка).
- [x] **АХ-72 · Счётчики меню — красные только при просрочке.** Число у «Очереди архивариуса» и «Моих
  папок» — серое, как в других модулях АСУБК; красное — только когда в счёт входит своя просрочка (у
  Асанова 1). Состав счётчиков не меняется (канон §9.1). Почему: архивариус начинает день с очереди, и
  «5» красным горит всегда — красный перестаёт что-то значить; у Мамбетова «1» — это «вам передают», не
  тревога. Отвергнуто: всё красное (было); без счётчиков (на другом экране не видно, что пришла бронь).
- [x] **АХ-73 · Поиск и «Принять папку» в рамку не выносятся.** Поиск остаётся в «Папках» и «Моих
  папках» (`АХ-55`), «Принять папку» — в «Папках» и «Заёмщиках без КЗД». Почему: поиск в шапке экономит
  один клик в С-3 (4 → 3), но даёт два поля поиска на «Папках» и «Моих папках»; «Принять папку» в очереди
  экономит один клик раз за сеанс ввода (С-8) и ставит «Принять папку» рядом с «Принять возврат» — их
  легко перепутать у окна. Отвергнуто: поиск в шапке; «Принять папку» в очереди.
- [x] **АХ-74 · Поле «Возврат» — ввод с клавиатуры.** Заголовок «Возврат», как у блоков; поле ~520 px
  с подсказкой внутри («номера с корешков через пробел»), кнопка «Принять возврат (N)» сразу за полем;
  Enter — то же, что кнопка; при входе в очередь курсор уже в поле. Почему: стопка — 3–5 номеров, ~20
  знаков; рука на клавиатуре, а кнопка стояла в 1300 px от конца ввода. Случайный Enter после первого
  номера не страшен — у каждой папки своя запись, подсказка «куда» остаётся в итоге (`АХ-76`).
  Отвергнуто: оставить мышью; Enter переносит строку, а принимает только кнопка.
- [x] **АХ-75 · Строки поля «Возврат» — № ссылкой, без колонки «Вернуть до».** № открывает карточку и у
  строки с причиной: номер папки «в архиве» чаще всего значит «хочу взять» — в карточке главная кнопка
  «Выдать». Колонка «Вернуть до» снята: при возврате срок ничего не меняет (задание закрывается само,
  `АХ-12`); просрочка — пометкой «просрочена N р.д.» под держателем. Держатель остаётся: по нему видно,
  что набран номер той папки, что в руках. Отвергнуто: как есть (№ текстом, дата у каждой строки); убрать
  и держателя (кто принёс — не важно, `АХ-Д2`, но держатель проверяет номер).
- [x] **АХ-76 · Итог возврата — под полем, без окна.** После «Принять возврат» поле очищается, под ним
  остаётся «Принято только что: N» — № · название · куда — до следующего ввода или ухода из очереди
  (вечером утренний итог уже неправда). Почему: окно итога
  закрывает очередь и требует клика, а «куда» нужно, пока папки раскладываются по полкам. Отвергнуто:
  окно (было); только всплывающее сообщение (пять полок держать в голове).
- [x] **АХ-77 · «Принять возврат» пачкой из «Папок» — окном с теми же строками.** Отмеченные →
  окно: № · название · держатель · куда · «＋ примечание»; не на руках — строка с причиной; кнопка
  «Принять возврат (N)». Почему: пачка принималась сразу, без примечания и без «куда» до нажатия (журнал
  волны 1); один вид возврата на весь модуль. Отвергнуто: переход в очередь с номерами в поле «Возврат»
  (теряются отбор и отметки «Папок»); оставить без примечания.
- [x] **АХ-78 · Порядок блоков очереди — по срочности.** К выдаче → Продления → На руках у уволенных →
  Ждут привязки. Почему: «Ждут привязки» — единственный блок без срока и единственный, что растёт при
  запуске: каждая старая КЗД заёмщика, которого нет в системе (`АХ-14`, `АХ-45`), встаёт туда — десятки
  строк сталкивали бы «уволенных» (риск потери папки) за край экрана. Отвергнуто: как было (привязки
  третьими); свернуть «Ждут привязки» (скрытое забывают). **Уточняет порядок `АХ-56` — на
  подтверждение.**
- [x] **АХ-79 · Печать и Excel в очереди — только где список уходит с экрана.** «К выдаче» — «Печать
  обхода» (как было); «На руках у уволенных» — «Печать» и «Excel» (канон §8: список со сводками, его
  несут руководителю и кадрам). «Продления» и «Ждут привязки» — без: решаются на экране. Руководитель
  отдельного списка не получает: папки уволенных своих он видит отбором «Подразделение держателя» в
  «Папках» (с пометкой «уволен») и заданием, поднятым к нему (`АХ-12`, `АХ-41`). Отвергнуто: печать и
  Excel у каждого блока; без печати (было).
- [x] **АХ-80 · После привязки — «Печать ярлыка», если название изменилось.** Сообщение «Привязка
  изменена: «…» — перепечатайте ярлык» с кнопкой «Печать ярлыка»; название то же — без кнопки. Везде, где
  есть «Изменить привязку» (очередь, карточка, «Заёмщики без КЗД»). Почему: ярлык несёт название
  (`АХ-60`), после привязки оно меняется, а напоминания не было — 4 клика через карточку, если вспомнишь.
  Отвергнуто: всегда открывать печать ярлыка (лишнее, когда название то же); как было.
- [x] **АХ-81 · Открытая папка подсвечена в строке очереди** — *по умолчанию, частный случай `АХ-50`*
  («закрыл — стоишь на той же строке»): в «Папках» строка открытой папки подсвечена, в блоках очереди —
