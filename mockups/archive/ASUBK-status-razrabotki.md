## Гриллинг 13.11.2026 · модуль с чистого листа

**Рамка:** архив — где лежит бумага: где сейчас физическая папка и у кого.
**Отвергнуты:** «бумага + свои электронные копии» (дубли сканов с досье), «всё по ТЗ с чатом»
(чат и обмен файлами — общесистемные).

Решения:
- [ ] **АХ-1 · Рамка.** Учёт физической папки: место, у кого, когда взял, когда вернуть. Сканы —
  ссылкой на досье/документооборот. Обмен файлами и чат — вне модуля, на подтверждение заказчику.
- [ ] **АХ-2 · Какие папки.** Любая папка архива Холдинга; вид из справочника решает привязку:
  кредитно-залоговое дело → заёмщик, номенклатурное и прочее — без (уточнено АХ-3).
  Один реестр на весь архив; «где бумага» из карточки заёмщика.
- [ ] **АХ-3 · Архив самостоятелен.** Место и выдача бумаги — только в архиве. Макет
  документооборота не учитывается: разработчикам не передан, ДО строится по старой системе.
- [ ] **АХ-4 · Выдаётся папка целиком.** Отдельный лист не выдаётся; толстое дело — тома, том =
  папка с той же привязкой. Опись для выдачи не нужна.
- [ ] **АХ-5 · Справочник мест.** Помещение → шкаф → полка; постоянное место папки сохраняется,
  пока она на руках; «переместить» — отдельное действие. Даёт отбор по полке и инвентаризацию.
- [ ] **АХ-6 · Рождение при приёме.** Архивариус заводит папку, когда принимает её на полку
  (вид, привязка, том, место, кто сдал). «Дело не сдано» — отчётом по привязке, без заготовок.
- [ ] **АХ-7 · Запрос или напрямую.** Запрос в системе (зачем, к какому числу) → архивариус
  выдаёт или отказывает с причиной; либо выдача пришедшему лично. Итог один — выдача.
- [ ] **АХ-8 · Срок всегда.** У каждой выдачи дата возврата; долгая работа — продлением с
  причиной в истории. Бессрочной выдачи нет (п. 19 пп. 2: в ДПО уходят копии).
- [ ] **АХ-9 · Продление по просьбе.** Держатель просит (дата + причина) → архивариус продлевает
  или отказывает. По умолчанию: срок выдачи — настройка архива, 10 р.д.
- [ ] **АХ-10 · Передача из рук в руки.** «Передать» → «Получил»; срок прежний; до подтверждения
  отвечает передающий.
- [ ] **АХ-11 · Очередь на занятую папку.** Держатель видит «ждёт …», может передать напрямую;
  при возврате — выдача первому; при продлении архивариус видит очередь.
- [ ] **АХ-12 · Просрочка.** Уведомление за 2 р.д.; после срока — задание «Вернуть папку» с
  подъёмом к руководителю; закрывается само (возврат, передача, продление). Долг соседям:
  «Задания», «Уведомления».
- [ ] **АХ-13 · Списать папку.** Причина + основание; запись и история остаются; «утрачена» —
  можно восстановить. Срок хранения не моделируется.
- [ ] **АХ-14 · Запуск вручную.** Существующие папки архивариус заводит до запуска формой приёма,
  по одной; экрана загрузки описи нет.
- [ ] **АХ-15 · Сверка — печатью.** Печать списка полки; расхождения — «Переместить» / «Списать».
- [ ] **АХ-16 · Видят все.** Реестр видят все; запросить может любой со «зачем»; архивариус вправе
  отказать. По умолчанию: права на действия — канон §7.
- [ ] **АХ-17 · Сводки в модуле.** По состояниям, «Заёмщики без КЗД», «Журнал движения»; отборы,
  печать, Excel. В перечень отчётов не добавляем.

По умолчанию (владелец может переиграть): срок выдачи 10 р.д.; права на действия (канон §7);
возврат — на постоянное место или первому в очереди; получатель — только сотрудник; «Получил» —
только при передаче из рук в руки, не при выдаче из архива.

На подтверждение заказчику: обмен файлами и чат из ТЗ (стр. 1009–1010) в модуль не входят (`АХ-1`).

## Автогриллинг 13.11.2026 · проход 1 по плану

Предмет — открытые вопросы плана (`ASUBK-arhiv-plan.md` §8) и сверка канона с планом. Решения
приняты Claude рекомендованным вариантом, владелец может переиграть. Итог: **17 решений — 11 по
вопросу, 6 по умолчанию; 5 дефектов.**

Решения:
- [ ] **АХ-18 · Название папки.** С привязкой собирается само «вид · заёмщик · том N», следует за
  переименованием заёмщика; без привязки — вручную; «Содержание (кратко)» — свободный текст.
  Почему: дубли и опечатки (`АХ-2`). Отвергнуто: всегда вручную; всегда само.
- [ ] **АХ-19 · Номер и ярлык.** Сквозной номер «А-000123», не переиспользуется; ярлык на корешок;
  поиск по номеру, названию, ИНН; без штрихкода. Отвергнуто: без номера; штрихкод.
- [ ] **АХ-20 · Следующий том** — *по умолчанию, частный случай АХ-4/АХ-6*: «Принять следующий том».
- [ ] **АХ-21 · Смена привязки** — *по умолчанию*: «Изменить привязку» с основанием, история.
- [ ] **АХ-22 · Несколько архивариусов.** Очередь общая, к помещениям не привязаны. Отвергнуто:
  архивариус на помещение.
- [ ] **АХ-23 · Бронь.** Свободная для первого в очереди папка — бронь 2 р.д. + уведомление; другому
  не выдать; не забрал — «не забран», бронь следующему. Почему: без брони очередь `АХ-11` обходят у
  окна. Отвергнуто: без брони; доставка архивариусом. **На подтверждение: 2 р.д.**
- [ ] **АХ-24 · Порядок очереди** — строго по времени; «к какому числу» порядок не меняет.
  Отвергнуто: по сроку нужности; ручная перестановка.
- [ ] **АХ-25 · Жизнь запроса** — *по умолчанию*: отзыв до выдачи; закрытия; повторный и на
  выбывшую — нельзя.
- [ ] **АХ-26 · Выдача у окна — с уведомлением** держателю; расписки нет. Отвергнуто: «Получил» у
  окна; печатная расписка.
- [ ] **АХ-27 · Незавершённая передача** — *по умолчанию, из АХ-10*: «Отменить» / «Не получал»;
  просрочка — передающему.
- [ ] **АХ-28 · Передача при очереди** — любому; очередь сохраняется; срок не меняется. Отвергнуто:
  только первому; с причиной.
- [ ] **АХ-29 · Держатель уходит.** Пометка «уволен», список у архивариуса, задание — по правилам
  «Заданий»; заявка «Сотрудникам». Отвергнуто: запрет увольнения; автоматический возврат.
- [ ] **АХ-30 · Рабочие дни** — *по умолчанию*: производственный календарь системы.
- [ ] **АХ-31 · Врезка «Где бумага»** у заёмщика: папки КЗД, состояние, «Запросить»; нет —
  «не сдано». Отвергнуто: счётчик со ссылкой; вся история.
- [ ] **АХ-32 · «Заёмщики без КЗД»** — с действующим кредитом, колонка дней, отбор «и закрытые».
  Отвергнуто: все заёмщики; порог N дней.
- [ ] **АХ-33 · Уведомления** — *по умолчанию*: шесть видов (канон, «что модуль требует от соседей»).
- [ ] **АХ-34 · Раскладка на 1920.** Реестр — 9 колонок, место одной колонкой; карточка — шапка
  «где сейчас», два столбца, история на виду. Отвергнуто: место тремя колонками; история вкладкой.

Дефекты (сверка канона и плана):
- [ ] **АХ-Д1 · Покрытие ТЗ неполное.** `АХ-1` называет отступлением только обмен файлами и чат, а
  ТЗ ещё требует электронное хранение и поиск (стр. 139–143), регистрацию архивного *документа* и
  внесение файла (стр. 1005–1006). Исправлено: таблица покрытия в каноне §0; позиция на
  подтверждение заказчику расширена.
- [ ] **АХ-Д2 · Непроверяемое правило возврата.** «Возвращает только держатель или тот, кто
  принёс» — система не знает, кто принёс. Исправлено: возврат отмечает архивариус, кто принёс — не
  важно.
- [ ] **АХ-Д3 · Перемещение: канон и план расходились.** План — только «в архиве», канон — без
  ограничения. Исправлено: в любом состоянии, кроме «выбыла».
- [ ] **АХ-Д4 · Списание и очередь.** Канон не закрывал очередь при списании, план закрывал.
  Исправлено: очередь закрывается, запросы — «закрыт: папка выбыла».
- [ ] **АХ-Д5 · Удаление из справочников не определено.** Исправлено: то, на что ссылается папка,
  только выводится из употребления.

На подтверждение владельцу: срок брони 2 р.д. (`АХ-23`). На подтверждение заказчику: таблица
покрытия ТЗ (`АХ-Д1`, канон §0). Заявки соседям: «Уведомления» (6 видов), «Сотрудники».

## Автогриллинг 13.11.2026 · проход 2 по ролям

Предмет — сквозные сценарии дня пяти ролей: архивариус, куратор, юрист ДПО, бухгалтер, руководитель
(план §6, С-1…С-19). Ищем тупики: действие недоступно с экрана, где его ищут; данные, которых у
человека нет; противоречия правил. Решения приняты Claude рекомендованным вариантом, владелец может
переиграть. Итог: **15 решений — 9 по вопросу, 6 по умолчанию; 3 дефекта.**

Решения:
- [ ] **АХ-35 · Стартовый экран.** Архивариусу — «Очередь архивариуса», остальным — «Мои папки» с
  поиском сверху. Отвергнуто: всем реестр; всем мои папки.
- [ ] **АХ-36 · Очередь архивариуса — только ждущее действия:** «К выдаче» (брони по месту),
  «Продления», «Ждут привязки», «На руках у уволенных», «Просрочены». Запросов на занятые папки нет.
  Отвергнуто: все запросы; одобрение каждого запроса.
- [ ] **АХ-37 · «Нужна до» вместо «к какому числу».** Подставляется сроком возврата при выдаче.
  Почему: после брони «к какому числу» ни на что не влияет. **Уточняет АХ-7, АХ-24 — на
  подтверждение.** Отвергнуто: оставить; оба поля.
- [ ] **АХ-38 · Уведомление сдавшему** «папка принята в архив, № …». Отвергнуто: без уведомления;
  расписка о приёме.
- [ ] **АХ-39 · Примечание при возврате** («без оригинала договора залога — в суде») → история и
  «Содержание». Отвергнуто: не фиксировать; действие «изъять документ».
- [ ] **АХ-40 · Подразделение** у папки без привязки, необязательно; отбор. Отвергнуто: у всех; без
  подразделения.
- [ ] **АХ-41 · Руководитель** — *по умолчанию*: роли нет; задание ведёт в карточку; отбор
  «Подразделение держателя».
- [ ] **АХ-42 · Имя «Архив папок».** «Архив» занят (`Поручительства ▸ Архив`). Заявка навигации.
  Отвергнуто: «Архив»; «Бумажный архив».
- [ ] **АХ-43 · Семь видов уведомлений** — *по умолчанию, уточняет АХ-33*: «Запрос закрыт» с
  причиной; «не получал» — передающему; «принята» — сдавшему.
- [ ] **АХ-44 · Пачкой:** запросить, выдать, принять возврат; записи по каждой папке. Отвергнуто:
  только по одной; пачка как одна выдача.
- [ ] **АХ-45 · КЗД без заёмщика в системе** — принять без привязки (название, ИНН вручную) → «Ждут
  привязки» → «Изменить привязку». Отвергнуто: не принимать; принять как «прочее».
- [ ] **АХ-46 · «Принять ещё»** — *по умолчанию, из АХ-14*.
- [ ] **АХ-47 · Подсказка «куда» после возврата** — *по умолчанию*.
- [ ] **АХ-48 · Поиск и по «Содержанию»** — *по умолчанию*.
- [ ] **АХ-49 · Куратору «мои заёмщики»** в «Заёмщики без КЗД» — *по умолчанию*.

## Гриллинг 13.11.2026 · проход 3 по экранам

Предмет — каждый экран модуля: что на нём, содержание, кнопки. Макета нет, экраны — из плана §3.
Порядок: карточка папки → «Папки» → «Мои папки» → «Очередь архивариуса» → формы действий →
«Заёмщики без КЗД» → «Журнал движения» → справочники → врезка у заёмщика → печать. Решения
принимает владелец из 2–3 вариантов с рекомендацией.

Решения:
- [ ] **АХ-50 · Карточка — панель поверх списка.** Справа ~900 px, свой адрес; список остаётся,
  следующая папка — клик по строке; один столбец: шапка «где сейчас», кнопки, реквизиты, очередь,
  история. Почему: папка — лёгкая запись, работа всегда начинается из списка (очередь, поиск,
  полка, тома). Переигрывает `АХ-34` в части «два столбца». Отвергнуто: отдельная страница.
  По умолчанию: шапка — номер, название, вид; «где сейчас» крупно по состоянию; реквизиты —
  заёмщик с ИНН, «том N из M» со ссылками на другие тома и их состоянием, подразделение,
  содержание, постоянное место, принята (когда, кем), сдал.
- [ ] **АХ-51 · Кнопки карточки — главная + частая + «Ещё ▾».** Главная по состоянию: в архиве —
  «Выдать», забронирована — «Выдать <кому>» и «Снять бронь», на руках и передаётся — «Принять
  возврат», выбыла (утрачена) — «Восстановить»; рядом «Переместить»; в «Ещё» — следующий том,
  привязка, ярлык, списать. Чужие по роли — не показываются; недоступные по состоянию — серые с
  причиной (как `ЗН-13`). Почему: в 9 из 10 случаев выдача или возврат; три кнопки помещаются в
  панель одним рядом; «Списать» не рядом с «Выдать». Отвергнуто: все доступные в ряд.
- [ ] **АХ-52 · История — по выдачам.** Строка на выдачу: с — по · держатель (подразделение) ·
  зачем · итог (в срок / просрочена N р.д. / продлена N раз / передана / вернул с примечанием);
  раскрывается в события «Дата · Кто · Что сделал». Своими строками — приём, перемещение, смена
  привязки, списание, восстановление и запросы, не дошедшие до выдачи (отозван, отказ, не забран).
  Новые сверху. Почему: история отвечает «у кого была» — 3–5 строк вместо 50+ событий; последний
