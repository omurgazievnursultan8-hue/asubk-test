## 1. Что строим

Самостоятельный HTML-макет `mockups/archive/archive.html` — модуль «Архив папок» (имя в интерфейсе,
`АХ-42`): где сейчас физическая папка и у кого. Без сети и хранилища, дизайн-система gov-blue (как соседние макеты), ширина от
1920 px. Дата макета заморожена (`TODAY`), часы двигаются только смоуком. Рабочие дни — по
производственному календарю (в макете — свой список праздников). Все проверки прав и правил — в
движке; кнопка лишь показывает запрет и причину. Шов для смоука — `window.AX`, действия возвращают
`{ok, why}`.

На макет документооборота не опираемся (`АХ-3`).

## 3. Экраны

Модуль — одна страница с разделами в левом меню «Архив папок» (канон §9). Формы действий — окном
поверх экрана.

| раздел | кому | что |
|---|---|---|
| **Очередь архивариуса** | архивариусы (общая, `АХ-22`); стартовый для них (`АХ-35`) | сверху поле «Возврат»: номера подряд → подсказка «куда» и «＋ примечание» → «Принять возврат (N)» (`АХ-57`); четыре блока, только ждущее действия (`АХ-36`, `АХ-56`): «К выдаче» (брони по месту, «Выдать» / «Отказать», «Печать обхода»), «Продления» (видна очередь), «Ждут привязки» (подсказка «найден по ИНН → Привязать»), «На руках у уволенных»; «Просрочены» — нет |
| **Папки** | все | реестр, восемь колонок (`АХ-53`): ☐ · № · Название · Подразделение · Место · Состояние · Держатель · Вернуть до · Ждут; поиск по номеру, названию, ИНН, содержанию (`АХ-48`); плашки «в архиве · забронированы · на руках · просрочены · в очереди · передаются · выбыли» (выбывшие скрыты до плашки); отборы (вид, помещение · шкаф · полка, держатель, подразделение, подразделение держателя `АХ-41`, заёмщик); пачкой (`АХ-44`, `АХ-59`): «Запросить» · «Выдать» · «Принять возврат» · «Переместить» · «Печать ярлыков» · «Списать»; «Принять папку» у архивариуса |
| **Мои папки** | все; стартовый для всех, кроме архивариуса (`АХ-35`) | поле «Найти папку» — Enter ведёт в «Папки» с запросом (`АХ-55`); три блока (`АХ-54`): «Вам передают» («Получил» / «Не получал») → «На руках у меня» (срок, кто ждёт; передача и просьба продлить пометкой; «Передать», «Попросить продление», «Отменить передачу») → «Мои запросы» (№ в очереди или «ждёт вас до …»; «Отозвать»); пустые скрыты |
| **Заёмщики без КЗД** | все | с действующим кредитом (`АХ-32`): заёмщик · ИНН · куратор · департамент · первый кредит · дней; отбор «и закрытые»; куратору — «мои заёмщики» по умолчанию (`АХ-49`); архивариусу в строке «Принять папку» с подставленным заёмщиком; пометка «есть непривязанная папка с этим ИНН» |
| **Журнал движения** | все | за период: принята · выдана · передана · продлена · возвращена · перемещена · списана · восстановлена; отборы по событию, папке, сотруднику |
| **Справочники** | архивариус | «Места» (дерево, число папок, «Печать списка полки»), «Виды папок», «Настройки» — срок выдачи, срок брони, напоминание (`АХ-61`); вывести из употребления |

Счётчики меню: у «Очереди архивариуса» — строки, ждущие действия; у «Моих папок» — «Вам передают»,
брони за мной, мои просрочки.

**Карточка папки** — панель ~900 px поверх списка, свой адрес, один столбец (`АХ-50`): шапка «где
сейчас» крупно → кнопки (главная по состоянию + частая + «Ещё ▾», `АХ-51`, `АХ-58`) → реквизиты (том N
из M со ссылками на другие тома) → просьба продлить на решении → очередь → история по выдачам
(`АХ-52`). Чужие по роли кнопки скрыты, недоступные по состоянию — серые с причиной.

**Формы-действия:** Принять папку (с «Принять и ещё», `АХ-46`) · Принять следующий том · Выдать ·
Запросить · Отозвать запрос · Попросить продление · Продлить (по просьбе и напрямую, `АХ-58`) /
Отказать · Передать · Получил / Не получал · Отменить передачу · Принять возврат (подсказка «куда»,
примечание — `АХ-47`, `АХ-39`) · Переместить · Изменить привязку · Списать · Восстановить. Поля — канон
§9.6.

**Печать:** ярлык на корешок — номер крупно и название, без места (`АХ-60`), по одному или листом
(`АХ-59`); список полки (сверка, `АХ-15`); «Печать обхода» (`АХ-56`); любой список — печать и Excel.

**Шов с заёмщиком:** врезка «Где бумага» (`АХ-31`) — образец на демо-заёмщике: его папки, состояние,
«Запросить», при нескольких томах «Запросить все тома»; у заёмщика без КЗД — «Кредитно-залоговое дело
в архив не сдано».

**Переключатель пользователя** (как в соседних макетах): два архивариуса, куратор ДРР, куратор ДАК,
заведующий отделом ДРР (руководитель, к нему поднимается задание — `АХ-Д7`), юрист ДПО, бухгалтер;
уволенный сотрудник — только как держатель в данных.

## 4. Правила движка (что проверяет смоук)

1. **Принять:** вид с привязкой требует заёмщика; место — действующая полка; номер выдаётся
   сквозной; название с привязкой собирается само. «Следующий том» подставляет вид, заёмщика, том
   N+1.
2. **Выдать:** только архивариус; папка «в архиве» без брони или забронирована за этим получателем;
   срок обязателен — из «нужна до» запроса, иначе срок по умолчанию (настройка, 10 р.д.); «зачем»
   обязательно; получатель — действующий сотрудник; держателю — уведомление. Пачкой — по каждой папке отдельно, занятые не выдаются.
3. **Запросить:** любой; «зачем» обязательно, «нужна до» (`АХ-37`) — по желанию (`АХ-Д14`); второй свой запрос на ту же папку и
   запрос на выбывшую — нельзя; порядок очереди — по времени. Пачкой — запрос на каждую папку.
4. **Бронь:** ставит система, без одобрения (`АХ-Д6`): папка свободна для первого в очереди → бронь
   на срок брони (настройка, 2 р.д.) + уведомление «папка свободна, заберите до …»; другому не выдать; срок брони прошёл →
   запрос «не забран», бронь следующему.
5. **Отказать в запросе** — причина обязательна, в любой момент до выдачи; запросившему —
   уведомление.
6. **Просьба продлить** — только держатель, дата позже текущего срока, причина обязательна; решает
   архивариус, видит очередь; держателю — уведомление о решении. **Продлить напрямую** (`АХ-58`) —
   архивариус без просьбы: дата позже текущего срока, причина обязательна, держателю — то же
   уведомление.
7. **Передать** — только держатель, любому действующему сотруднику; до «Получил» — «передаётся»,
   отвечает передающий; срок не меняется; «Отменить» (передающий) и «Не получал» (получатель)
   возвращают папку передающему; передача любому ждущему закрывает его запрос (`АХ-63`).
8. **Принять возврат** — архивариус; папка на постоянное место; есть очередь → бронь первому;
   подсказка «на полку …» / «отложить: бронь …»; необязательное примечание («вернулось не всё»).
   Пачкой — по каждой папке; поле «Возврат» (`АХ-57`): номер находится без ведущих нулей, папка не
   на руках — строка с причиной, кнопка не принимает её.
9. **Просрочка:** за N р.д. (настройка, 2) — напоминание; после срока — задание «Вернуть папку» держателю (при
   незавершённой передаче — передающему); закрывается возвратом, передачей, продлением, списанием.
10. **Переместить** — в любом состоянии, кроме «выбыла»; полка — действующая (`АХ-Д3`). Пачкой — все
    отмеченные на одну полку (`АХ-59`).
11. **Изменить привязку** — архивариус, основание обязательно, название пересобирается.
12. **Списать** — причина и основание обязательны; закрывает выдачу, бронь, задание и очередь
    («закрыт: папка выбыла»); «Восстановить» — только у «утрачена». Пачкой (`АХ-59`) — причина и
    основание одни на всех, запись у каждой; до списания — сколько на руках и с очередью.
13. **Справочники:** то, на что ссылается папка, не удаляется — только выводится из употребления.
14. **Приём без заёмщика:** КЗД без привязки (название, ИНН вручную) → «Ждут привязки»; в «Заёмщики
    без КЗД» не засчитывается до привязки. «Кто сдал» необязательно; указан — ему уведомление.
15. **Права** — по таблице канона §7; запрет из движка, не только скрытая кнопка.
16. **Настройки** (`АХ-61`): срок выдачи, срок брони, напоминание — меняет только архивариус; новое
    значение действует на новые выдачи и брони, назначенные даты не сдвигаются.
17. **Ярлык** (`АХ-60`): номер и название, без места; лист ярлыков — по отмеченным (`АХ-59`).

## 5. Демо-набор

Собирается действиями движка (как в соседних макетах), чтобы сам проходил свои проверки:

- 2 помещения (Архив ГО, Архив ДПО), 4 шкафа, ~20 полок, одна выведенная полка;
- ~30 папок: КЗД (в т. ч. двухтомное дело), номенклатурные, прочие (две «Протоколы правления ·
  2025» разных отделов — различаются номером);
- все состояния: в архиве; забронирована (ждёт получателя); на руках в срок; на руках с просрочкой
  (задание поднято к руководителю); у уволенного держателя; передаётся (ждёт «Получил»); отменённая
  передача в истории; очередь из двух запросов; просьба продлить на решении; отказ в запросе; «не
  забран»; выбывшие (утрачена, уничтожена); восстановленная; папка со сменой привязки;
- 3–4 заёмщика без КЗД с разным числом дней от регистрации кредита, один закрытый;
- КЗД без привязки (заёмщика нет в системе); две «Протоколы правления · 2025» разных подразделений;
  возврат с примечанием «без оригинала договора залога»; вид «Дело взыскания» (к заёмщику).

## 6. Сценарии по ролям и смоук

Сквозные сценарии (проход 2) — их же проходит смоук `scripts/inspect/archive-check.mjs` вместе с
группами правил §4; отрисовка на 1920 px. Лёгкий режим: одно ревью, один раунд правок, мелочи — в
журнал.

**Архивариус**
- С-1 Утро: стартовый экран — «Очередь архивариуса»; «К выдаче» отсортировано по месту.
- С-2 Выдача по брони у окна: срок подставлен из «нужна до»; держателю — уведомление.
- С-3 Выдача пришедшему без запроса; попытка выдать забронированную за другим — запрет с причиной.
- С-4 Отказ в запросе → «Запрос закрыт: отказ» → бронь следующему.
- С-5 Возврат стопкой через поле «Возврат» (три номера, разные держатели) → подсказка «куда» до
  нажатия; при очереди — бронь первому; возврат с примечанием.
- С-6 Просьба продлить при очереди → отказ «папку ждут».
- С-7 Приём новой КЗД → ярлык → уведомление сдавшему; «Принять следующий том».
- С-8 Ввод при запуске: «Принять ещё» ×3; КЗД без заёмщика → «Ждут привязки» → привязка.
- С-9 Печать полки; «Переместить» найденную на чужой полке.
- С-10 Папка у уволенного → «Списать: утрачена» → очередь закрыта; «Восстановить».
- С-20 Держатель у окна просит неделю → «Продлить» напрямую с причиной → уведомление держателю.
- С-21 Акт уничтожения: отбор полки → отметить все → «Списать» пачкой с одним основанием; после ввода
  при запуске — «Печать ярлыков» листом.

**Куратор**
- С-11 Из врезки «Где бумага» запросить все тома пачкой.
- С-12 «Папка свободна» → получил → «Мои папки».
- С-13 «Передать» заведующему → «Получил» → передача обратно.
- С-14 Напоминание за 2 р.д. → «Попросить продление» → решение.
- С-15 «Заёмщики без КЗД» с отбором «мои заёмщики»; сдал дело → уведомление о приёме.

**Юрист ДПО**
- С-16 Запрос занятой папки → место в очереди → куратор передаёт напрямую → запрос закрыт.
- С-17 Продление под суд; возврат «без оригинала» с примечанием.

**Бухгалтер**
- С-18 Стартовый экран «Мои папки» пуст → «Найти папку» по содержанию → две одноимённые различает
  подразделение → запрос с «нужна до».

**Руководитель**
- С-19 Поднятое задание «Вернуть папку» → карточка папки → отбор «подразделение держателя».
